# 반점 제거 보호 장치와 시험 보강 (dense-speckle-guard)

## 결론
- `remove_speckles` 에 세 가지를 손봤다: (1) 지도 길이가 w·h 와 다르면 아무것도 건드리지 않고 0 을 돌려준다(w=h=4, 깊이 8개에서 예전에는 범위 밖 인덱스로 죽었다), (2) 지운 화소의 비용을 1.0 대신 무효 값 `f32::INFINITY` 로 둔다, (3) 단위 시험에 대각 접촉, 0.5% 경사, 0.8% 계단, 문턱과 정확히 같은 상대차, 짧은 지도 경우를 넣었다.
- 새 시험은 연결 규칙과 문턱 비교를 실제로 잡는다. 4-연결을 8-연결로 바꾸면 대각 접촉 시험이, `<` 를 `<=` 로 바꾸면 문턱 동치 시험이 실패한다. 예전 시험은 두 변이를 모두 통과했다.
- 비용을 INFINITY 로 바꿔도 사용처는 깨지지 않는다. 지운 화소는 깊이 0 이라 융합에서 이미 빠지고, 가중 위치 계산은 비용이 유한하지 않으면 균등 가중으로 돌아가도록 되어 있다(fusion.rs 의 `weight`). 스윕이 빈 지도를 INFINITY 로 채우는 것과도 같은 관례가 된다.

## 수치 표
| 시험 | 장면(손계산) | 기대 | 정상 | 8-연결 변이 | `<=` 변이 |
|---|---|---|---|---|---|
| 기존 큰 평면·조각 | 400 화소 평면 + 9 + 5 화소 | 14 지움 | 통과 | 통과 | 통과 |
| 대각 접촉 | 12×12 와 9×9 가 모서리 한 점 접촉 | 81 지움 | 통과 | 실패 | 통과 |
| 0.5% 경사 | 30×30, 열마다 ×1.005 | 0 지움 | 통과 | 통과 | 통과 |
| 0.8% 계단 | 20×20(10.0) 옆 5×5(10.08), 문턱 0.007 | 25 지움 | 통과 | 통과 | 통과 |
| 문턱 동치 | 20×20(8.0) 옆 5×5(10.0), 문턱 0.25 | 25 지움 | 통과 | 통과 | 실패 |
| 짧은 지도 | 4×4, 깊이 8개 | 0, 지도 불변 | 통과 | 통과 | 통과 |

변이는 임시로 넣어 시험을 돌린 뒤 되돌렸고, 되돌린 파일로 다시 전체 시험을 통과시켰다.

## 방법
- 모두 합성 지도에 손계산 정답을 숫자로 단언한다. 0.5% 경사는 이웃 상대차가 0.005 < 0.007 이라 한 성분이고, 0.8% 계단은 0.008 > 0.007 이라 갈라진다.
- 문턱 동치는 상대차가 부동소수로 정확히 떨어지게 8 → 10, 문턱 0.25 를 골랐다(2/8 = 0.25). 큰 평면이 먼저 훑이므로 낮은 깊이에서 높은 깊이로 가는 방향이 문턱과 같아진다. 0.007 같은 값은 f32 에서 정확히 같게 만들기 어려워 이 방식을 썼다.
- 측정 환경은 4 코어 측정 기계, 시험은 release 로 돌렸다.

## 남은 문제
- 0.8% 계단·0.5% 경사 시험은 문턱 0.007 의 양쪽을 확인하지만 `<=` 변이는 잡지 못한다. 그 경계는 문턱 동치 시험이 맡는다.
- 길이 불일치는 오류 대신 0 으로 처리했다. 호출 쪽이 이를 "지운 것 없음"과 구분하지 못한다. 오류가 필요하면 시그니처를 바꿔야 한다.
- 비용만 보는 후처리가 아직 없어 INFINITY 의 효과는 단위 시험에서만 확인된다.
