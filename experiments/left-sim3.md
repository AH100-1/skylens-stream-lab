# 떨어진 왼쪽 카메라 성분의 닮음 변환 붙이기

## 결론

- 목표(시드 5 verify 7/7, 또는 6/7 + registered ≥ 80/81 + preview_vs_refined 통과)는 못 이뤘다. 시드 5 는 80/81, 5/7 그대로이고
  preview_vs_refined 는 여전히 실패한다(최근접 중앙 최대 4.08 m, 높이 차 중앙 최대 5.44 m).
- 붙인 왼쪽 카메라의 합성 정답 대비 오차를 처음 쟀다: 위치는 구역 0 에서 중앙 0.29 m, 구역 1 에서 1.72 m 로 작지만,
  회전은 구역 0 에서 약 25°, 구역 1 에서 약 3.8° 틀어져 있다. 그러나 같은 구역의 정면·오른쪽 카메라도 구역 0 에서 14.6°,
  구역 1 에서 4.9° 틀어져 있어, 왼쪽 카메라만의 오차는 구역 0 에서 약 10°, 구역 1 에서 약 1° 이다. 구역 모델 전체의 연직·롤
  오차가 더 큰 몫이다.
- 규모·회전·이동을 모두 푸는 닮음 변환(점 최근접 겹침 + GPS 중심 약한 사전항)을 넣어 왼쪽 회전 오차를 24.95°→22.84°(구역 0),
  3.77°→2.77°(구역 1) 로 줄였지만 preview_vs_refined 는 고치지 못했다.
- 시드 1 은 7/7(registered 통과), 떨어진 성분 없음, 왼쪽 회전 오차 0.8~1.1° 로 변화 없다.

## 방법

1. 기존 단계(바닥 법선으로 롤 선택, GPS 평균 이동)로 초기 해를 만든다. 사진 6장·GPS 정상 대응 3개 관문은 그대로다.
2. 그 상태에서 부분 모델 점을 주 모델 점에 가까운 점쌍(3 m 격자 해시, 문턱 3→1.5→0.8→0.4 m)으로 맞추는 ICP 를 돌린다.
   각 반복의 닮음 변환은 점쌍과 GPS 중심 쌍(점쌍 수의 약 1/4 가중)의 Umeyama 로 구한다.
3. 결과가 규모 0.85~1.18, 회전 변화 20° 이내이고 GPS 정상 대응의 80 % 이상이 5 m 안에 남을 때만 적용한다. 점쌍이 50 개
   미만이면 건너뛰어 초기 해를 쓴다.
4. 시험 `pipeline::detached_tests` 3 개: 기존 둘 + 규모 1/1.08, 임의 축 4° 회전, 이동을 준 성분이 규모 2 %·위치 1 m·회전
   4° 안으로 돌아온다(회전 실측 약 2.9°). 요구한 2° 는 못 맞췄다. 겹침이 20 m 폭이라 롤이 약하게 정해지고 점대점 ICP 가
   매끈한 기복에서 미끄러진다. 규모는 1.084 로 정답 1.08 에 맞았다.

## 남은 문제

- preview_vs_refined 원인 미확인. 이전 기준 대비 구역 정밀 모델의 정면·오른쪽 카메라 자체가 구역 0 에서 약 15° 기울어 있어
  (왼쪽 성분과 무관), 이 기울기가 초벌·정밀 사이 높이 차의 후보다. 부분 모델 점을 점 구름에 넣지 않았을 때의 비교는 못 했다.
- 한 장 미등록(80/81) 그대로.
- 회전을 2° 안으로 줄이려면 점대면 ICP 나 주 모델과의 공통 트랙 직접 사용이 필요해 보인다.
- 시드 3 은 측정하지 못했다.
