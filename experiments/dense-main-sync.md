# 조밀 재구성 브랜치 체인의 main 동기화

## 결론

- 조밀 재구성 PR 체인(dense-accuracy → dense-pose-robust → dense-speckle-guard)에 최신 main(a1d2ad5)을 합쳤다. 합치는 과정에서 충돌은 없었고(dense-accuracy 에서 같은 시험 파일을 먼저 고친 커밋과만 충돌, 새 측정값 쪽을 택함), 시험 실패 2건은 라이브러리 오류가 아니라 고정해 둔 측정값이 바뀐 것이었다.
- 원인은 main #67 이 작은 사진(긴 변 800 px 미만)의 2배 확대 보충을 기본으로 켠 것이다(상세는 experiment/dense-regress-cause 35b57bf). 단구역 장면은 320x180 이라 여기에 해당한다. 카메라 중심 오차는 줄었고(중앙 0.312 → 0.256 m, 최대 0.851 → 0.713 m) 표면 거리 분포는 넓어졌다(95% 0.932 → 1.214 m).
- 단구역·구역 2개 시험의 상한, 시험 주석, README 표를 현재 출력에 맞게 다시 고정했다. 세 브랜치 모두 같은 숫자가 나왔다(조밀 코드가 브랜치마다 달라도 e2e 출력은 동일).

## 방법

1. dense-accuracy 에 origin/main 을 병합(병합 커밋)하고 pipeline_e2e, pipeline 을 `--nocapture` 로 돌려 출력을 기록했다.
2. 시험의 상한, 시험 주석, README 표(단구역·구역 2개 표, 초벌 다듬기 표)를 출력 숫자와 같게 고쳤다. 라이브러리 코드는 건드리지 않았다.
3. 위쪽 브랜치로 차례로 병합해 같은 시험을 다시 돌렸다. 출력이 같아 추가 재고정은 필요 없었다.
4. fmt, clippy(`-D warnings`) 통과를 확인했다.

## 남은 문제

- 단구역 표면 거리 95% 가 0.932 → 1.214 m 로 나빠진 것은 확대 보충이 만든 분포 변화이며(p90 0.768 → 0.992 m) 이번에 고치지 않았다. 중심 오차는 좋아졌으므로 점 필터 쪽 점검이 필요하다.
- dense-accuracy 에는 다른 쪽에서 먼저 올라온 재고정 커밋이 있어 병합했고, 시험 파일은 최신 main 기준 측정값을 택했다.
- 단구역 시험은 4 코어 측정 기계에서 pipeline_e2e 약 4~5 분, pipeline 약 8~12 분 걸린다.
