# 시드별 장착 거부 기준선 (F-426)

## 결론
- 시드 1~4 는 `default_path_seed_verify` 가 7/7, 등록 81/81(초벌·정밀 모두)이고 구역은 3개다. 네 시드 모두 떨어진 성분이 하나도 나오지 않아 `diag detached`·`diag rig check` 줄이 없다. 따라서 시드 1~4 에서는 3° 문턱에 걸려 거부된 정상 성분이 없다(시험 대상 표본이 없다). 붙은 성분의 각거리 중앙 ≤ 2.5° 는 표본이 없어 시드 1~4 에서는 재지 못했고, 위반도 없었다.
- 시드 5 는 6/7, 정밀 80/81(`registered` 만 FAIL)로 기준선과 같다. 떨어진 L 성분 셋의 장착 검사 중앙값은 0.38°(27장, 붙음), 2.47°(17장, 붙음), 10.05°(5장, 거부)로 이전 보고치와 같다. 붙은 성분 최대 2.47° 는 문턱 3.0° 안쪽이다.
- 문턱 3° 의 정상 쪽 근거는 여전히 시드 5 표본 둘뿐이다. 시드 1~4 는 성분이 안 나와 근거를 더 주지 못한다. 제품 코드와 문턱은 바꾸지 않았다.

## 방법
- 제품 83ad938(작업 트리를 이 커밋에 분리해 둠, 브랜치 없음)에서 `crates/cli/tests/seed_verify.rs` 의 `default_path_seed_verify` 를 시드마다 `SKYLENS_TILT_SEED=<시드> SKYLENS_REGION_DIAG=1 cargo test --release -j 2 -p skylens-stream --test seed_verify default_path_seed_verify -- --ignored --nocapture` 로 한 번에 한 시드씩 차례로 돌렸다. 4코어 측정 기계에서 다른 작업과 겸해 시드 하나에 약 4~10분(시드 1은 빌드 포함 9분).
- 붙은·거부된 성분의 각거리는 `diag rig check n .. med_deg ..` 줄의 중앙값이다. 이 줄은 떨어진 성분이 나왔을 때만 찍힌다.
- 시험 `pipeline_stream_order` 는 제품 83ad938 에 있으며 작업 공간 루트에서 통과한다는 점은 `detached-rig-seeds.md` 에서 정정했다.

## 남은 문제
- 성분이 나오는 시드가 5 하나뿐이라 문턱 3° 의 정상 쪽 근거(0.38°·2.47°)를 넓히지 못했다. 성분이 나오는 다른 합성 설정이나 표본을 더 만들어야 한다.
