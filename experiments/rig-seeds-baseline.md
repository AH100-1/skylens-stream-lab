# 시드별 장착 거부 기준선 (F-426)

## 결론
- 시드 1·2 는 `default_path_seed_verify` 가 7/7, 등록 81/81(초벌·정밀 모두)이다. 두 시드 모두 구역 3개이고, 떨어진 성분이 하나도 나오지 않아 `diag detached`·`diag rig check` 줄이 없다. 따라서 이 두 시드에서는 3° 문턱에 걸려 거부된 정상 성분이 없다. 붙은 성분·거부된 성분의 각거리 중앙은 표본이 없어 잴 수 없었다.
- 시드 3~5 는 시간 안에 끝내지 못했다(아래 표 '미측정'). 문턱 3° 의 근거는 여전히 시드 5 정상 표본 둘(0.38°·2.47°)이 전부이며, 확인 기준(시드 1~4 7/7·81/81, 시드 5 80/81, 붙은 성분 각거리 중앙 ≤ 2.5°)은 시드 1·2 에서만 확인됐다.
- 제품 코드는 바꾸지 않았다. 문턱도 그대로 3.0°.

## 방법
- 제품 83ad938(작업 트리를 이 커밋에 분리해 둠, 브랜치 없음)에서 `crates/cli/tests/seed_verify.rs` 의 `default_path_seed_verify` 를 시드마다 `SKYLENS_TILT_SEED=<시드> SKYLENS_REGION_DIAG=1 cargo test --release -j 2 -p skylens-stream --test seed_verify default_path_seed_verify -- --ignored --nocapture` 로 한 번에 한 시드씩 차례로 돌렸다. 4코어 측정 기계에서 다른 작업과 겸해 시드 하나에 약 7~10분(시드 1은 빌드 포함 9분).
- 붙은·거부된 성분의 각거리는 `diag rig check n .. med_deg ..` 줄의 중앙값이다. 이 줄은 떨어진 성분이 나왔을 때만 찍힌다.
- 시험 `pipeline_stream_order` 는 제품 83ad938 에 있으며 작업 공간 루트에서 통과한다는 점은 `detached-rig-seeds.md` 에서 정정했다.

## 남은 문제
- 시드 3, 4, 5 측정. 특히 시드 5 에서 `diag rig check` 중앙값 분포와 80/81 확인.
- 시드 1·2 처럼 성분이 안 나오는 시드는 문턱 근거를 주지 못하므로, 성분이 나오는 시드(시드 5)의 표본을 늘려야 한다.
