# 시드 3 구역0 붕괴: 회전 평균 단계에서 깨진다

## 결론

- 시드 3 구역0 이 깨지는 단계는 회전 평균이다. 회전 평균 출력이 이미 정답 대비 평균 39.7° / 최대 52.3°(전역 회전을 맞춘 뒤) 틀어져 있고,
  이후 위치 단계·첫 BA·정밀 BA·GPS 정렬은 이 틀어진 회전을 물려받는다. 정상 구역은 같은 단계에서 0.5~0.7°다.
- 입력 상대 회전은 거의 멀쩡하다. 구역0 간선 347개 중 정답과 5° 넘게 어긋난 것은 2개뿐이고, 그중 1개(정상 대응 25개)가 회전 평균에 그대로 들어간다
  (`min_inl` 0, 기본은 카메라 쌍 투표 꺼짐). 정상 간선 중앙의 정상 대응 수는 656. 즉 간선 하나가 회전 평균의 해를 크게 휘게 한다.
  뒤의 10° 간선 제거 한 바퀴는 이미 휜 해를 기준으로 하므로 복구하지 못한다.
- 같은 시드 3 에 `--pair-vote`(카메라 쌍 단위 회전 투표, 이미 있는 옵션)를 주면 그 간선이 걸러지고(남긴 불량 간선 0) 구역0 회전 평균 출력이 1.90° / 최대 2.43° 로 돌아오며,
  최종 구역0 평균 회전 오차가 24.455° → 2.725°(연직 기울기 중앙 12.14° → 3.16°), verify 5/7 → 6/7(남은 실패: preview_vs_refined, 높이 차 2.82 m > 2 m)이다.
- 위치 단계 이후는 원인이 아니다: 회전이 틀어진 채로 위치를 풀기 때문에 척도 1.16 배·중심 잔차 중앙 6.8 m 로 나빠질 뿐이며, 정렬 후보가 여럿이라서 생긴 문제로는 보이지 않는다
  (GPS 강건 정렬은 68장 중 47장을 정상으로 잡고 척도 1.11 을 냈다. 입력 모델이 이미 틀어졌기 때문이다).
- 실패 빈도: 시드 3 은 구역0 붕괴(5/7), 시드 4 는 6/7(구역2 회전 오차 13.8°), 시드 5 는 5/7(등록 54/81 이라 다른 실패 방식). 시드 1·2 는 7/7. 5개 중 3개가 7/7 아님.
- 수정: `PipelineConfig` 기본 `pair_vote` 를 켬으로 바꿨다(한 줄). 시드 1·2 는 `--pair-vote` 를 준 실행(= 새 기본과 같은 경로)에서 7/7 이고 구역별 회전 오차가 바꾸기 전과 소수 셋째 자리까지 같다
  (0.923 / 1.298 / 1.649, 0.835 / 1.504 / 3.314). 기본값을 바꾼 빌드 자체는 다시 돌리지 못했다.

## 방법

- 제품 feat/seed3-collapse(feat/default-tilt-seeds 363b2db 위). 환경 변수 `SKYLENS_REGION_DIAG` 가 있을 때만 `pipeline.rs` 가 단계별 사진 자세(회전·중심)와 입력 상대 회전,
  첫 BA rms·점 수, 정밀 BA rms, GPS 정렬 요약(정상 수·척도·정상 잔차 중앙)을 표준 오류로 낸다. 켜지 않으면 동작 불변.
- 무시 시험 `default_tilt.rs` 가 이 줄들을 합성 정답과 비교한다. 회전 오차는 Q = polar(Σ R_estᵀ R_true) 로 전역 회전을 맞춘 뒤 (R_est Q)ᵀ R_true 의 각.
  중심은 Umeyama 닮음 변환을 맞춘 뒤 잔차. 입력 상대 회전은 R_j R_iᵀ 와 비교. 환경 변수 `SKYLENS_TILT_RUN_ARGS`(예: `--pair-vote`), `SKYLENS_TILT_VERBOSE`(사진별 회전 오차) 추가.
- 명령: `SKYLENS_TILT_SEED=<시드> [SKYLENS_TILT_RUN_ARGS=--pair-vote] RAYON_NUM_THREADS=2 cargo test --release -j 2 -p skylens-stream --test default_tilt -- --ignored --nocapture`
- 시드 4·5 는 단계 진단을 넣기 전 빌드로 쟀다(구역별 최종 값만 있음). 시드 3 은 단계 진단 빌드.

## 남은 문제

- 기본값을 바꾼 빌드로 시드 1~5 를 인자 없이 다시 재야 한다(이번에는 플래그 실행으로 대신함). 시드 4·5 는 켠 상태를 재지 않았다.
- 켠 시드 3 도 preview_vs_refined 가 실패(높이 차 2.82 m)하고 구역1·2 회전 오차 4° 대는 그대로다. 시드 4·5 의 실패(구역2 13° 기울기, 시드 5 등록 54/81)는 다른 원인이며 단계별로 보지 못했다.
- 회전 평균 자체가 간선 하나(정상 대응 25)에 이렇게 약한 것도 문제다. `min_inl` 문턱이나 초기화 단계의 강건성을 보면 투표 없이도 막을 수 있을지 모른다. 확인 안 함.
