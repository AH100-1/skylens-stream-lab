# 번들 조정 강건 손실 — 실측 편대 배치 검증 (F-036, F-034, F-040)

## 결론
- 실측 편대 배치(SPEC §6: 3대 약 10 m 간격, 방향 −3°/+125°/−116°, 기울기 60°, 위치 간 1.0 m) 12위치 = 카메라 36,
  점 600(관측 5648) 합성 문제로 정답 대비 시험 `robust_losses_on_formation_scene` 를 만들었다.
  기준은 이론값에 묶었다: 이상치 없는 최소제곱 RMS / σ√2·√(1−p/2m) 가 0.95~1.05, 강건 손실 내정 RMS < 1.2·σ√2(Cauchy)·1.5·σ√2(Huber),
  중심·점 오차 < 깨끗한 최소제곱 해(최대우도 하한) 의 1.5배(Cauchy)·2.5배(Huber), 중심 < 0.05 m, 이상치를 받는 최소제곱은 내정 RMS > 3·σ√2.
- 시드 41 에서 시험이 실패해 무시 표시로 남겼다. 원인은 강건 손실이 아니라 기하다: 이상치 없는 최소제곱도 잔차는 잡음 하한(0.992)에
  닿는데 정렬 중심 오차 1.2 m·점 오차 13 m 가 남고 100회 안에 수렴하지 않는다. 내부 파라미터를 정답으로 고정하고 섭동을
  작게(이동 0.05 m, 회전 0.002 rad) 해도 같다. 위치 간 1.0 m 기선·먼 점(최대 60 m 옆)에서 비용이 거의 평평한 방향이 남는다.
  따라서 F-036 확인 기준 "편대 장면 중심 오차 < 0.05 m" 는 현 문제 구성(점 분포·감쇠)으로는 성립하지 않는다.
- 같은 시드에서 강건 손실 자체는 동작한다: 내정 RMS Huber 0.945·Cauchy 0.850 (< 1.2·0.707 = 0.849 바로 경계), 이상치 받는 최소제곱 4.806.
  Cauchy 내정 3 px 초과 4개(관측 수 적은 점 일부가 이상치 쪽 해) 는 이전 장면과 같은 현상.
- F-034: main 의 축척 게이지 고정(두 번째 기준 카메라 이동 한 성분) 시험 `scale_gauge_is_fixed`·`empty_fixed_cameras_uses_default_gauge` 가
  이 브랜치에서도 그대로 있다. 확인 기준(λ₀ 1e-12/1e-4 |c1−c0| 상대 차 < 1e-9, 촐레스키 실패 0, 빈 fixed_cameras 패닉 없음)은 감독 재측정으로 통과 확인됨.
  남은 F-121(NaN·inf 점)·F-122 는 ba-hardening 3차에서 처리. 이 묶음에서 새 변경 없음.
- F-040: 미착수(시간 부족). 편대 문제 36대·600트랙에서 반복 수만 기록: 세 손실 모두 100회 상한 도달.

## 방법
- 장면: `synth::Scene::new(SceneConfig { positions: 12, ..기본 })` 의 정답 포즈 36개, 카메라 종류별 내부 그룹 3개
  (fx 1%씩 차이, 왜곡 k1 −0.10 등). 점은 x ∈ [−60, 71], y ∈ [−60, 60], 높이 = 지형 + 0~3 m, 세 장 이상 보이는 것만.
- 정답 픽셀에 σ = 0.5 가우시안, 관측 10% 에 20~60 px 이상치. 같은 섭동 시작을 깨끗한/이상치 문제에 함께 준다.
- 최대 100회, 카메라 0 고정(축척은 자동 고정).

## 남은 문제
- 편대 배치의 약한 방향: 점 오차가 큰 것이 먼 옆쪽 점 때문인지(점 범위를 좁혀 재기), 반복 한도·감쇠 때문인지(1000회까지 늘려 수렴 여부) 확인.
  수렴 후 오차가 공분산 기준 하한과 맞는지 측정하고 그 뒤 기준을 정한다. 실제 파이프라인은 GPS 사전정보가 이 방향을 묶을 수 있다.
- Cauchy 내정 3 px 초과 0개 기준은 여전히 미달(관측 3~5개 점).
- F-040 구간 분해(편대 배치 240대) 미착수.
