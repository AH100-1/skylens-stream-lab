# 정밀 BA 위치 사전항이 기울기를 만드는가 (seed 3)

## 결론

- 위치 사전항(GPS)은 정밀 모델 기울기의 원인이 아니다. 사전항을 끄면(가중 0) 구역 0 높이 차 중앙값이 2.819 m → 3.518 m 로 오히려 나빠지고, y 방향 평면 기울기도 0.146 → 0.182 로 커진다.
- 사전항을 10배 세게 주면 구역 0 은 2.819 → 2.499 m, 구역 1 은 2.342 → 1.349 m 로 좋아지고 구역 1 기울기도 0.140 → 0.079 로 줄어든다. 구역 0 기울기는 0.138 로 거의 그대로여서 기울기 자체는 남는다.
- 100배로 올리면 구역 0 이 4.499 m 로 다시 나빠진다(기울기 0.221). 즉 가중에 대해 단조롭지 않고, 10배 부근이 가장 낫다. 사전항은 기울기를 줄이는 쪽으로 작동하지만 원인은 다른 곳(초벌 쪽 기울기 +, 정밀 쪽 기울기 −가 서로 반대로 생기는 점)에 있다.
- verify 의 preview_vs_refined 는 어떤 가중에서도 통과하지 못했다(최소 2.499 m, 기준 2 m).

## 수치 표

가중은 정밀 BA 에 넘기는 σ 를 나누는 배율이다(1 = 기존 동작). 높이 차 dz 는 초벌 점과 가장 가까운 정밀 점(수평 짝)의 높이 차. 기울기는 dz 의 평면 맞춤에서 y 방향 계수(m/m).

| 가중 | 구역0 중앙 abs dz | 구역1 | 구역2 | 구역0 y기울기 | 구역1 | 구역2 | verify 높이 차 최대 / 최근접 최대 |
|---|---|---|---|---|---|---|---|
| 0 (끔) | 3.518 | 2.694 | 0.717 | 0.182 | 0.165 | -0.015 | 3.518 / 3.097 |
| ×1 (기본) | 2.819 | 2.342 | 0.632 | 0.146 | 0.140 | -0.021 | 2.819 / 2.543 |
| ×10 | 2.499 | 1.349 | 0.950 | 0.138 | 0.079 | -0.004 | 2.499 / 2.231 |
| ×100 | 4.499 | 1.721 | 1.512 | 0.221 | 0.095 | 0.010 | 4.499 / 4.030 |

구역 0 의 y 구간 양끝(bin_y0 / bin_y5)에서 초벌·정밀 점의 지표 대비 높이 중앙값(med_hp / med_hr, m):

| 가중 | bin_y0 초벌 / 정밀 | bin_y5 초벌 / 정밀 |
|---|---|---|
| 0 | -3.14 / 1.69 | 3.90 / -2.55 |
| ×1 | -2.42 / 1.68 | 2.39 / -2.46 |
| ×10 | -2.49 / 0.65 | 3.51 / -1.74 |
| ×100 | -2.15 / 4.44 | 3.05 / -3.82 |

초벌은 y 가 커질수록 위로, 정밀은 아래로 기운다. 이 반대 방향 기울기는 가중을 바꿔도 부호가 유지된다. 구역 0 에서 초벌 쪽 기울기 자체는 정밀 BA 의 가중과 무관하게 남는다(초벌 BA 는 이번에 바꾸지 않았다).

## 방법

- seed 3 합성 데이터, 4 코어 측정 기계에서 `SKYLENS_SPLIT_SEED=3` 로 preview_split 진단을 가중마다 1회씩(릴리스 빌드) 실행.
- 정밀 BA 에서 위치 사전항 σ 를 `SKYLENS_GPS_PRIOR_WEIGHT` 로 나눈다. 미설정이면 기존 동작, 0 이하이면 σ=1e9 로 사실상 끔. 초벌 BA 의 사전항은 그대로 두었다.
- 가중 1 의 값은 이전 기록(2.819 m, 평면 기울기 0.146 / 0.140 / -0.021)과 일치했다.

## 남은 문제

- 가중마다 1회씩만 돌렸다. 구역별 점 수가 조금씩 달라(예: 구역 0 짝 10736~10953) 실행 간 변동이 있을 수 있어 ×10 의 이득이 안정적인지는 반복이 필요하다.
- 기울기의 원인은 아직 모른다. 초벌 쪽(초벌 BA 사전항, 초기 위치 풀이)과 정밀 쪽(고정 카메라, 구역 연결 기준) 각각을 따로 흔들어 봐야 한다. 구역 2 는 기울기가 거의 없는데 구역 0, 1 만 크다는 점도 설명이 안 된다.
- 초벌 BA 쪽 사전항 가중은 아직 실험하지 않았다.
