# T11 depth-fusion — 다시점 깊이 맵 일관성 융합

## 결론
채택 제안(조건부). 왕복 재투영(1 px) + 상대 깊이 차(1%) 검사와 최소 3시점 동의로 점군을 만든다.
잡음(σ = 0.1% 상대 깊이) + 이상치 10% 깊이 맵에서 정답 표면 거리 중앙값 0.00109, 최대 0.0150.
이상치를 그대로 올리면 최대 1.47 이므로 이상치는 걸러진다. 2장만 주면 점이 나오지 않는다.
다만 시험 안의 정답 가시성 판정(점이 정답 기준 몇 장에 보이는가)이 약 10% 의 점을 3장 미만으로 센다.
판정 쪽 문제로 보이나 확인하지 못해 기준값으로 쓰지 않았다(남은 문제 1).

## 수치 (4 코어 측정 기계, 96×72 깊이 맵 6장)
| 검증 | 기준 | 결과 |
|---|---|---|
| 정답 깊이 융합: 점 수 | > 2000 | 5313 |
| 정답 깊이: 표면 거리 중앙값 | < 1e-5 | 2.93e-8 |
| 정답 깊이: 표면 거리 최대 | < 0.035 (화소 크기 절반) | 0.0146 |
| 잡음+이상치: 점 수 | > 2000 | 4648 |
| 잡음+이상치: 중앙값 | < 0.004 (σ/√3) | 0.00109 |
| 잡음+이상치: 최대 | < 0.07 (깊이 7 × 1%) | 0.0150 |
| 걸러지지 않은 대조: 최대 | > 0.3 | 1.470 |
| 표면에서 0.03 넘게 벗어난 점 비율 | < 1% | 통과 |
| 2장 입력, min_views 3 | 0 점 | 0 점 (min_views 2 면 점 생김) |
| NaN·음수 깊이 섞인 입력 | NaN 없음 | 통과 |
| 법선 단위 길이, 색 평균 | | 통과 |

기준값 근거: 장면 깊이 약 4.5~7, f ≈ 83 px → 화소 크기 ≈ 0.07(깊이 6).
잡음 σ = 0.001·d ≈ 0.005~0.007, 3장 이상 평균이면 σ/√3 ≈ 0.004 이하.
살아남은 각 깊이는 기준 깊이와 1% 이내이므로 최대 오차는 깊이 7 × 1% = 0.07 이하.

## 방법
- 장면: 바닥 평면 z = 0 위 상자 [−0.6, 0.6]² × [0, 0.8]. 카메라 6대가 반지름 4, 높이 3 원 위에서 (0, 0, 0.3) 을 본다(화각 60°).
- 정답 깊이·법선은 시험 안에서 광선–평면/상자(슬래브) 교차로 화소 중심마다 렌더.
- 잡음: 화소마다 d·(1 + 0.001·N(0,1)). 이상치: 10% 화소를 d·(1 ± U[0.1, 0.4]) 로 바꿈. 결정적 xorshift64* 난수.
- 융합: 기준 사진 r 의 화소 p, 깊이 d → X. 다른 사진 j 에 투영한 화소 q 의 깊이로 Y 를 올리고 r 로 되돌려
  |π_r(Y) − p| ≤ reproj_px, |z_r(Y) − d|/d ≤ depth_rel 이면 동의. 동의 수 + 1 ≥ min_views 이면
  X 와 Y 들의 평균 위치, 세계 좌표 법선 평균(정규화), 색 평균으로 점 하나. 쓰인 화소(r 과 동의한 j 의 q)는 표시.
- 정답 표면 거리 = min(|z|, 상자 부호 거리의 절댓값).

## 남은 문제
1. 시험의 정답 가시성 판정(3×3 이웃, 0.04 거리)이 융합 점의 약 10% (457/4648) 를 3장 미만으로 센다.
   해당 점들은 표면 위(거리 기준 통과)에 있어 판정 쪽 문제(영상 경계·바닥 경사 시선)로 추정되나 확인 못 함.
   확인 뒤 "정답 기준 3장 미만 가시 점 0" 을 숫자 기준으로 넣어야 한다.
2. 처리 순서가 사진 0 부터라 결과가 순서에 따라 조금 달라진다. 비용(cost) 순 정렬은 아직 안 씀.
3. 직렬 구현. 큰 영상에서는 기준 사진 단위 병렬화와 표시 충돌 처리가 필요하다.
4. `DepthMap` 은 fusion.rs 안의 임시 형. 깊이 추정 묶음 병합 뒤 그 형으로 바꾼다.
5. 법선은 카메라 좌표계 입력으로 가정했다. 깊이 추정 쪽 규약과 맞춰야 한다.

## 제품 저장소
- 브랜치 `feat/depth-fusion` (AH100-1/skylens-stream-rs), 커밋 d7e6617
- 공개 API: `fusion::fuse(&[FusionView], &[DepthMap], FusionConfig) -> ply::PointCloud`,
  `FusionConfig { reproj_px: 1.0, depth_rel: 0.01, min_views: 3 }` (Default),
  `FusionView { camera: Camera, rgb: Vec<[u8; 3]> }`, `DepthMap { w, h, depth, normal, cost }`.
