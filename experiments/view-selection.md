# T10a view-selection — 이웃 사진 선택·깊이 범위·왜곡 보정

## 결론
채택 제안. 밀집 깊이 준비 세 가지를 넣었다.
- 이웃 선택: 공유 희소 점마다 광선 사이 각(목표 10°, 아래쪽 σ 5°, 위쪽 σ 15° 가우스)과 축척 비((min/max)²)
  가중치를 곱해 합산, 상위 8장. 고도 30 m, 1 m 간격 직선 비행 합성 배치에서 가운데 사진의 이웃은
  간격 [6, −6, 7, 5, −7, −5, 8, −8] 순. 1칸 이웃(광선 각 약 2° 이하)은 8장 안에 들지 않고 8칸 이웃은 들어간다.
- 깊이 범위: 관측 점 깊이 5~95 % 분위 × (0.9, 1.1). 이상점 1 %(깊이 300 m)가 섞여도 범위 26.20~34.01 m 로
  정답 분위 29.11~30.90 m 를 덮는다.
- 왜곡 보정: 긴 변 960 px 핀홀 사진(역사상 표 + 쌍선형 보간). 정답 3D 점 투영과 보정 사진 반점 무게중심 차 최대 0.0076 px.

## 수치
| 검증 | 기준 | 결과 |
|---|---|---|
| 이웃 순위: 8칸 이웃 순위 < 1칸 이웃 순위(양쪽) | 성립 | 8칸은 7·8위, 1칸은 탈락 |
| 이웃 1위 간격 | 5~9칸 (광선 각 약 9~17°) | 6칸 |
| 깊이 범위 ⊇ 정답 깊이 [q05, q95] | near ≤ q05, far ≥ q95 | 26.199 ≤ 29.110, 34.011 ≥ 30.897 |
| 깊이 범위 과대 여부 | near ≥ 0.85 q05, far ≤ 1.15 q95 | 통과 |
| 역사상 표 보간 → 역왜곡 → 출력 좌표 왕복(400점) | < 1e-3 px | 7.55e-5 px |
| 보정 사진 반점 무게중심 vs 핀홀 투영(6점, σ≈3 px, 8비트) | < 0.05 px | 0.0076 px |
| 왜곡 0 RGB 사진 축소 값 | 선형 보간과 ±1 | 통과 |

## 방법
- 합성 배치: 1600×1200, 수평 화각 70°, 연직 하방, 고도 30 m, x 방향 1 m 간격 21장. 지면 점 3000개(고도 ±1 m),
  사진 안에 투영되는 사진을 관측자로 두고 관측자 2장 이상만 남김.
- 각 기준 근거: 목표 10° 에서 가장 깊이 분해능·정합 겉모습 균형이 맞는다는 일반적 경험값. 30 m 고도 바로 아래 점에서
  10° 는 기선 약 5.3 m, 화면 가장자리 점은 거리가 길어 각이 작아지므로 1위가 5~9칸에 오는 것이 기하로 예측된다.
  1칸(1 m) 기선 각은 1.9° 이하라 아래쪽 가중치 exp(−0.5·(8.1/5)²) ≈ 0.27 이하.
- 깊이 범위 과대 기준 0.85·1.15 는 여유 10 % 에 분위 이동(이상점 1 %)분 5 % 를 더한 값.
- 왜곡 보정 시험 영상: 정규(왜곡 없는) 좌표에서 가우스 반점(출력 σ≈3 px)을 그린 왜곡 사진을 1600×1200 으로 렌더.
  출력 핀홀에서는 반점이 그대로 가우스라 무게중심 = 투영. 왜곡 k1 −0.12, k2 0.03, p1 0.001, p2 −0.0015.
- 좌표 규약: 화소 (i, j) 는 연속 좌표 (i, j) 표본. 축소 시 u' = (u + 0.5)·s − 0.5, 새 fx = fx·s.
- 측정: 4 코어 측정 기계, release.

## 남은 문제
- 축소 전 저역 통과가 없어 큰 축소비(예: 4000 → 960)에서 계단·무아레가 생길 수 있다. 상자 평균 선필터 검토.
- 보정 사진 가장자리: 배럴 왜곡에서 원본 밖으로 나가는 출력 화소는 0. 유효 영역 표시(마스크)가 필요할 수 있다.
- 이웃 점수 매개변수(10°, 5°, 15°)는 실측 비행 자료로 다시 맞춰 볼 것. 공유 점이 매우 많은 쌍이 점수를 독식하는 문제(점 수 정규화) 미검토.
- 깊이 범위는 관측 점이 없으면 (0, 0) 을 돌려준다. 호출 쪽에서 처리 필요.
