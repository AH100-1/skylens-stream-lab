# frame-tilt — 출력 좌표계 기울기와 GPS 정렬의 위 방향

## 결론
- 위 방향 추정(`up_from_rotations`)의 오차가 출력 좌표계 기울기의 큰 부분이다. 단구역 실행에서 추정 위 방향과 정답 위 방향 사이 각은 **0.473 도**, 거의 동쪽 축 둘레(+0.435 도, 북 둘레 -0.187 도)다. 정답 자세로 같은 추정을 하면 편차 0.000 도이므로 추정식 자체는 맞고, 번들 조정 뒤 회전의 편향이 그대로 위 방향에 들어온다.
- 가설(한 카메라 묶음의 기울기 편향이 위 방향을 끈다)은 **기각**. 묶음 하나를 빼도 위 방향 오차가 0.52 / 0.47 / 0.43 도(camF / camR / camL 제외)로 그대로다. 오차는 세 카메라가 함께 갖는 공통 편향이다. 켬 실행에서 camL 의 부호 평균 기울기(+0.59)가 크지만 전체 위 방향은 한 묶음이 정하지 않는다.
- `up_cross_check` 는 이 실행에서 묶음별 어긋남 0.080 / 0.076 / 0.089 도(경고 문턱 0.3 도 미만)라 아무것도 잡지 못한다. 세 묶음 모두 자기 방위가 한 방향뿐이라 자기 위 방향(`up_own`)이 없고, 묶음별 위 방향의 중앙 결합은 만들 수 없다.
- 위 방향 고정 없이 GPS 만으로 맞추기는 불가능하다: 경로 둘째 주축 폭이 `TILT_MIN_SPREAD_M` 미만이라 `align_to_enu_with` 가 `None` 을 돌려준다(GPS 잡음 2 m 에서 어차피 기울기 σ 가 수 도).
- 대안으로 희소 점의 지면 평면 법선을 써 보았다: 오차 0.370 도(동쪽 +0.248)로 약간 낫지만 장면 지형·건물 점이 섞인 근사이고 0.1 도 정도 차이라 기본에 넣을 근거가 못 된다.
- 기본 동작은 바꾸지 않았다(좋아지는 방법이 없음). 밀집 95% 재실행은 하지 않았다(좌표계 기울기가 줄지 않았으므로).

## 수치 표
단구역(`dense_caml_tail` 과 같은 설정, 등록 120/120), 출력 카메라를 GPS 에 다시 정렬하는 방식(위 방향 추정은 좌표계에 공변). 기울기는 정렬 뒤 중심을 정답 중심에 Kabsch 한 회전의 동/북/위 성분.

| 방법 | 위 방향 오차(도) | 동쪽 축 성분 | 정렬 뒤 기울기 동/북/위 (도) | camF/R/L 회전 오차 중앙(도) |
|---|---|---|---|---|
| 전체 회전 위 방향(현재 기본) | 0.473 | +0.435 | -0.435 / +0.186 / -0.142 | 0.457 / 0.259 / 0.726 |
| 희소 점 평면 법선 | 0.370 | +0.248 | -0.247 / +0.274 / -0.142 | 0.457 / 0.259 / 0.726 |
| 위 방향 고정 없음(GPS 만) | 정렬 불가(경로 폭 부족) | | | |
| 묶음별 위 방향 성분 중앙 | 불가(자기 위 방향 없음) | | | |
| 교차 검사로 튄 묶음 제외 | 해당 없음(최대 0.089 도 < 0.3 도) | | | |

묶음 하나를 뺀 위 방향 오차: camF 제외 0.523(동 +0.488), camR 제외 0.468(+0.410), camL 제외 0.425(+0.405).
카메라별 회전 오차 중앙은 위 방향만 바꾸면 변하지 않는다(Kabsch 뒤 값이라 카메라 자체의 기울기 편향은 그대로).

## 방법
- 시험 `frame_tilt`(`#[ignore]`, 약 3분)가 파이프라인을 한 번 돌려 출력 카메라와 GPS 를 얻고, 위 방향 후보별로 `align_to_enu_with` 를 다시 돌려 중심 Kabsch 로 기울기를 잰다. 정답 위 방향은 출력 좌표계에서의 정답 중심 강체 정렬의 역으로 구한다.
- 재정렬은 한 번 정렬된 좌표계에서 하므로 실제 번들 조정 좌표계에서 처음 정렬하는 것과 위 방향 추정 면에서는 같지만, 전체 기울기 0.75 도 중 이 방법으로 설명되는 것은 위 방향 오차 0.43~0.47 도까지다. 나머지(약 0.3 도)는 이 측정으로 못 가렸다.

## 남은 문제
- 위 방향 오차의 원인은 세 카메라 공통의 회전 편향이다. 카메라 F/R/L 의 고정 기울기(장비 구성)를 번들 조정 제약으로 쓰거나, 짐벌 롤 0 을 번들 조정에 넣어 회전 편향을 줄이는 쪽이 다음 단계다. 위 방향 추정만으로는 줄지 않는다.
- 전체 기울기 0.75 도 중 위 방향 오차로 설명되지 않는 약 0.3 도(파이프라인 최종 단계의 지역 정렬)는 따로 점검해야 한다.
- 평면 법선은 지형이 평평한 장면에서만 의미가 있다.
