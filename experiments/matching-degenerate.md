# 8점 퇴화 판정의 축척 불변 지표

## 결론
- 정규화 설계 행렬의 (둘째로 작은 특이값 / 가장 큰 특이값)을 퇴화 지표로 쓴다. 픽셀 크기·영상 크기와 무관하다.
- 잡음 σ 0, 0.5, 1 px 의 동일선상·평면 배치는 모두 문턱 3.5e-3 아래, 일반 배치와 편대 장면(건물 10%)은 모두 위다.
- 기존 1e-10(특이값 비로 1e-5) 문턱은 잡음 있는 퇴화를 못 잡았다. 새 지표는 진단으로만 공개하고 8점 풀이·RANSAC 의 거부 규칙은 바꾸지 않았다(평면 짝은 호모그래피 선택·평면 표시 경로가 처리). 평면·편대 장면의 정상 짝 수와 평면 표시는 전과 같다.

## 수치 표
지표 = 특이값 비(시드 1~5, 점 200개, 동일선상은 60개). 문턱 3.5e-3.

| σ (px) | 동일선상 최대 | 평면 최대 | 일반 배치 최소 | 편대(건물 10%) 최소 |
|---|---|---|---|---|
| 0 | 0 | 8.7e-9 | 2.58e-2 | 4.91e-3 |
| 0.5 | 8.9e-4 | 1.10e-3 | 2.60e-2 | 5.02e-3 |
| 1.0 | 1.79e-3 | 2.20e-3 | 2.63e-2 | 5.38e-3 |

정상 짝 수(σ 0.5 px, 시드 1/2/3), 지표 추가 전 → 후 동일:

| 장면 | 정상 짝 수 | 평면 표시 |
|---|---|---|
| 평면 z=0, 200점 | 200/200/200 | 예 |
| 편대 F 4칸 지면, 300점 | 300/300/300 | 예 |
| 편대 F 4칸 건물 10% | 299/300/300 | 아니오 |
| 편대 R 1칸 지면 | 300/299/300 | 예 |

## 방법
정규화(Hartley) 좌표로 AᵀA 를 만들어 고윳값을 정렬하고 sqrt(λ2/λ9)를 지표로 한다. 퇴화 시 영공간이 2차원 이상이라 λ2 가 0 으로 간다. 잡음이 있으면 λ2 가 (σ/스케일)² 수준으로 오르지만 일반 배치의 값보다 한 자릿수 이상 작아 문턱이 갈린다.

## 남은 문제
- 편대 장면에서 건물 비율이 더 낮으면(5% 이하) 지표가 문턱에 가까워진다. 이 경우는 건물 점이 소수라 판정이 맞지만, 거부에 쓰려면 지면+건물 짝의 정상 짝을 지키는 별도 검토가 필요하다.
- 8점 최소 표본(8점)에는 이 지표를 쓰지 않았다(표본이 작아 값 분포가 다르다).
- 지표를 호출하는 곳은 아직 없다(진단 공개만).
