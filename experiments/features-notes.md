# T03 features 보충 — 회전·축척·잡음에서 재검출률과 기술자 매칭

## 결론
- DoG 검출기와 128차원 기술자는 회전·축척·잡음에 대해 쓸 만하게 버틴다. 회전 15~45°에서 재검출률 0.87~0.88, 축척 1.25~2에서 0.83~0.89, 비율 0.8 최근접 매칭의 정밀도는 모든 조건에서 0.975 이상이다.
- 회전 90°(0.986)와 회전 0(1.000)이 높은 것은 이 와핑이 화소 격자에 정확히 맞아 보간 흐림이 없기 때문이다. 15·30·45°의 0.87 근처 하락은 대부분 쌍선형 보간 흐림과 격자 재표본화의 몫으로 본다(검출기의 방향 의존성과는 이 측정만으로 구분하지 못함).
- 축척 1.5 가 가장 낮다(재검출 0.830, 매칭 재현 0.790). 축척 2 는 정확히 한 옥타브 차이라 DoG 층이 그대로 겹쳐 오히려 0.887 이다. 옥타브당 3층(s=3) 사이 중간 축척에서 극값 위치·층 선택이 흔들리는 것으로 보인다.
- 잡음은 σ=0.02(밝기 [0,1])까지 재검출 0.86 이상, σ=0.05 에서 0.709 로 떨어진다. 매칭 정밀도는 σ=0.05 에서도 0.985. 대비 문턱(contrast 0.01)이 잡음 σ 에 비해 낮아 잡음 극값이 섞이는 것이 원인 후보다.
- 시간: 960×540 한 장 검출+기술 약 0.5~1.2 s (4 코어 측정 기계, 동시 부하 있음). 특징 수 3700~4100 개.
- 제품 코드 변경 없음.

## 수치 표
합성 장면 기본 설정(960×540, 수평 화각 70°)에서 세 장(camF_0000, camR_0010, camL_0040)을 렌더해 합산했다. 영상 잡음 σ 는 [0,1] 밝기 단위 가우시안.

- 유효 위치: 원본 특징점(같은 위치 여러 방향은 하나로)을 정답 사상으로 옮겼을 때 변환 영상 안쪽 10 px 여백 안에 드는 것.
- 재검출률: 유효 위치 중 변환 영상 특징점이 정답 대응 위치 2 px 이내에 있는 비율.
- 매칭: 유효한 원본 특징마다 변환 영상 특징 전체에서 기술자 L2 최근접, 거리 비 < 0.8 이면 채택. 채택된 상대 특징점이 정답 위치 2 px 이내면 정답.
- 정밀도 = 정답/채택, 재현 = 정답/유효 특징 수(방향별로 셈).

## 방법
- 정답 대응은 알려진 2D 닮음 변환으로 만든다: 영상 중심 c 에 대해 dst = c + s·R(θ)(src − c). 변환 영상은 역사상 + 쌍선형 보간으로 만들고, 원본 밖은 0.5 로 채운 뒤 가우시안 잡음(σ)을 더하고 [0,1] 로 자른다(난수 splitmix64 + Box–Muller, 고정 씨앗).
- 원본은 `Scene::new(SceneConfig::default())` 의 `views[0]`, `views[31]`, `views[122]` 를 `render` 해서 `GrayImage::from_rgb` 로 바꿨다. 양쪽 모두 `detect_and_describe(&img, &DetectorConfig::default())`.
- 원본 특징점을 정답 사상으로 옮겨 여백 10 px 안쪽인 것만 센다. 재검출은 위치 단위(같은 위치 여러 방향 중복 제거), 매칭은 특징 단위. 최근접은 128차원 L2 전수 비교, 비율 0.8(거리 기준).
- 측정 코드는 제품 저장소 origin/main 작업 트리에 임시 예제(`crates/core/examples/feat_eval.rs`, 커밋하지 않음)로 두고 `cargo run --release --example feat_eval` 로 돌렸다. 시간은 변환 영상 한 장의 `detect_and_describe` 벽시계 시간 세 장 평균.

## 남은 문제
- 회전 15~45° 하락에서 보간 흐림 몫과 검출기 몫을 나누려면, 같은 장면을 카메라 롤만 바꿔 다시 렌더해 3D 정답 투영으로 대응을 만드는 측정이 필요하다(이번에는 2D 와핑만 했다).
- 축척 1.5 근처 약점: 옥타브당 층 수(scales 3→4)나 부스케일 정밀화 범위를 바꿔 다시 잴 것.
- 잡음 σ=0.05 대비 문턱: contrast 를 잡음 수준에 맞춰 올리는 설정(예: 0.02~0.03)의 재검출·특징 수 맞교환을 아직 재지 않았다.
- 카메라 시점 변화(원근 왜곡, 가림)가 있는 실제 인접 시점 쌍의 재검출률은 이번 표에 없다(기존 노트의 1칸 이웃 매칭 정밀도 0.984 만 있음).
- 시간은 한 장 약 1 s 로, 다중 스레드 분할이나 옥타브 병렬화 여지를 따로 재지 않았다.
