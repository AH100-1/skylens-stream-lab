# 2구역 합성 장면 초벌↔정밀 높이 차 (pipeline-two-region-height)

## 결론
- height2 상태(광선 각 20도)에서 2구역(`--stride 1 --span 48`, 240장)은 verify 5/7, 높이 차 중앙 최대 6.278 m(최근접 5.946 m)였다. 단구역에서 얻은 개선이 2구역에서는 거의 나타나지 않았다.
- 원인 하나는 확인했다. 초벌 점군의 광선 각 거름에는 "남는 점이 200개 미만이면 거르지 않는다"는 하한이 있었는데, 2구역의 구역 0(50 위치)은 희소 점 1310개 중 광선 각 20도 이상이 84개뿐이라 거름이 통째로 꺼져 있었다(구역 1도 1442개 중 119개). 단구역(40 위치)은 2746개 중 509개라 거름이 적용됐다. 하한을 50으로 낮추면 2구역 높이 차가 6.278 → 3.469 m, 최근접 5.946 → 3.168 m 로 줄고 단구역 7/7 은 유지된다. 그래도 기준(2 m)에는 못 미쳐 2구역은 5/7 그대로다.
- 정렬 점쌍에도 같은 거름을 쓰는 안은 효과가 없고 해로웠다: 구역 0 점쌍이 1310 → 84 로 줄어 단구역에서 preview_align(점쌍 ≥ 1000)이 509 로 떨어져 6/7 이 되고, 2구역 높이 차는 5.773 m 로 거의 그대로였다. 채택하지 않았다.
- 남은 높이 차의 큰 부분은 정렬 변환 자체다. 구역 0 초벌은 자기 정밀 모델과의 정렬에서 잔차 중앙 5.130 m, 스케일 0.940 이고 구역 1 은 2.735 m, 1.017 이다(둘 다 희소 점 전체 사용). 반대로 구역 0 초벌을 구역 1 정밀 모델에 맞추면 잔차 0.179 m 로 훨씬 작다.

## 방법
README 의 합성 명령(`synth scene 320 180`, 구역 2개는 `run scene out2 --stride 1 --span 48 --ovl 2 --max-features 800 --dense-width 96 --hfov 65 --ba-iters 15`, 단구역은 `--stride 2`)을 한 번씩 돌려 출력 폴더와 로그를 남기고 재사용했다. 구역별 값은 `preview/*.ply`·`refined/*.ply` 를 읽어 verify 와 같은 정의로 따로 계산했다(전체 verify 값과 구역 1 값 6.278 m 이 일치). 후보는 (a) 정렬용 트랙에 광선 각 20도 거름, (b) 초벌 점군 거름의 최소 점 수 하한 200 → 50 두 가지다.

## 남은 문제
- 2구역은 아직 5/7: 높이 차 3.469 m (기준 2 m), preview_align 은 점쌍 최소 324 (기준 1000)와 구역 0 잔차 5.130 m 가 문제다. 점쌍 기준 1000 은 구역이 짧거나 겹침 창이 좁은 경우 구조적으로 못 맞출 수 있어, 기준을 위치 수에 비례시킬지는 별도 판단이 필요하다(README·cli 시험 기대 판정은 이 묶음에서 고치지 않았다. 필요하면 2구역 시험의 높이 차 단언은 3.5 m 미만 정도로, 판정 5/7 은 그대로다).
- 정렬 점쌍은 희소 점 전체(좁은 각 포함)라 잔차가 크다. 광선 각을 거르면 점쌍이 모자란다. 점쌍을 늘리면서(구역 간 겹침 창 확대, 밀집 점 사용) 좁은 각 점을 가중으로 낮추는 방법이 다음 후보다.
- 구역 0 초벌의 부호가 하한 변경 뒤 +1.8 → -2.5 m 로 뒤집혔다. 절대값은 줄었지만 정렬 변환 편향이 남았다는 신호다.
