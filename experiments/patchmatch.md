# T10b patchmatch — 시점별 경사 평면 PatchMatch 깊이·법선

## 추가 절: 거친 층 이웃 축소 (F-048 일부)

### 결론
목표(960×540 이웃 8장 한 장 ≤ 1 s)는 이번에도 달성하지 못했다. 체커보드 병렬 전파, 창 표본 간격, 저해상도 다단계(240 폭 시작)는
이미 들어 있어 측정만 했고, 새로 거친 층(폭 240)에서 첫 반복만 이웃 8장을 쓰고 이후는 비용이 낮은 4장만 쓰게 했다.
시간 이득은 부하 때문에 분리하기 어렵다(거친 층 전파·정련 17.6 s → 14.7 s, 부하 평균 약 17~18). 편대 지면 시험은 통과를 유지했다.
반복 수를 줄이면 더 빠르지만 법선이 무너진다(반복 2: 법선 중앙 5.71°). 경사 평면·계단 두 시험은 여전히 `#[ignore]`.

### 방법
- 거친 층 반복 1회 뒤 `eval_all` 로 이웃별 비용을 다시 재서 낮은 4장만 마스크로 남기고 나머지 반복을 돈다(`Config::coarse_neighbors`, 0 이면 끔).
- 반복 번호와 층 전체 반복 수를 `Sched` 에 따로 두어 섭동 척도·난수가 나뉜 호출에서도 이어지게 했다.

### 남은 문제
- 거친 층이 총 시간의 60~70%. 가설 수(무작위 1 + 섭동 9)와 이웃 4장 비용이 그대로라 1 s 에는 한 자릿수 배 더 줄여야 한다.
- 가설 비용 조기 중단(상위 k 평균은 하한이 약해 효과가 작음), 기준 창 평균·분산 캐시, 행 단위 호모그래피 증분은 미착수.
- 부하가 높아 시간 비교의 오차가 크다. 조용한 기계에서 1 스레드/4 스레드 재측정 필요.

## 방법
- 좌표: 화소 (i, j) 중심 = 연속 좌표 (i + 0.5, j + 0.5), `camera` 와 같은 규약. 광선은 K⁻¹(i+0.5, j+0.5, 1),
  이웃 투영 결과는 −0.5 해서 쌍선형 표본. 반 크기 층은 K 의 fx, cx 를 그대로 절반으로(규약 덕분에 보정 항 없음).
  시험 렌더러도 같은 규약으로 고쳤다.
- 값 범위: 시점마다 유한 값의 최소·최대로 0~1 정규화. `sigma_color` 는 정규화 단위. `features::GrayImage` 에서 변환(`From`).
- 피라미드: 너비 ≥ 2×240 이면 2×2 평균으로 반. 가장 거친 층에서 무작위 초기화 + 6회, 위 층은 평면을 옮겨
  (같은 평면 nᵀX = c 를 고운 광선으로 교차) 1회씩, 섭동 1단계만.
- 창: 오프셋 −4..=4 간격 2(25 표본, 중심 포함). 공간 가중 표 + 밝기 차 1024 칸 표, 화소마다 그 자리에서 정규화.
- 호모그래피: 창 중심에서 H·q 한 번, 표본마다 dx·H₀ + dy·H₁ 더하기.
- 이웃 비용: 고정 버퍼, 정렬 대신 k 번째 선택. 이웃은 앞에서부터 최대 8장.
- 무효: 이웃 없음·질감 없음·NaN·투영 밖·범위 오류 → 깊이 0, 법선 0, 비용 2.
- 범위 검사: 유한하고 0 < 최소 < 최대 아니면 전부 무효. 창에 NaN 이 있으면 그 화소 무효.
- 편대 지면 장면: 고도 30 m, 북쪽 진행, 60° 내려다봄, 수평 화각 65°, 기준 위치 0 과 같은 카메라 위치 ±4, ±8 m.
