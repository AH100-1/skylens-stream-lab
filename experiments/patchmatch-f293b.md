# 회차: 건너뜀 실제 비율 진단과 비용 기반 섭동 폭 대안 (2026-10-03, 4 코어 측정 기계)

## 결론
- 건너뜀은 960×540 에서 실제로 작동한다: skip_cost 0.08 일 때 고운 층 L2·L1·L0 에서 방문 화소의 85.5%·89.7%·92.4% 를 건너뛴다(가장 거친 층은 0). 반면 192×108 에서는 층이 하나뿐(거친 층 = 원 해상도)이라 건너뜀이 0% 이다. F-293 의 "192 px 에서 skip 0·0.08 결과 동일" 은 건너뜀이 작동하지 않은 입력이었기 때문이다(깊이 너비 192 의 피라미드가 한 층). 따라서 192 px 흐름 표는 건너뜀의 근거가 될 수 없고, 960 px 단독 표가 유효한 비교다.
- 새 방식(비용 기반 섭동 폭, 건너뜀 없음)을 설정 항목 cost_adaptive·adaptive_fewer 로 추가했다. 폭만 바꾸면(cost_adaptive) 정확도는 건너뜀 0 과 같거나 약간 낫지만(1% 이내 98.5%, 법선 2.61°) 시간은 줄지 않는다. 좋은 화소(비용 ≤ 0.6)의 시도 후보를 단계당 3 → 1 로 줄이면(adaptive_fewer) CPU 가 건너뜀 0 보다 약 20% 적고 정확도는 거의 유지(98.5%, 2.90°)된다. 그러나 현재 기본값 skip 0.08 보다는 CPU 가 42% 더 든다(2.02 s 대 1.42 s).
- 기본값은 바꾸지 않았다(둘 다 끔). skip 0.08 과 같은 속도에서 정확도를 지키는 방식은 이번에 찾지 못했다.

## 방법
- 진단: 화소 갱신 함수에 반쪽 한 줄 단위 지역 계수(방문·건너뜀·저비용)를 두고 줄 끝에 원자 합산, 층마다 profile 출력에 비율을 덧붙임. 시험 skip_count_diag(--ignored).
- 새 방식: 화소의 현재 비용(1−NCC 집계)이 ≤0.6 이면 시작 폭 ×1/4, ≤0.8 이면 ×1/2, 그 밖 ×1. 기준 폭은 깊이 ±0.3%, 법선 ±16°(첫 단계)·±10° 상당(성분 0.28 / 0.175). 후보가 비용을 개선하면 그 화소의 폭을 반으로. 비용 ≥ 0.9 인 이웃에서는 전파받지 않음(고운 층 기존 문턱). 가장 거친 층은 기존 일정(160×120 시험에서 거친 층까지 좁히면 법선 중앙 22.9°, 1% 이내 63% 로 무너져 제외). adaptive_fewer 는 비용 ≤ 0.6 화소의 단계당 후보를 (깊이+법선 동시) 하나로 줄이되 시도를 생략하지는 않는다.
- 비교 시험 ab_good_960(--ignored), 단위 시험 fast_cost_adaptive_slanted(160×120, 중앙 0.5% 미만·1% 이내 90% 초과·법선 5° 미만).

## 남은 문제
- 법선 ±16°/±10° 해석(성분 진폭 0.28/0.175)은 근사다. 후보 수 6 → 3 은 고운 층 단계 수가 1 이라 후보 3 → 1 로 대응시켰다.
- 부하 평균이 20 대라 벽시계 값은 참고용. 부하가 낮은 기계에서 재측정 필요(F-292).
- skip 0.08 급 속도에서 정확도를 지키려면 질감 없는 화소 제외나 층 수 조정 등 다른 방법이 필요.
- 192 px 흐름에서 건너뜀을 보려면 깊이 너비가 최소 480 이상이어야 한다.
