# 구역 2개 이상 끝까지 잇기 시험 (F-273)

## 결론

- 현재 main(4825669)에서는 README 명령(stride 1, span 48, BA 15회)도, 인자 없는 기본 경로(구역 3개)도 verify 7/7 이다. F-273 에 적힌 높이 차 2.994 m·정렬 잔차 3.867 m 는 오래된 main 의 값이고 지금은 재현되지 않는다(아래 표).
- 구역 ≥ 2 에서 `refined_overlap`·`preview_align`·`preview_vs_refined` 를 '해당 없음' 없이 판정하고 verify 기준 상수(겹침 < 0.3 m, 높이 차 < 2 m, 최근접 < 3 m, 정렬 잔차 < 6 m, 점쌍 ≥ 1000, 스케일 차 ≤ 10%)로 상한을 건다. 실측 × 여유가 아니다.
- BA 반복 10회와 15회의 차이는 이 장면에서 겹침 0.005 m, 높이 차 0.004 m 로 사실상 없다. 반복을 늘리면 초벌↔정밀 차가 커진다는 경향은 관찰되지 않았다.

## 방법

- 기존 시험 확인: `pipeline_e2e.rs` 는 README 명령으로 구역 2개를 이미 판정했으나 BA 15회만이었고, 스케일 차 상한을 SPEC(10%)이 아닌 1%로 걸었다. `default_path.rs` 는 구역 3개에서 PASS 문자열만 보고 겹침 쌍 수·정렬 잔차·높이 차는 단언하지 않았다.
- 바꾼 것: 구역 2개 단언을 함수 하나로 묶어 상수로 바꾸고 BA 10회 시험을 추가했다. 기본 경로 시험에는 겹침 쌍 수 = 구역 수 − 1, 정렬 기록 수 = 구역 수, 위 상한을 추가했다. README 표를 7/7 과 위 수치로 고쳤다.
- 수치는 `skylens-stream` 을 직접 돌려 얻었다(synth → run → verify).

## 남은 문제

- 기본 경로의 구역 간 스케일 차가 5.77% 로 상한 10% 에 가깝다. 상한은 SPEC 값이라 그대로 두었고, 이 값이 커지면 시험이 먼저 알린다.
- BA 반복 10/15 의 차이가 작아 경향 자체는 더 큰 장면에서 봐야 한다.
- 시험 시간이 길다(구역 2개 시험 하나가 부하 상태에서 6 분 안팎).
