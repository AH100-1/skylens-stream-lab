# 초벌 카메라 위치 다듬기 (pipeline-preview-pos)

## 결론

- 초벌 포즈 뒤, 삼각측량 앞에 회전 고정·중심 전용 다듬기(번들 조정 아님)를 넣으면 2구역 stride 1 의 초벌↔정밀 높이 차 중앙이 4.715 m → 1.055 m 로 내려가 SPEC 기준(< 2 m)을 채우고 verify 7/7 이 된다. 단구역(stride 1, 구역 1개)도 4.735 m → 0.266 m, 7/7.
- 다듬기 자체는 2구역 합쳐 0.06 s(호출 2회). 총 시간 변화는 측정 기계 부하 변동에 묻혔다(아래 참고).
- 근거가 있어 기본 켬(5회), `--preview-refine-iters 0` 으로 끈다.

## 방법

회전을 고정하고 길이 3 이상 트랙(긴 것 우선, 4000 개)을 쓴다. 점은 현재 중심에서 광선 교차로 삼각측량(최대 삼각측량각 < 1° 점 제외), 카메라별로 점–카메라 광선 수직 잔차의 3x3 정규방정식으로 중심 갱신(각 잔차 Huber 0.3°, 1/깊이² 가중, 시작 위치로 당기는 약한 항 0.02), 5바퀴 교대. 두 번째 바퀴부터 각도 잔차 > 2° 관측 제거. 합성 입력의 단위 시험 하나(중심 잡음 감소)를 넣었다.

## 남은 문제

- 정답 대비 초벌 중심 중앙/최대(닮음 맞춘 뒤)는 시간이 부족해 재지 못했다. 공통 회전 하나를 뺀 높이 차도 못 쟀다(요청 사항). 파라미터(Huber, 바퀴 수, 당김 항)는 한 설정만 시험.
- 같은 기준에서 비교한 시간은 부하 없는 기계에서 다시 재야 한다.
- translation-averaging 위치 방식과의 조합은 시험하지 않았다(해당 방식 실행이 매우 느림).
