# 초벌 위치 추정을 위치 평균으로 바꾸기 (pipeline-ta)

## 결론
- 초벌 단계의 위치 추정을 선택 가능하게 연결했다. 설정 `position`: `GpsLeastSquares`(기존, 기본값) / `TranslationAveraging`(짝 방향 + 트랙 점 방향 제약 + 강건 재가중, 축척·원점만 GPS 로 맞춤).
- 위치 평균 쪽 측정은 마감까지 끝나지 못했다(부하 평균 10~20 인 4 코어 측정 기계에서 단구역 40위치 시험이 10분 넘게 걸림). 그래서 기본값은 기존 방식으로 둔다. 개선이 확인되면 기본값만 바꾸면 된다.
- 감독 지시(잔차·높이 차 감소 확인)는 아직 확인되지 않았다.

## 방법
회전 평균 결과(세계→카메라)와 짝 상대 이동 방향, 길이 3 이상 트랙 상위 3000개의 관측 방향을 `average_translations_with_points` 에 넣는다. 얻은 중심을 기존 좌표 맞춤 회전 g 로 돌린 뒤 축척과 이동만 GPS 에 강건하게(중앙 잔차 3배 문턱 반복) 맞춘다. 실패하면 기존 방식으로 되돌아간다. 시험은 환경 변수 PIPE_POSITION=ta 로 선택.

## 남은 문제
