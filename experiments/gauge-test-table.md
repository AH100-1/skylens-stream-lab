# 게이지 분리 시험 표 정리 (F-450)

## 결론
- 시험 위 주석이 변형 3개라 적었으나 실제 변형은 4개(기존 시작, 기존+sim3, 고정 정답, 고정 정답+sim3). 주석을 4개로 맞췄다.
- 닮음(sim3) 맞춤 두 변형은 맞춤이 오차를 키워 보이게 하므로(시작 행도 0.17 에서 0.48 로 커짐) 판정 근거가 못 된다. 표를 '판정 행'(맞춤 없음 두 변형)과 '참고용(판정에 안 씀)' 두 묶음으로 나눠 찍는다.
- 이 시험은 무시 시험이고 단언이 없다. 따라서 참고용 행이 단언에 쓰이는 일은 없다. 단언을 새로 넣지는 않았다.
