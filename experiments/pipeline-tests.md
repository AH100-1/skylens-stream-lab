## 결론
시험을 README 명령과 같은 설정(특징 800, 깊이 폭 96, 화각 65도, BA 15회)으로 맞추고 두 가지로 나눴다: 단일 구역(stride 2, 위치 40곳)과
구역 2개(stride 1, 위치 80곳, span 48). 두 번째 설정에서 이웃 겹침(refined_overlap)이 처음으로 실제 판정되었고 크게 실패한다
