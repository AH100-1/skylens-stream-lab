# matching-followup — 실측 편대 짝 일정의 회전 오차, LM 종료 사유

## 결론
- F-148(매칭 쪽): 실측 편대 배치(`SceneConfig::default()`, 시드 1, 480×270)의 SPEC 짝 일정에서 매칭·F RANSAC 이 확정한 간선 21개 중 5개가 상대 회전 오차 2° 를 넘는다. 틀린 간선은 **모두 같은 카메라 짝**(4칸 2, 5칸 2, 16칸 1)이고, 다른 카메라 ±4 위치 짝 27개는 하나도 확정되지 않았다(겹침 없는 짝 통과는 이 배치에서 원인이 아님). 원인(F 자체 오류인지, F→E→자세 분해 쪽인지)은 아직 분리하지 못했다. 시험 `formation_pair_schedule_rotation_errors` 는 5% 기준으로 실패하므로 이유를 달고 무시 상태로 두었다.
- F-139: Sampson LM 종료 사유(수렴/정체/상한)를 시험용으로 따로 기록. 4000 대응 시험에서 호출 31회 중 수렴 20, 정체 10(첫 걸음 정체 0), 상한 1. 시험은 수렴 과반·첫 걸음 정체 0 을 단언한다.
- F-150(matching.rs 쪽): `ransac_on_synthetic_drone_views` 상수 주석을 같은 커밋의 출력(정상 504~703, 정밀도 0.991~1.000, 재현율 1.000)으로 고쳤다. 기준 400 은 최솟값의 약 79%.
- F-091·F-093·F-120: main(1d79e0f) 에 이미 해당 시험이 있다(`line_plus_few_general_points_is_not_confirmed`, `ratio_match_rounding_boundary`·`ratio_match_ties_take_lower_index`, `homography_support_finds_plane_among_outliers`). 이번에 새로 바꾼 것은 없다. 변이 확인 표는 이번에 다시 만들지 못했다.

## 방법
- 각 짝: 480×270 렌더 → 특징 → `ratio_match(0.8, 상호)` → `ransac_fundamental(기본 설정)` → E = K₂ᵀFK₁ → 정상 짝 정규 좌표로 `recover_pose` → 정답 R_b R_aᵀ 와의 각 차. 기준 위치 8, 같은 카메라는 8→8+간격, 다른 카메라는 8→8+d.
- LM: `refine_sampson` 이 반복마다 걸음을 받아들였는지(accepted)와 상대 감소(> 1e-10)를 구분해, 받아들인 뒤 감소가 작으면 수렴, 감쇠 8단계 모두 실패면 정체, 반복을 다 쓰면 상한.

## 남은 문제
- F-148: 4·5·16칸 같은 카메라 짝의 틀린 회전 원인 분리(F 의 떼어 둔 정답 대응 Sampson 오차 vs recover_pose 의 후보 선택). 지면 위주 장면에서 4~5 m 기선의 평면 쌍둥이(F-144) 가능성이 높다 — `select_two_view_model` 결과를 같은 표에 붙여 볼 것. bench 재측정 미완. 다른 카메라 짝이 하나도 확정되지 않는 것이 정상인지(겹침 없음) 겹침 정답으로 확인 필요.
- F-141(시차 짝 훑기), F-142(RANSAC 반환에 평면 표시), F-003(평면 장면 호출 경로) 이번에 손대지 못함 — 마감.
- F-139 확인 기준의 '종료 규칙을 끈 판에서 실패' 변이 실험 미실시.
- 시험 시간: 부하 상태 측정 기계에서 matching 시험 묶음 248 s. 전체 시험에서 `two_view::five_point_terminates_on_many_seeds`(시간 단언, 최악 호출 135 ms)가 부하로 실패했고 단독 재실행에서 통과(0.50 s).
