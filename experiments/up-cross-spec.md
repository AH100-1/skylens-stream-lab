# 위 방향 교차 차 문턱의 문서화 (up-cross-spec)

## 결론
- SPEC §4 표에 여덟째 항목(구역별 정밀 모델 위 방향 교차 차: 실패 > 10°, 경고 > 0.3°)을 추가했다.
- 제품 검증 코드의 모듈 문서 항목 수를 여덟으로 맞추고, 경고 문턱은 정렬 모듈의 상수 하나를 가져다 쓰도록 모았다(중복 정의 제거). 동작 변화 없음.

## 수치 표
| 근거 | 구역별 최대 어긋남 |
|---|---|
| 시드 1/2/3 정상 실행 | 1.449° 이하 |
| 시드 4 구역 0/1/2 | 0.559 / 1.477 / 2.135° |
| 한 기체 짐벌 구름 1~2° 장면 | 1.1~1.3° |
| 회전이 틀린 묶음 | 47° 이상 (시드 3 구역 0 최대 69.5°) |

- 실패 10° 는 정상 최대의 약 5~7배, 고장의 1/4 이하. 경고 0.3° 는 구름 1° 이상을 모든 시드에서 잡지만 정상 실행도 넘을 수 있어 경고(통과)만.
- 경계 시험: 0.29999 / 0.3 은 경고 없음, 0.30001 경고, 10.0 은 경고로 통과, 10.00001 실패.

## 방법
verify.rs 의 실제 판정(`> 10` 실패, `> 0.3` 경고, 값이 모두 null 이면 측정값 없음, 항목이 없으면 건너뜀)을 읽고 SPEC 줄을 맞췄다.

## 남은 문제
- 정상 실행의 구역별 최대가 경고 문턱을 넘는 일이 흔하다(시드 4 의 세 구역 중 두 곳 이상). 경고가 정보로서 변별력이 있는지는 별도로 볼 것.

## 제품 브랜치·커밋
feat/up-cross-spec, 커밋은 보고에 기재.
