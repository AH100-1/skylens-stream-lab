# 롤 문턱 표의 장면 설명과 롤 오차 정의 바로잡기

## 결론

- 선택 규칙과 문턱(0.95)은 그대로다. 시험 `choose_roll_tests::bank_sweep_table` 의 주석과 노트를 코드에 맞게 고쳤다.
- 장면 설명: 광축 흩어짐은 "±3°" 가 아니라 기울기 bank 를 중심으로 -6°~+6°(3° 간격 5단계)다(코드 `((i % 5) - 2) × 3°`). 비행 축 길이도 300 m 가 아니라 0~270 m(30 m 간격 10단계)로 적었다. 코드는 바꾸지 않았다.
- 오차 정의: 기존 표의 '롤 오차' 는 후보 회전 전체의 회전각이었다. 이제 전체 회전각과 비행 축(x) 둘레 성분(순수 롤)을 따로 낸다. 기존 전체 회전각 수치는 재측정에서 한 자리도 바뀌지 않았다.
- 새로 보인 점: GPS 해 오차는 거의 롤 몫이다(잡음 2.4 m, 폭 12 m 의 전체 4.260° 중 x축 롤 4.224°). 퍼짐 해는 기울기 bank 와 같은 롤 오차를 가진다(4°→4.000°). 문턱 판단에는 기존 전체 회전각 표로도 결론이 달라지지 않는다.

## 수치 표

4 코어 측정 기계, 같은 시험 출력(조건당 200회, 잡음 0 은 1회). 전체 = 후보 회전의 회전각, x축 롤 = 비행 축 둘레 성분. 단위 도. 일부 조건만 옮긴다(나머지는 `roll-gps-scene.md` 표와 시험 출력).

## 방법

- 시험 보조 코드만 바꿨다. `SweepRow` 에 x축 롤 세 필드를 더하고, 정답이 항등이므로 `UnitQuaternion` 의 비틀림 `2·atan2(i, |w|)` 를 비행 축(x) 둘레 롤로 썼다. 출력 머리말에 두 오차 묶음을 구분해 적었다.
- 시험의 단언(기울기 0° 에서 GPS 승 0·최소 비 > 0.95, 폭 120 m·기울기 4°·잡음 2.4 m 에서 GPS 승 200, 잡음 0 에서 선택 오차 < 1e-6)은 전체 회전각 기준 그대로 둔다. 4개 시험 통과.
- `roll-gps-scene.md` 의 수치 표 머리말과 방법 문장을 코드에 맞게 고치고 x축 롤 열을 더했다.

## 남은 문제

- '틀림' 은 전체 회전각 기준이다. 롤 성분만으로 다시 세면 달라질 수 있으나 세지 않았다.
- 문턱을 다시 정하려면 롤 성분 기준 틀림 열이 필요할 수 있다.
