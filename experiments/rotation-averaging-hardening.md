# 회전 평균 다듬기 (F-006~F-009)

## 결론
- 이상치 문턱을 잔차 분포에서 정한다: 문턱 = max(5°, 6·σ̂), σ̂ = 중앙값(잔차)/1.5382. 기본 설정 그대로 σ 0.5/1/2° 와 σ 1°+이상치 10% 에서 오거부 ≤ 1%, 이상치 놓침 0. (F-009)
- 강건 단계는 변화량 1e-4 rad 또는 정상 집합 두 번 연속 불변이면 멈춘다. 반복 50 → 3~10. (F-008)
- **σ 2° 에서 기준 해와 2~3e-2 rad 어긋나던 것은 국소 해가 아니라 정상 집합 불일치였다.** 최소제곱에 넣는 간선은 강건 단계(조기 종료) 잔차로 골랐는데, 돌려주는 정상 표시는 최소제곱 뒤 잔차로 다시 매겼다. σ 2° 는 문턱(9.35~9.45°) 근처 간선이 있어 두 집합이 갈렸고, 기준 해는 "돌려준 정상 표시" 집합으로 풀었으니 다른 문제를 푼 셈이었다. 초기화·가우스–자이델 자체의 문제는 아니고, 이상치 문턱 적응 + 강건 단계 조기 종료의 조합이 원인.
- 고침: 최소제곱 → 최종 잔차로 정상 집합 재선정 → 바뀌었으면 다시 최소제곱, 최대 8회. 이제 σ 0.5/1/2°·이상치 10% 모두 기준 해와 정점별 최대 차 ≤ 1.1e-11 rad, 정상 집합 비용도 유효숫자 10자리까지 같다. 시험은 σ 2° 까지 1e-6 rad 단언. (F-006)
- 정규 방정식은 간선별 3×3 블록 희소 + 블록 야코비 켤레 기울기. 밀집 촐레스키와 1단계 차 ≤ 6e-14 rad(240·1000 정점), 시험은 1e-9 단언. 2000 정점·7990 간선 전체 0.46~0.67 s(단독·직렬 측정). (F-007)

밀집 2000 은 한 번만 따로 쟀다(84.8 s). 희소-밀집 차는 수렴 해를 0.02 rad 흔든 출발점에서 한 단계 비교. 240 장면 그래프(간선 942)에서는 1단계 4.3e-15, 10단계 3.9e-14 rad.
저장량은 행렬 블록만 센 값: 희소 = (대각 블록 m + 비대각 블록 = 정상 간선 수) × 72 바이트, 밀집 = (3m)² × 8 바이트, m = 정점 − 1.

## 방법
- 잡음 모델: 간선 회전 = exp(축당 σ 정규) · 정답. 각 크기는 자유도 3 카이 분포(평균 1.596σ, 중앙값 1.5382σ).
- 정확도 기준 근거: 선형화 정보 행렬 H(가중 1, 기준 정점 0 고정)에서 정점 블록 대각합 평균의 제곱근 = 1.927 → 예측 정점 RMS 1.927σ. 세계 회전 정렬은 기준 정점 고정보다 오차를 줄이므로 RMS < 예측 을 단언. 평균 < 1.5σ 는 그 아래 별도 상한으로 유지(실측 1.06~1.24σ). 전역 최적 여부는 기준 해 비교(1e-6 rad)로 직접 확인.
- 국소 해 여부 판별: 같은 정상 집합에서 추정 해와 기준 해의 비용 Σ|log(R_j R_iᵀ R_ijᵀ)|² 을 나란히 출력. 고친 뒤 모든 경우 같은 값 → 같은 최소점. 고치기 전 σ 2° 차이는 비교한 두 해가 서로 다른 간선 집합의 최소점이라 생긴 것.
- 정상 집합 재선정: 문턱은 강건 단계 잔차로 한 번 정하고 고정, 집합만 다시 고른다. 최대 8회, 시험 장면에서는 1~2회로 멈춘다.
- 문턱 계수 6: 4.5 로 두면 σ 2° 에서 오거부 15(1.6%). 6 이면 0. 카이(3) 꼬리 P(>6σ) ≈ 1e-7.
- 하한 5°: 3° 로 두면 다수결 초기화 일치 문턱도 3° 가 되어 σ 1°+이상치 시드 5 에서 초기화가 깨졌다(최대 162°).
- 희소 풀이: H 를 대각 블록(정점별)과 간선별 비대각 블록으로 저장, 블록 야코비 전처리 켤레 기울기(상대 잔차 1e-14 까지). 밀집 풀이는 시험 전용으로 남겨 비교.

## 남은 문제
- 2000 정점 1초: 단독 측정 0.46~0.67 s 로 목표 안이지만 시험은 시간을 기록만 한다(부하에서 흔들림). 이전 기록 8~9 s 는 다른 빌드와 기계를 나눠 쓰던 때 값.
- 켤레 기울기 반복 수는 긴 사슬(조건수 ~N²)에서 늘어난다. 정점 1만 이상이면 다중 격자·희소 촐레스키 검토.
- 다수결 초기화 문턱이 이상치 문턱 하한과 묶여 있다. 분리 필요.
- 정상 집합 재선정이 8회 안에 멈추지 않으면 돌려주는 정상 표시가 마지막으로 푼 집합과 한 번 어긋날 수 있다(시험 장면에서는 없음).
