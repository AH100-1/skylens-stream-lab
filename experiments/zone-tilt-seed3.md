# 시드 3 에서 기준 구역 선택·직선 고정 두 안 확인

## 결론

- 시드 3 기본 경로는 verify 5/8 이고(구역 0 회전 붕괴, 이번 범위 밖) 두 설정 모두 5/8 로 같다. 통과 수는 더 나빠지지 않았다.
- 실패 항목도 같다: preview_align, preview_vs_refined, up_cross(구역 0 최대 어긋남 69.509°, 두 설정 동일).
- 개별 값은 한쪽이 낫다고 하기 어렵다. 두 옵션 함께(c)는 구역 2 정밀 높이 중앙이 +2.42 m 로 크고 preview_vs_refined 높이 차가 3.637 m 였고, 기준 구역만 켠 경우(a)는 3.446 m 였다. 구역 0 이 붕괴한 상태라 구역 0 값은 의미가 약하다.
- 끔(기본, 0)은 시간 안에 측정하지 못했다. 그래서 악화 여부를 기본 경로 수치와 직접 견주지 못했고, 통과 수(5/8)만 앞선 측정과 같다는 점으로 확인했다. 미측정.

## 방법

- 합성 장면 시드 3(`SceneConfig { seed: 3 }`, 구역 3개, 240장), 기본 인자로 `run` 후 `verify`. 시험 `realign_ref_zone.rs` 의 방식을 따라 정밀 점군 높이를 정답 표면(`surface_height`)과 비교했다(측정용 시험 파일은 저장소에 더하지 않음).
- 두 설정을 같은 4 코어 측정 기계에서 동시에 돌렸다(부하 약 40, 각 약 30분).
- 제품 코드는 바꾸지 않았다.

## 남은 문제

- 구역 0 회전 붕괴(up_cross 69.509°)는 두 안이 건드리지 않는다. 시드 3 의 verify 5/8 은 그대로다.
- (a)는 구역 0 기울기 24.517° 로 크고 (c)는 8.440° 로 작지만, 구역 0 이 붕괴한 상태라 해석을 보류한다.
- 끔(기본) 설정 측정이 필요하다. 구역 간 스케일 차는 (c) 16.41%, (a) 25.41% 로 둘 다 기준 10% 를 넘었다.
