# verify: 출력 폴더 검증 명령

## 결론
- `skylens-stream verify <폴더>` 가 SPEC §4 일곱 항목을 판정하고 표(항목·PASS/FAIL·측정값·기준)를 찍는다. 하나라도 실패면 종료 코드 1.
- 포즈 단계 정보(등록 사진 수, 재투영 오차, 구역별 위치·사진 수)는 manifest 에 없어서 출력 폴더 바로 아래 `report.json` 을 새로 정했다.
- 작은 합성 출력 폴더로 통과(코드 0) 1건, 항목별로 하나씩 깨뜨린 실패(코드 1) 경우를 시험했고 경계값에서 기대대로 갈린다.

## 수치 표 (시험 고정값)
| 항목 | 통과 경계 (시험값) | 실패 경계 (시험값) |
|---|---|---|
| 등록 사진 | 240/240 | 초벌 239/240, 정밀 239/240 |
| 구역 사진 수 | 42 = 3×14, 48 = 3×16 | 47 ≠ 3×16 |
| 정밀 재투영 | 0.700 px | 0.701 px |
| 초벌 정렬 점쌍 | 1000 | 999 |
| 초벌 정렬 잔차 중앙 | 5.99 m | 6.0 m |
| 구역 간 스케일 (중앙 대비) | 1.10, 0.90 (±10.00%) | 1.11, 0.89 |
| 초벌↔정밀 높이 차 중앙 | 1.990 m | 2.000 m |
| 초벌↔정밀 최근접 중앙 | 1.990 m | 20.000 m (짝 없는 먼 점이 절반 초과, 상한 20 m) |
| 이웃 정밀 겹침 차 중앙 | 0.290 m | 0.300 m (f32 로 0.30000001) |
| 스냅샷 | 점 100→150→200, 단계 2 새 영역 12.5 | 100→100 정체 / 단계 2 새 영역 0 / NaN 1점 |

시험 10건(통과 1, 항목별 실패 8, 폴더 없음 1) 실행 약 45 s (4 코어 측정 기계, 다른 빌드와 함께 돌 때).

## 방법
- 등록: `registered.preview == total` 이고 `registered.refined == total`.
- 구역 사진 수: `regions[].images == 3 × regions[].positions`.
- 재투영: `reprojection_px.refined ≤ 0.7`.
- 초벌 정렬: manifest `align` 전부에서 `pairs ≥ 1000`, `fit_median_m < 6`, 스케일은 전체 스케일 중앙값 대비 |s/중앙 − 1| ≤ 0.10 (부동소수 여유 1e-9).
- 초벌↔정밀: 같은 구역 번호 k 의 `preview_kk_*.ply` 와 `refined_kk_*.ply`. 초벌 점마다
  - 3D 최근접 거리(격자 해시, 셀 1 m, 껍질을 넓히며 찾고 20 m 에서 자름)의 중앙 < 3 m,
  - 수평 2 m 안의 수평 최근접 정밀 점과 짝을 지은 |Δz| 의 중앙 < 2 m (짝 없는 점은 뺌).
  - 전체 점군 중앙값끼리는 비교하지 않는다. 구역마다 계산해 최댓값으로 판정.
- 이웃 정밀 겹침: 번호 순 이웃 구역 쌍마다 앞 구역 점을 뒤 구역의 수평 1 m 안 최근접과 짝지어 |Δz| 중앙 < 0.3 m. 짝이 없으면 실패.
- 스냅샷: step 순(최종 "final" 은 맨 뒤)으로 점 수 엄격 증가, step ≥ 2 에서 `preview_new_area > 0`, `snapshots/step_*.ply` 전부 NaN 없음, 파일 점 수 = manifest 점 수.
- 점이 20만 개를 넘으면 질의 점을 일정 간격으로 추린다.

## report.json 형식
```json
{"registered": {"total": 240, "preview": 240, "refined": 240},
 "reprojection_px": {"preview": 4.5, "refined": 0.59},
 "regions": [{"region": 0, "positions": 14, "images": 42}]}
```

## 남은 문제
- 파이프라인 쪽에서 `report.json` 을 아직 쓰지 않는다. 포즈·구역 단계가 이 형식으로 기록해야 실제 출력에서 1~3 항목이 판정된다.
- 겹침 차는 수평 1 m 짝의 높이 차로 정했다. 경사면이 많으면 3D 최근접 거리 쪽이 나을 수 있어 실제 데이터로 비교가 필요하다.
- 최근접 상한 20 m 를 넘는 큰 어긋남은 20 m 로 찍힌다(판정에는 영향 없음).
- 매우 큰 점군에서 셀 1 m 고정 격자의 메모리·속도는 아직 재지 않았다.
