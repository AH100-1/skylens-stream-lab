# 장착 상대 회전을 떨어진 L 붙이기에 물려주기

## 결론
- 채택 권고(시드5). 초벌 모델에서 얻은 FR–L 장착 상대 회전(카메라 0 기준, 위치·구역 표본의 쿼터니언 평균)을 정밀 시작의
  떨어진 L 성분 붙이기에 물려주면 시드5 상대 오차가 구역0 5.30° → 2.34°, 구역1 4.49° → 3.04° 로 줄고, 최종 FR/L 회전 오차도
  전 구역에서 같거나 좋아졌다(구역0 FR 2.05→0.82, L 3.34→1.76 / 구역1 FR 2.08→1.48, L 2.28→1.55 / 구역2 변화 없음).
- 롤을 정하는 위치가 중요했다. 붙이기 첫 단계의 롤만 바꾸면 결과가 전혀 달라지지 않았다(소수 둘째 자리까지 동일).
  이어지는 닮음 보정(최근접 겹침 ICP)이 회전을 다시 돌려 놓기 때문이다. 닮음 보정 뒤에 장착 관계로 롤을 한 번 더 맞춰야 효과가 났다.
- 반복 측정: l-attach-rel(06105e2) 기준선을 2회 다시 쟀고 두 번 모두 같은 값이 나왔다(결정적). 구역0 악화는 재현된다
  (L 최종 3.34°, 상대 5.30°). 다만 이전 노트의 구역1 상대 3.43° 는 재현되지 않고 4.49° 가 나왔다(측정 조건 차이 추정, 원인 미확인).
- 시드5 verify 는 6/7 그대로(실패는 등록 80/81, 변경 전후 동일).

## 방법
- 초벌 모델(`coarse_start`)에서 같은 위치에 카메라 0 과 카메라 c 가 모두 등록된 곳마다 `R_c R_0^T` 를 표본으로 모은다.
  구역을 돌며 표본을 누적한다(구역0 은 자기 표본만, 구역2 는 앞 구역 포함).
- 카메라별 평균은 쿼터니언 외적 행렬의 최대 고유벡터(교과서 방식), 중앙 각거리 3배(최소 1°) 밖 표본은 한 번 빼고 다시 평균.
- 정밀 시작 호출의 `PreviewOpts::rig_rel` 로 넘긴다. `merge_detached_components` 가 떨어진 성분의 사진마다 같은 위치에서
  주 모델에 등록된 다른 카메라 사진을 찾아 목표 회전 `R_c R_c'^{-1} R_c'(위치)` 를 만든다.
- `attach_detached` 는 비행 축 둘레 회전각을 0.1° 간격 전수 탐색해 목표와의 각거리 합(L1)이 최소인 값으로 정한다.
  목표가 3개 미만이면 기존 바닥 법선 롤. 롤은 (1) 첫 정렬 단계와 (2) 닮음 보정 뒤 두 번 적용한다(닮음 보정 뒤 값: 구역0 3.6°, 구역1 1.9°).
- 측정: 시드5 `default_path_seed_verify` (4 코어 측정 기계, 스레드 2). 진단 줄 `diag rig …` 를 시험 출력에 추가했다.

## 남은 문제
- 구역1 상대 3.04° 는 기준 3° 를 약간 넘는다. 초벌 단계 상대 오차(2.6°)가 표본 평균에 섞여 있어 하한이 이 근처일 수 있다.
- 장착 상대 회전은 초벌 모델이 정확하다는 가정에 기댄다. 초벌 L 붙이기가 크게 틀린 장면에서는 이상값 제거(3배 규칙)가 전부다.
- 시드는 5 하나, 변경 후는 1회 측정이다(기준선이 결정적이므로 반복 가치는 낮다고 본다). 시드4 구역2 처럼 L 이 적은 경우 미검증.
- 시드1 기본 경로 결과는 아래 제품 쪽 검증 항목 참고(보고 시점에 측정 중이었음).
