# 회전 평균 후속 (놓침 정의·비회전 간선·재선정 상한·SPEC 그래프 놓침 출력)

## 결론
- (F-047 마무리, 7dc1b11) 사슬 시험에 정확도 단언을 넣었다. 전역 정렬 오차는 사슬을 따라 쌓이는 랜덤 워크라 자유도가 몇 개뿐이어서,
  대신 사슬 안쪽(양 끝 100 정점 제외) 정점 v, v+k 의 상대 회전 오차 각도² 평균을 선형화 공분산 예측 3σ²R(k) 와 비교한다.
  R(k) 는 거리 1..4 간선 사슬의 유효 저항으로, 무한 사슬 라플라시안 기호 λ(θ)=Σ_d 2(1−cos dθ) 의 적분 R(k)=(1/π)∫_0^π 2(1−cos kθ)/λ(θ)dθ 로 구한다
  (R(1)=0.2279, R(4)=0.2773, R(100)/100=0.0349 → 1/30 로 수렴해 검산). 1000·2000 정점에서 비가 [0.8, 1.25] 안임을 단언한다(측정 0.96~1.01).
  역행렬 없이 수 ms 에 끝난다. 시간 상한 5 s(단독 0.30~0.70 s 의 7배 이상)와 2000 정점 희소-띠 1단계 차 < 1e-9 rad(측정 1.3e-13 rad) 단언은 유지.
- origin/main(50fce8a) 병합 뒤 F-171·F-172·F-173·F-138 처리분을 포함해 fmt·clippy·전체 시험을 다시 돌렸다(결과는 아래 표).
- 놓침 판정 여유를 `min(두 끝 정점 오차 합, 문턱)` 으로 자르고, 해를 믿을 수 없을 때(`reliable=false`)는 여유 0(문턱만 정의)으로 센다.
  끝 정점이 크게 틀린 해에서 놓침이 0 으로 보이던 문제(절반 오염 시드 41·42, 전부 오염 시드 41)를 시험이 하한 3/4/258 로 잡는다.
- 간선 사용 조건에 회전 검사(유한, ‖RᵀR − I‖ < 1e-6, det > 0)를 넣었다. 0 행렬·반사·1.001 배 축척 간선은 거부되고, 그 간선으로만 이어진 정점은 None.
- 성긴 최악 사례 그래프(같은 카메라 1~3칸 + 같은 위치, 942 간선)를 시험에 되살려, σ 2° 시드 115·7 에서
  상한 8: 재선정 ≥ 1·수렴, 상한 1: 미수렴 표시·50단계 이동 < 1e-9 rad·기준 해 차 < 1e-6 rad 를 단언한다.
- SPEC 짝 일정 그래프(3663 간선) 시험이 σ 1°·2° + 이상치 10% 에서 놓침 합(두 정의)과, 문턱만 정의로 놓친 간선마다
  간선 번호·짝·정답 잔차·추정 잔차·문턱·끝 오차 합을 출력한다.

## 방법
- 정확도 단언의 기준 ±25%: 1000·2000 정점 측정 비가 0.96~1.01 이고 표본이 수백~천여 개라 흔들림은 수 % 이며, 강건 무게의 효율 손실도 덮는다.
  정상 간선 일부를 버리거나 무게를 잘못 줘 오차가 예측의 1.25배를 넘게 커지는 결함은 잡는다. 240 정점은 안쪽 표본이 40개 남짓이라 출력만 한다.
- 선형화 공분산: 등방 잡음 σ(축마다)의 최소제곱 해는 L⁺⊗σ²I₃(L 은 간선 그래프 라플라시안) 공분산을 가지므로 두 정점 상대 오차 각도²의 기댓값은 3σ²·R_eff.
- 여유 상한을 문턱으로 둔 근거: 문턱은 잔차 중앙값에서 추정한 σ̂ 의 6배(상한 15°)이므로 잡음 모형에 묶여 있고, 두 끝 정점 오차가 각각 3σ 안이면 합은 문턱 근처에 머문다.
- 해가 믿을 수 없을 때는 정점 오차가 잡음 모형을 따르지 않아, 어떤 여유도 근거가 없다고 보고 0 으로 둔다.
- 비회전 간선: `RelativeRotation.rotation` 이 `from_matrix_unchecked` 로 만들어질 수 있어 사용 전에 직교성·행렬식을 본다. 초기화의 대체값(첫 예측)은 이제 늘 회전이다.

## 남은 문제
- F-148 의 회전 평균 몫(카메라 간 간선이 없어 연결 성분이 카메라별로 갈릴 때 성분별 결과와 경고)은 하지 못했다. 현재 `AveragingResult` 는 가장 큰 성분만 돌려주고 나머지 정점은 None 이며 경고 항목이 없어, 성분별 결과를 내려면 결과 구조를 바꿔야 한다(다음 판).
- verify.rs 의 1 s 시간 단언 시험이 부하 30 에서 실패한다(맡은 파일 밖).
- 부하가 큰 상태(4 코어에 부하 평균 23)에서 회전 평균 시험 전체를 돌렸을 때 `large_chain_graph_is_fast` 가 실패했다(이 판에서 고치지 않은 시험; 5 s 시간 상한으로 보이나 출력이 잘려 확인 못 함). 그 시험만 따로 돌리면 통과: 2000 정점 전체 1.30 s, 희소-띠 1단계 차 1.3e-13 rad, 1000 정점 희소-밀집 차 6.6e-14 rad. 여러 무거운 시험이 함께 돌 때 5 s 상한이 넘을 수 있어, 시간 상한을 단독 실행 시험으로 떼거나 한 단계 시간 비로 바꾸는 것을 검토해야 한다.
