# 회전 평균 강건화 (F-075, F-045, F-101, F-076, F-077, F-009, F-046, F-047, F-078)

## 결론
- 결과 성분을 "가장 작은 번호 정점이 든 성분"에서 **가장 큰 연결 성분**(정점 수 → 간선 가중합 → 작은 번호)으로 바꿨다. 기준 정점은 그 성분 안 가장 작은 번호. 0번·3번이 서로만 이어진 SPEC 짝 일정에서 238대 복원, 평균 0.225°(σ 0.6°). (F-075)
- 정상 표시 = 마지막 최소제곱에 실제로 쓴 간선 집합. 재선정 반복이 끝까지 안 멈춰도 마지막으로 푼 집합을 돌려준다. 기준 해 차 30시드 × 4경우 모두 < 1e-6 rad(실측 ≤ 4e-14). (F-045)
- 다수결 초기화 일치 문턱 `init_agree_rad`(기본 15°)을 이상치 문턱과 분리. σ 2° + 이상치 10% 가 평균 33°/최대 179° 에서 30시드 최악 평균 0.79°/최대 2.69° 로. (F-101)
- 이상치 문턱 = clamp(6·σ̂, 하한 1°, 상한 15°). 상한에 걸리거나 정상 비율 < 50% 면 `reliable = false`. 간선 절반·전부 오염에서 문턱 15°, 거짓 표시. (F-076)
- 하한을 5° → 1° 로 낮춰 σ 0.3° 에서 3° 오차 간선 366개 중 365~366개 검출, RMS 0.109~0.115° (무오염 0.106~0.110°). (F-077)
- 시험 그래프를 SPEC 짝 일정(`candidate_pairs(.., 5, 4, 16)`, 3663 간선)으로 바꾸고 시드 100..129 분포(중앙·최악)로 단언. RMS 단언은 예측의 0.8배(측정 0.59~0.68배), 주석과 일치. (F-046, F-078, F-009)

## 방법
- 성분: 쓸 수 있는 간선으로 합집합-찾기. 작은 번호를 뿌리로 합쳐 성분 대표 = 최소 번호.
- 잡음 추정 σ̂ = 중앙값(잔차)/1.5382(자유도 3 카이 중앙값). 6σ̂ 는 정규 잡음에서 꼬리 확률 무시할 수준. 상한 15° 는 σ 2°·이상치 20% 에서 문턱 13.2° 가 나오는 것을 보고 그 위로 정했다. 문턱이 상한을 넘으려 한다는 것은 중앙값이 이상치 쪽으로 갔다는 뜻이라 실패로 본다.
- 초기화 일치 15°: σ 2° 이웃 예측 차(4~5°)의 3배 이상, 임의 회전 이상치가 15° 안에 들 확률은 작다.
- 놓침 정의: 오염 간선 중 정상으로 남았고 정답 잔차 ≥ 문턱 + 두 끝 정점 오차 합. 추정 잔차와 정답 잔차는 끝 정점 오차 합만큼 다를 수 있어 문턱 바로 위 간선은 판별 불가. 문턱만으로 센 값도 함께 출력한다(σ 1°+이상치 시드 100 에서 1개: 생성된 오차가 우연히 약 6° 인 간선).
- 측정은 4 코어 측정 기계, 여러 작업이 함께 도는 부하에서.

## 남은 문제
- 간선 절반 오염은 `reliable = false` 로 알리지만 해 자체는 최대 133° 로 틀린다. 호출자가 표시를 봐야 한다.
- F-047: 2000 정점 시간 상한(5 s) 단언은 넣었다. 2000 정점 밀집 비교는 80 s 넘게 걸려 `#[ignore]` 시험으로 분리. 사슬 그래프 정확도를 선형화 공분산 예측 대비로 단언하는 것은 못 했다(사슬 오차 240/1000/2000 정점 평균 1.4/4.9/4.8°).
- 선형화 예측은 기준 정점 0 고정 공분산이라 정렬 오차보다 크다(비 0.59~0.68). 세계 회전을 뺀 공분산으로 바꾸면 배수 근거가 더 깔끔하다.
