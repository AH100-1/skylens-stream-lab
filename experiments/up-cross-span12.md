# 위 방향 교차 검사: 기본 경로(span 12, 구역 3개)의 거짓 초과 측정 (F-445 기록)

## 결론
- 기본 경로(인자 없는 synth 와 같은 장면, 80위치 → stride 3 → 27위치, `run` 기본값 span 12·구역 3개: 위치 14·16·5)에서 위 방향 교차 검사는 시드 3개 모두 보고서 최대가 문턱 0.3° 를 넘었다(0.577° / 1.386° / 69.509°). 구역 9개 중 5개가 초과다.
- 같은 사진에 정답 회전을 넣으면 9개 구역 모두 어긋남 0.000° 라서(묶음마다 방위가 한 방향뿐이어서 대체 갈래만 돌고, 이때 정답 어긋남이 0) 초과 5건은 전부 거짓 양성이다. 원인은 구름이 아니라 구역 안 정밀 모델의 회전 오차다.
- 초과는 구역이 작을 때 몰린다. 위치 5곳 구역 3개 중 2개가 1.25~1.30° 이고 위치 14곳 구역 3개 중 3개가 0.52~0.62° 또는 46~70° 다. 위치 16곳 구역은 0.02~0.25° 로 문턱 미만이다. 시드 3 의 구역 0(14곳)은 초벌 오차 4.214 px → 정밀 0.254 px 인데도 어긋남이 46.7~69.5° 로, 모델이 통째로 어긋난 경우다.
- 실행 알림은 이 경우 "한 카메라의 짐벌 구름 치우침이 의심된다" 를 띄운다. 기본 경로를 쓰는 사람은 장면에 구름이 없어도 시드에 따라 경고를 본다(F-445 (2)·(3) 의 실제 영향이 이것).

- 단언은 정답 회전의 어긋남이 문턱 미만임 하나뿐이다(검사 자체는 옳다는 기준). 제품 동작은 바꾸지 않았다.

## 남은 문제
- 정밀 모델의 회전 오차 자체(구역 안 광축 사이 각 대 참값)는 이번 시험이 직접 재지 못한다. 제품 출력(`poses.txt`)에 회전이 없고 `PipelineResult` 에도 회전이 없어서다. 대신 정답 회전에서 어긋남 0 이고 보고에서 0.5~70° 라는 사실로 모델 오차임을 확정했다. 시드 3 구역 0 은 이전 노트(span 8, 7.6~27.5°)와 같은 종류의 모델 붕괴다. 구역별 회전 오차(정밀 회전 대 정답 회전)를 report 나 시험에서 재도록 회전을 내보내는 일이 필요하다.
- 구역 안 묶음마다 방위가 한 방향뿐이라 `up_own` 이 전부 None 이고 대체 갈래(카메라 x 축이 나머지 위 방향에 수직인 면에서 벗어난 각의 평균)만 돈다. 구역 안 모델 기울기 오차 하나가 세 묶음에 거의 같은 크기로 들어가므로(시드별 F/R/L 가 서로 비슷함) 어긋남은 "한 묶음의 구름" 이 아니라 "구역 전체 기울기 오차" 를 재고 있다. 대체 갈래는 묶음 사이 값이 비슷하면 모델 오차, 한 묶음만 크면 구름이라는 구분이 가능해 보이지만 이번 값으로 문턱을 정하지는 않았다(구름 2° 일 때 묶음별 값은 이전 노트의 단구역 시험에만 있다).
- 하한 후보 비교: 위치 16 이상이면 이 9개 구역에서 거짓 초과 0 이지만 검사 구역이 3개(구역의 1/3)로 줄고, 그중 시드 3 구역 1(16곳)은 0.250° 로 문턱의 83% 다. 위치 14 이하(14곳 구역 3개 중 3개 초과)는 하한으로 못 거른다. 즉 위치 수 하한만으로는 위치 14 구역의 거짓 초과(시드 1·2 0.5~0.6°, 시드 3 46~70°)를 막을 수 없다. 위치 수 하한 외에 묶음 사이 값 비율(한 묶음 최대/나머지 평균)이나 구역별 재투영 오차·광축 사이 각 같은 모델 건전성 판단이 필요하다. 후보 비교는 시드 3개·구역 9개라 표본이 작다.
- 후보 제안(제품 기본 동작은 바꾸지 않음): (a) 구역 위치 수 ≥ 16 일 때만 초과 판정, 아니면 정보 줄로만 남김(거짓 초과 5 → 0, 검사 구역 9 → 3). (b) 판정을 구역 단위 최대가 아니라 "한 묶음이 나머지 두 묶음 평균의 몇 배 이상" 으로 바꾸는 후보는 이번 표에서 F/R/L 비가 1.0~1.4 배로 모두 비슷하므로 거짓 초과 9개 중 5개를 모두 거를 수 있을 것으로 보이나, 구름 있는 장면(한 기체 2° 일 때 구름 없는 묶음도 0.849°, 구름 묶음 1.17~1.27°, 비 1.4~1.5)에서는 비가 모자라 구별이 어렵다. 숫자로 확인하지 못했으므로 다음 작업에서 재야 한다.
- F-445(낮음, 기록만): (1) 최대 어긋남 카메라 이름이 알림에 없음, (2) 구름 없는 묶음도 0.849° 로 가려짐, (3) 문턱 미만일 때도 알림 목록에 한 줄. 이번 측정으로 (3) 의 실제 영향이 확인된다: 기본 경로 알림 목록에 시드 3개 모두 "초과" 줄이 있고 전부 구름과 무관한 거짓 양성이다. 이번에는 코드를 고치지 않았다.
