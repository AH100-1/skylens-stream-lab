# 시드 3 구역 0 회전 붕괴: 종류 덩어리 붕괴 검출 뒤 종류별 문턱 재평균

## 결론
- 회전 평균 직후 카메라 종류별로 "같은 종류 간선 잔차 중앙은 작은데 다른 종류와 잇는 간선 잔차 중앙이 큰" 경우(덩어리 전체가 돌아간 경우)만 종류별 문턱으로 재평균하는 검출기를 기본 켬으로 구현했다. 다른 경우는 기존 경로 그대로다.
- 시드 3 의 verify·F/R/L 회전 오차, 시드 1 의 발동 여부·표면 중앙: **미측정**(마감 시점에 시드 3 실행이 끝나지 않았다). 아래 문턱 3°·20° 는 실측이 아니라 시드 3 노트(L 84.7° 붕괴, F 1.27°, R 0.33°)에 맞춘 가정값이다.

## 방법
- `group_residual_stats`(rotation_averaging.rs): 간선 잔차 ∠(R_j R_iᵀ R_ijᵀ) 를 종류별로 같은 종류 간선·교차 간선 중앙과 개수로 요약.
- 파이프라인 `class_collapse_detected`: 어떤 종류에서 같은 종류 간선 중앙 ≤ 3°, 교차 간선 중앙 ≥ 20°, 각 20 개 이상이면 `class_thresholds` 로 재평균(이후 가지치기 재평균도 같은 설정). 요약은 항상 표준 오류로 `rotavg-detect` 줄에 찍는다. `SKYLENS_ROT_DETECT=0` 으로 끔.
- 시험 `crates/cli/tests/seed3_zone0_rot.rs`(무시 시험, `ZONE0_SEEDS`)는 기본 경로 한 번의 F/R/L 오차·verify·`DETECT` 줄을 출력한다.
- 검사: fmt·clippy(-D warnings) 통과. `rotation_averaging` 단위 시험은 빌드 잠금 대기로 미실행.

## 남은 문제

- 시드 1 에서 미발동 로그와 표면 중앙 확인, 시드 2 확인.
