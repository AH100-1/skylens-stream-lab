# L 붙이기 상대 회전: 정밀 시작 단계의 부분 모델 다듬기

## 결론
초벌 단계와 정밀 시작 단계의 L 붙이기가 다른 이유는 입력 점의 차이였다. 초벌 호출은 위치 전용 다듬기
(`preview_refine_iters`)를 거치고, 정밀 시작 호출은 다듬기 0회였다. 떨어진 L 성분의 부분 모델은 이
옵션을 그대로 물려받으므로, 정밀 시작에서는 다듬지 않은 점으로 바닥 법선을 구해 롤이 어긋났다.
정밀 시작 호출에서 부분 모델에만 초벌과 같은 다듬기 횟수를 쓰게 했더니 시드5 구역1 의 상대 오차가
정밀 BA 직후 7.17° → 3.43°, 최종 FR 4.39° → 1.67°, L 3.18° → 1.66° 로 줄었다. 반면 구역0 은 상대 오차가
4.40° → 5.41° 로, L 최종이 1.79° → 3.43° 로 나빠졌다. 시드5 verify 는 6/7 그대로(실패는 등록 80/81).
구역1 은 기준(상대 ≤ 3°)에 약간 못 미치고(3.43°), 구역0 은 후퇴하므로 부분 채택(순이득이지만 최선 기준
미달)으로 본다.

구역2 FR 0.57 (변화 없음).

## 방법
- 원인 확인: `merge_detached_components` 의 부분 모델 옵션이 `refine_iters` 를 주 호출에서 받는다.
  초벌 호출은 `cfg.preview_refine_iters`, 정밀 시작 호출은 기본값 0. 입력 GPS 는 같고, 점·법선만 다르다.
  (법선 각도 자체는 이번 시간 안에 따로 찍지 못했다. 상대 오차 변화로 간접 확인.)
- 수정: `PreviewOpts::detached_refine_iters`(None 이면 기존 동작)를 추가하고 정밀 시작 호출에서만
  `Some(cfg.preview_refine_iters)` 로 지정. 주 모델의 시작점은 건드리지 않았다.
- 측정: 시드5 `default_path_seed_verify` 한 번(4 코어 측정 기계, 스레드 2).

## 남은 문제
- 구역0 이 나빠진 이유 미확인: 다듬기가 구역0 의 L 성분 법선을 오히려 기울였을 가능성. 한 번 측정이라
  잡음 여부도 불명. 초벌 단계의 FR–L 상대 회전을 여러 위치 평균으로 직접 물려받는 방식은 시간 부족으로 시도하지 못함.
- 구역1 상대 3.43° 는 기준 3° 보다 약간 큼.
- 시드1 결과와 단위 시험은 제품 브랜치 커밋 메시지 이후 별도 확인 필요(아래 참조).
