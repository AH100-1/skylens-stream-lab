# 종류별 회전 문턱 기본 켬 판단: 시드 1 기본 경로 표면 오차

## 결론
- 시드 1 에서 종류별 문턱(SKYLENS_ROT_CLASS_THRESH=1)을 켜면 표면 오차 중앙이 0.4042 → 0.5059 m 로 기준 0.5 m 를 근소하게(0.006 m) 넘는다. 기본값은 바꾸지 않고 끔을 유지한다.
- 등록 수(81)·카메라 중심 오차 중앙(0.4265 → 0.4279 m)·verify(8/8)는 변하지 않았다. 표면 p95 는 1.3237 → 1.5687 m 로 늘었다.
- 앞서 덩어리 잇기 켬(0.5849 m)보다는 덜 나쁘지만, 같은 방향(중심은 그대로, 표면이 나빠짐)이다.

## 수치 표 (시드 1, 기본 경로, 4 코어 측정 기계, 같은 부하에서 연달아 1회씩)
| 설정 | 등록 | 중심 오차 중앙 / 최대 (m) | 표면 오차 중앙 / p95 (m) | 점 수 | verify |
|---|---|---|---|---|---|
| 끔 | 81 | 0.4265 / 0.9402 | 0.4042 / 1.3237 | 32050 | 8/8 |
| 종류별 문턱 켬 | 81 | 0.4279 / 0.9329 | 0.5059 / 1.5687 | 32018 | 8/8 |

끔 값은 앞서 잰 끔 기준선과 소수 넷째 자리까지 같다(재현). 시드 2 는 미측정(시간 부족, 기본 경로 한 번에 약 4분 + 부하).

## 방법
- 새 무시 시험 `crates/cli/tests/default_path_class.rs`: 시드를 `CLASS_SEEDS` 로, 설정을 `CLASS_MODES`(off,on)로 골라 합성 장면을 쓰고 `run`·`verify` 후 `default_path` 와 같은 방식으로 정답과 비교.
- 실행: `CLASS_SEEDS=1 cargo test --release -p skylens-stream --test default_path_class -- --ignored --nocapture`.

## 남은 문제
- 켬에서 표면 중앙이 0.1 m 늘어나는 원인 미확인(덩어리 잇기 켬에서도 같은 현상). 중심 오차는 그대로라 점군 쪽(구역 간 정렬 또는 깊이)에서 생기는 것으로 보인다.
- 기준 0.5 m 에 0.006 m 차이라 반복 분산(같은 설정 반복 차는 앞서 0)이 아니라 설정 자체의 차이.
- 시드 2 끔/켬 미측정. 시드 3 은 켬이 verify 5/8 → 7/8 이라 득실이 시드마다 갈린다.
