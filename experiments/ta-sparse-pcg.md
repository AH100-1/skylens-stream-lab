# ta-sparse-pcg: 점 소거 카메라 계통의 반복 풀이

## 결론
gp_solve 의 카메라 축소 계통 S = D_c - W D_p^-1 W^T 를 밀집으로 만들지 않고 행렬-벡터 곱(관측 목록 훑기, 병렬)과
대각 야코비 전처리 공액 기울기(이전 반복 해로 시작, 상대 잔차 1e-10)로 푼다. 구성 비용이 사라져 시험 한 번이
약 295 s 에서 100~140 s 로 줄었으나 기준 60 s 에는 못 미쳤다(부하가 높은 측정 기계). 기존 translation_averaging 시험은 10 통과·7 무시(무시 7개는 변경 전 8개 중 측정 시험 제외 수치와 동일 구성)로 통과.

## 수치 표 (4 코어 측정 기계, 부하 5~18)
| 항목 | 이전(밀집 촐레스키) | 변경 후 |
|---|---|---|
| 풀이 1회(300 반복) 구성 | 약 62~68 s | 7~16 s (병렬 구성 포함) |
| 풀이 1회 선형 풀이 | 0.22 s | 8~23 s (반복당 CG 약 3.2회) |
| 풀이 1회 나머지(역대입·잔차) | 8~9 s | 4~9 s |
| 번호 0 입력 시험 | 294.6 s | 114.7 s (부하 5.6), 142.5 s (부하 11~18) |
| 번호 1e6 입력 시험 | 290.6 s | 101.4 s, 105.5 s |
| 최대 메모리 | 165 MB | 147~184 MB |
| 중심 RMS | 0.0002 | 0.0002 |

풀이 8번(입력 2 x 3회) 모두 300 반복 상한까지 돌고 1e-9 수렴 판정에 걸리지 않는다.

## 방법
- 활성 관측의 카메라별·점별 색인(CSR)을 한 번 만들고 반복마다 가중 w_k 만 갱신.
- 곱: u_p = (sum_k w_k x_cam) / app_p, y_c = D_c x_c - sum_k w_k u_p. 점·카메라 각각 rayon 으로 모음.
- 전처리: S_ii = D_c,i - sum w_k^2 / app_p. 게이지는 기존 릿지 그대로.
- 우변·점 역대입·잔차/가중 갱신도 색인으로 병렬화.

## 남은 문제
- 60 s 미달: 반복당 CG 3회 x 관측 두 번 훑기, 그리고 300 반복 x 풀이 4회가 그대로다. 거르기 뒤 재풀이를 이전 해(중심·점·d·가중)에서 워밍 스타트해 반복 수를 줄이는 것과 수렴 판정 개선이 다음 후보.
- CG 상대 잔차 문턱을 1e-6 정도로 풀면 선형 풀이 비용이 줄 것이나 소수 4자리 일치 확인은 못 했다.
