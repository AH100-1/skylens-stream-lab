# 짧은 마지막 구역 정밀 모델의 연직 기울기 — 정렬 단계에서 생기는지 가르기

## 결론

- 시드 4 구역 2(위치 22~27) 기울기의 큰 몫은 마지막 GPS 정렬(카메라 중심 ↔ GPS 닮음 변환)이다. 구역 2 의 카메라 중심은 거의 일직선(공분산 둘째/첫째 고유값 비 0.021, 구역 0·1 은 0.047·0.050)이라 직선 둘레 회전이 정해지지 않는다. 단계별 기울기(정답 회전 대비, 구역 0 같은 단계와의 차): 회전 평균 직후 +4.0°, 위치 평균 직후 +4.0°, BA 직후 +4.0°, GPS 정렬 직후 +9.9°. 즉 회전 평균 단계에서 이미 약 4° 가 있고, BA 는 더하지 않으며, GPS 정렬이 약 6° 를 더 얹는다. 절댓값에는 카메라 축 규약 차가 섞여 구역 0·1 에서도 약 31° 가 나오므로 차로만 읽는다.
- 대안: 위치가 일직선에 가까울 때(비 < 문턱) BA 시작 모델의 연직(GPS 좌표계 연직)을 BA 가 돌려놓은 회전으로 옮겨 위 방향으로 쓰고, 방위·축척·이동만 푸는 연직 고정 정렬. 환경 변수 `SKYLENS_ALIGN_LINE_FIX=<비>`(기본 끔), 시험은 0.1 로 켬.
- 시드 4 끔/켬(0.1): 자기 정렬 기울기 구역 2 가 13.458° → 1.230°, 정밀 구역 간 정렬 1→2 9.630° → 0.449°, 0→2 10.245° → 1.675°. verify 7/8 → 8/8(preview_vs_refined 통과, 켬 refined_overlap 0.087 m).

## 방법

- `SKYLENS_DIAG_PREVIEW=1` 이면 정밀 시작 모델의 회전 평균 직후(`rot`)·위치 평균 직후(`placed`), BA 직후(`ba`), GPS 정렬 직후(`gps`) 포즈를 내고, 시험 `short_zone_tilt.rs`(무시 시험, `SKYLENS_TILT_SEED=4 [SKYLENS_ALIGN_LINE_FIX=0.1] cargo test --release -p skylens-stream --test short_zone_tilt -- --ignored --nocapture`)가 정답 회전과 비교한다. 켬 판정은 자기 정렬 닮음 변환 기울기 6° 미만.
- 연직 고정에 쓰는 위 방향: Q = 평균(R_시작ᵀ·R_BA) 의 Qᵀ·z. 시작 모델은 GPS 좌표계 연직을 따른다는 가정이다.

## 남은 문제

- 회전 평균 직후부터 구역 2 에 약 4° 가 있다(이 값은 켬에서도 남음: 켬 GPS 정렬 뒤 +4.0°). 연직 고정은 정렬이 얹는 6° 만 막는다. 시작 모델의 회전 평균·비행 축 둘레 롤 선택(구역 2 가 짧아 방향이 한 방향)이 뿌리일 가능성이 있어 따로 봐야 한다.
- 단계 기울기 절댓값의 규약 차 31° 원인은 못 풀었다(구역 0 과의 차로만 해석).
- 시험 켬 판정 단언을 고친 뒤(자기 정렬 기울기) 다시 돌리지 못했다(측정은 단언 수정 전 실행, 값은 동일). 시드 4 외 미측정. 재정렬(구역 간 sim3) 코드는 건드리지 않았다.
- fmt 통과, clippy 0. 이 묶음의 `cargo test --release` 는 무시 시험 1개(위 실행)만 해당.
