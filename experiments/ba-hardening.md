# 번들 조정 보강 (P20)

## 결론
- (3차, F-121) 좌표가 유한하지 않은 점(NaN·inf)은 트랙 선택 전에 그 점의 관측을 모두 빼고 `num_observations_rejected` 에 센다.
  점 자체는 고치지 않는다. 장면 시드 13(카메라 10, 점 400)에서 관측 9개인 점 하나의 x 를 NaN 또는 inf 로 바꿔도
  제곱·Huber 손실 모두 Converged, 제외 9, 최종 RMS 가 깨끗한 실행과 1% 이내(시험 단언).
  유한하지 않은 포즈·내부 파라미터(NaN 이동 성분, NaN fx)는 `BaStop::InvalidInput` 이고 입력은 그대로다.
- (3차, F-122) `refined` 는 받아들인 단계 수 > 0 일 때만 참. 쓸 관측이 0개면(모든 픽셀 NaN, 관측 없음, 빈 문제)
  반복에 들어가지 않고 EvaluationOnly·refined false·converged false. 촐레스키가 매번 실패한 경우도 refined false.
- (3차) main 병합 뒤 축척 게이지(F-034) 시험은 그대로 통과. F-036 엄격 기준(시드 21~30)은 여전히 미달, 편대 장면 BA 시험 미착수.
- (2차) main 의 카메라 단일 정규화 경로 변경을 병합한 뒤에도 축척 게이지·입력 검증·멈춤 이유·3그룹 시험이 그대로 통과한다.
- (2차) RMS 분모를 카메라 앞에 투영된 관측 수로 바꾸고, 카메라 뒤 관측 수를 시작·끝 상태별로 보고한다
  (`initial_observations_behind`, `final_observations_behind`). 점 6개를 카메라 3 뒤에 둔 장면에서 보고 RMS 가
  sqrt(Σ|r|²/투영 성공 수) 와 상대 1e-12 안에서 같고 제외 수가 일치한다.
- (2차) 내부 파라미터 판정을 초기 오차와 연결했다: 주점 < 0.5·초기 오차(3 / 2.5 px), k1 < 0.1·|k1|, k2 < 0.25·|k2|,
  p1·p2 < 0.5·|정답|(0 에서 시작). 시드 11~13 모두 통과.
- (2차) Cauchy 는 같은 척도의 Huber 로 먼저 돌리고(수렴·더 못 내려감·반복 한도 절반 중 먼저) Cauchy 로 바꾸는 단계 방식이다.
  시드 22 내정 RMS 2.548 → 1.450 px 로 줄었지만 확인 기준(시드 21~30 에서 Cauchy < 1.2·0.707, 3 px 초과 0개,
  Huber < 1.5·0.707)은 10개 시드 모두 못 맞춘다. 엄격 시험은 무시 표시로 남겼다.
- 축척 게이지를 명시적으로 고정했다. 고정 카메라가 하나면 두 번째 기준 카메라의 평행이동 한 성분을 고정한다.
  같은 장면에서 초기 감쇠 λ₀ = 1e-12 와 1e-4 의 결과 |c1−c0| 가 12자리까지 같고(3.788409442875), 축소 계통 촐레스키 실패는 두 경우 모두 0회.
  `fixed_cameras` 가 비거나 범위 밖이면 첫 카메라를 고정한다.
- 입력 검증: 포즈·그룹 길이 불일치, 범위 밖 그룹 번호는 아무것도 고치지 않고 `BaStop::InvalidInput`.
  범위 밖 점·카메라 번호와 유한하지 않은 픽셀의 관측은 제외하고 `num_observations_rejected` 로 보고. 트랙은 관측 2개 이상만 쓴다.
- 멈춘 이유 `BaStop`(Converged / MaxIterations / StepFailed / InvalidInput / EvaluationOnly) 과 촐레스키 실패 수를 보고에 넣었다.
  `converged` 는 상대 비용 감소 기준으로 멈췄을 때만 참. 비유한 비용(점 좌표 NaN), 감쇠 0 + 관측 없는 카메라(촐레스키 12회 실패)는 StepFailed.
- 내부 파라미터 3그룹(fx 800/820/790, k1 −0.10/−0.05/0.0, 그룹 2 는 k2·p1·p2 고정) 장면에서 시드 3개 모두
  fx·fy 0.12% 이내, 주점 0.9px 이내, k1 0.002 이내, 고정 항목 비트 단위 동일, 최종 RMS/기댓값 0.993~0.997.
- 실제 규모(카메라 240, 점 10만, 관측 64.8만, 축소 계통 n = 1441) 반복 한 번 약 3.0초(4 코어 측정 기계, 동시 부하 있음).
  선형화·슈어 소거가 각각 약 1.1초로 촐레스키(0.57초)보다 크다.

## 방법
- (3차) `observation_is_valid` 에 점 좌표 유한성을 더해 비유한 점 관측이 트랙·비용 계산에 들어가지 않게 했다.
  `input_is_consistent` 에 포즈(회전 행렬·이동)와 내부 파라미터 8개 유한성을 더했다.
  반복 루프에서 받아들인 단계를 세어 `refined` 를 정한다.
- (2차) 단계 Cauchy: 손실이 Cauchy(δ) 이면 Huber(δ) 로 LM 을 돌리다가 수렴·StepFailed·반복 한도의 절반 중 먼저 오는 때에
  비용을 Cauchy 로 다시 재고 λ 를 초기값으로 되돌려 이어 간다. 보고의 initial/final_cost 는 요청한 손실로 잰다.
- (2차) RMS 분모: `evaluate` 가 돌려주는 카메라 뒤 관측 수를 분모에서 뺀다. 끝 상태의 수는 마지막으로 받아들인 단계의 값.
- 축척 고정: 고정 카메라 C₀ 를 중심으로 한 축척 s 에서 t_k = −R_k(C₀ + s(C_k − C₀)) 이므로 ∂t_k/∂s = −R_k(C_k − C₀).
  이 기울기의 절댓값이 가장 큰 (카메라 k, 성분 i) 의 t_k,i 를 축소 계통에서 뺀다. 축척 방향과 횡단이라 다른 자유도는 남는다.
  고정 카메라가 2개 이상이면 축척이 이미 정해지므로 더 고정하지 않는다.
- 이전 방식과의 차: 고정 전에는 축척 방향이 λ·diag 로만 막혀 λ₀ 에 따라 해가 축척 방향으로 달라질 수 있었다.
- 슈어 소거의 `flat.iter_mut().find` 선형 탐색을 축소 계통 번호 → 위치 표(점마다 채우고 되돌림)로 바꿨다.
  누적 순서가 같아 S·rhs 가 이전 방식과 비트 단위로 같다(시험 `schur_matches_linear_search_accumulation`).
- 3그룹 장면: 그룹 g 섭동 fx ×(1 + 0.02(g−1) + 0.01), fy ×0.98, cx +5−3g, cy −4, k1 = 0, 그룹 0·1 은 왜곡 전부 0 에서 시작.
- 측정 시험: `cargo test --release -p skylens-core ba_scale_timing -- --ignored --nocapture`.

## 남은 문제
- (3차, F-036) 엄격 기준(시드 21~30 Cauchy·Huber 내정 RMS < 1.5·0.707, 3 px 초과 0개)은 이번에도 손대지 못했다. 무시 시험 그대로.
- (3차, F-036) SPEC §6 편대 배치 장면 BA 시험(최종 RMS/기댓값 0.95~1.05, 중심 오차 < 0.05 m)도 아직 없다.
- (3차) 비유한 점 시험의 RMS 상대 차 실제 값은 단언(1% 미만)만 했고 표로 따로 적지 않았다.
- (2차, F-036) 단계 Cauchy·Huber 모두 이상치 10% 장면에서 내정 RMS 엄격 기준을 못 맞춘다. 3 px 를 넘는 내정 관측이 남는 것은
  관측 수가 적은 점에서 이상치가 과반이거나 비등해 점 위치가 이상치 쪽으로 정해지는 경우로 보인다(점별 분석은 아직).
  확인 방법: 정답 시작에서 같은 실행, 점별 이상치 비율과 3 px 초과 관측의 대응. 대안은 강건 단계 뒤 잔차 큰 관측 제거 후 재조정.
- (2차, F-036) SPEC §6 편대 배치(3대 × 12 위치 이상, 위치 간 1.0 m, 내려다보는 각 60°) 장면 BA 시험은 아직 없다.
- (2차, F-085) k2·p1·p2 야코비안 열을 0 으로 만든 변형 코드에서 실패하는지는 돌려 보지 않았다(허용치가 초기 오차보다 작으므로
  계수가 0 에 머물면 실패해야 한다).
- 점 단위 rayon 병렬 누적은 하지 않았다. 선형화와 슈어 소거가 반복 시간의 약 3/4 이다. 밀집 n×n 누적을 스레드별로 나누면
  합산 순서가 바뀌어 결과가 비트 단위로 같지 않으므로, 결정성 기준(허용 오차)을 먼저 정해야 한다.
- λ 재시도마다 슈어 소거와 n³/3 촐레스키를 다시 한다. 반복당 시간 목표는 이 표를 바탕으로 정한다.
- 감쇠 초기값 0 이하는 검사하지 않는다(관측 없는 카메라와 겹치면 촐레스키가 계속 실패해 StepFailed 로 보고).
- 관측이 하나도 없는 카메라·그룹 자체는 InvalidInput 으로 거르지 않는다(감쇠가 있으면 증분 0 으로 남는다).
