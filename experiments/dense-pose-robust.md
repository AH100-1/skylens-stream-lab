# 자세 잡음에서 이웃 시점 선택 (dense-pose-robust)

## 결론
- 이웃 점수에 "최소 광선 각"을 두면 자세 잡음에서 표면 거리가 크게 준다. 최소 8도가 가장 좋았다:
  잡음 0.05 m·0.05도에서 중앙 0.4113 → 0.2857 m (−30.5%), 정답 자세에서도 0.0651 → 0.0371 m (−43%, 악화 아님).
- 최적 각 12도로 올려도 최소 8도와 결과가 같았다(24장 장면에서 같은 이웃이 뽑힘). 최소 10도는 정답 자세는 더 좋지만 잡음에서 최소 8도보다 나쁘고 점이 줄었다.
- 잡음 0.2 m·0.2도에서는 어떤 설정도 못 고친다(중앙 약 2.0~2.4 m, 점 4만 → 약 6천). 그 크기의 자세 오차는 이웃 선택이 아니라 자세 정제로 풀어야 한다.
- 기본값은 바꾸지 않았다. 최소 8도 기본에서 기존 시험 4개가 깨졌다: 4 위치(기선 짧음) 장면은 점 0개, 편대 이웃 순위 시험 2개, 융합 편대 시험 1개(이웃 8장 보장 가정). 모자란 이웃을 작은 각으로 채우는 변형도 해 봤으나 이득이 사라졌다(잡음 중앙 0.3927, 정답 0.0535로 오히려 정답 악화). 이득은 "넓은 기선 이웃만 쓰는 것"에서 나온다.

## 방법
- 두 시점 깊이 오차 ≈ 회전 오차 / 삼각측량 각이므로 작은 각 쌍을 이웃 점수에서 뺀다. 쌍 점의 광선 각이 최소 각보다 작으면 그 점수 0.
- 이웃 선택 설정(최소 각·목표 각·아래/위 폭·상한 각)을 NeighborConfig 로 노출. 기본값은 이전 동작(최소 0도, 상한 180도).
- 자세 잡음: 사진마다 독립인 중심 가우스 잡음과 임의 축 회전 잡음(씨앗 7). 깊이·반점 제거·융합은 공개 API 로 같은 순서로 구성하고 이웃 선택만 교체.
- 12도 설정: 목표 12도, 아래 폭 4도.

## 남은 문제
- 최소 각을 기본으로 하려면 이웃이 모자랄 때의 처리가 필요하다(작은 각으로 채우면 이득 소실). 장면별 기선 분포에 맞춰 최소 각을 고르는 방식(예: 사진별 후보 각 분포의 하위 분위 기준)이 후보.
- 기존 이웃 순위·융합 편대 시험이 "1칸 이웃이 하위"·"이웃 8장"을 가정하므로 기본 변경 시 같이 손봐야 한다.
- dense 의 이웃 선택은 DenseConfig 에 설정 통로가 없어 실제 흐름에서 쓰려면 dense.rs 에 NeighborConfig 전달이 필요하다.
- 0.2도 이상의 자세 오차는 이웃 선택으로 해결되지 않는다.
