# 자세 잡음에서 이웃 시점 선택 (dense-pose-robust)

## 결론
- 이웃 점수에 "최소 광선 각"을 두면 자세 잡음에서 표면 거리가 크게 준다. 최소 8도가 가장 좋았다:
  잡음 0.05 m·0.05도에서 중앙 0.4113 → 0.2857 m (−30.5%), 정답 자세에서도 0.0651 → 0.0371 m (−43%, 악화 아님).
- 최적 각 12도로 올려도 최소 8도와 결과가 같았다(24장 장면에서 같은 이웃이 뽑힘). 최소 10도는 정답 자세는 더 좋지만 잡음에서 최소 8도보다 나쁘고 점이 줄었다.
- 잡음 0.2 m·0.2도에서는 어떤 설정도 못 고친다(중앙 약 2.0~2.4 m, 점 4만 → 약 6천). 그 크기의 자세 오차는 이웃 선택이 아니라 자세 정제로 풀어야 한다.
- 기본값은 바꾸지 않았다. 최소 8도 기본에서 기존 시험 4개가 깨졌다: 4 위치(기선 짧음) 장면은 점 0개, 편대 이웃 순위 시험 2개, 융합 편대 시험 1개(이웃 8장 보장 가정). 모자란 이웃을 작은 각으로 채우는 변형도 해 봤으나 이득이 사라졌다(잡음 중앙 0.3927, 정답 0.0535로 오히려 정답 악화). 이득은 "넓은 기선 이웃만 쓰는 것"에서 나온다.

## 스트림 경로 영향 (F-330)
- `pipeline_stream`(3구역, 320×180 입력, `dense_width` 80 → 깊이 지도 80×45)에서 문턱: 상한 없는 면적 비례 = 2 화소(PR #58 c704bf6), 하한 포함 = 4 화소(base 463d345 와 병합 후 f8fcf2b).
- 스냅샷 점 수: base 463d345 [236, 4432, 6696, 8291] → c704bf6 [365, …, 7056, 8722] → 병합 후 f8fcf2b [236, 4432, 6696, 8291] (base 와 같음). 병합 후 기본 스트림 출력은 base 와 달라지지 않는다.
- 표면 거리: `pipeline_stream` 은 표면 거리를 재지 않는다(점 수·정렬 잔차만 출력; 병합 후 정밀 재정렬 잔차 중앙 [0.103, 0.051, 0.103] m). 같은 80×45 지도의 직접 측정은 위 표(2 화소 → 4 화소: 스윕 중앙 0.1486 → 0.1397, 패치매치 0.1465 → 0.1177).
- `pipeline_e2e`(병합 후): 단구역 점 10302·표면 중앙 0.336/95% 0.932 m, 2구역 점 18575·0.431/1.336 m·겹침 0.253 m, 2/2 통과. base 와 같다(960 폭 아님: e2e 도 상한 400 이 적용되는 지도 크기는 아니므로 변화 없음).

## 방법
- 두 시점 깊이 오차 ≈ 회전 오차 / 삼각측량 각이므로 작은 각 쌍을 이웃 점수에서 뺀다. 쌍 점의 광선 각이 최소 각보다 작으면 그 점수 0.
- 이웃 선택 설정(최소 각·목표 각·아래/위 폭·상한 각)을 NeighborConfig 로 노출. 기본값은 이전 동작(최소 0도, 상한 180도).
- 자세 잡음: 사진마다 독립인 중심 가우스 잡음과 임의 축 회전 잡음(씨앗 7). 깊이·반점 제거·융합은 공개 API 로 같은 순서로 구성하고 이웃 선택만 교체.
- 12도 설정: 목표 12도, 아래 폭 4도.

## 남은 문제
- 사진별 자동 최소 각(50% 분위)을 기본으로 하려면 깨진 시험 2개의 가정(편대 이웃 순위·이웃 8장)을 새 동작에 맞춰 고쳐야 한다. 960 폭 스윕에서 자세 잡음 효과, 문턱 400 이 잡음 자세에서도 좋은지는 재지 않았다.
- 960 폭 측정은 정답 자세만이다.
- 최소 각을 기본으로 하려면 이웃이 모자랄 때의 처리가 필요하다(작은 각으로 채우면 이득 소실). 장면별 기선 분포에 맞춰 최소 각을 고르는 방식(예: 사진별 후보 각 분포의 하위 분위 기준)이 후보.
- 기존 이웃 순위·융합 편대 시험이 "1칸 이웃이 하위"·"이웃 8장"을 가정하므로 기본 변경 시 같이 손봐야 한다.
- 이웃 설정은 DenseConfig 로 전달되도록 했고 기본값은 이전 동작이다. 새 단위 시험 `neighbor_config_options_on_tiny_scene` 이 최소 각·상한 각·자동 분위·채움을 확인한다. 단 `min_keep` 채움 조건 `out.len() < want` 를 `<=` 로 바꾸면 같은 값에서 안쪽 `>= want` 검사가 즉시 끝나 동작이 같아(동치 변이) 시험이 잡을 수 없다. 안쪽 `>=`→`>`, `min(k)` 제거 변이는 시험이 잡는다(확인함).
- 960 폭 상한 400 은 병합 후에도 e2e·스트림 시험이 닿지 않는 크기라 시험은 `speckle_min_px` 단위 시험(960×540→400, 80×45→4)뿐이다.
- 0.2도 이상의 자세 오차는 이웃 선택으로 해결되지 않는다.
