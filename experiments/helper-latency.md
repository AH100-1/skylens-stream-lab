# 뒤쪽 보조 사진이 초벌 도착을 늦추는 문제 (F-348)

## 결론
- 기록 추가: 구역마다 "마지막으로 읽은 위치 − hi" 와 보조 수를 report.json 의 events 줄에 남긴다.
- 기본 27위치(구역 3개, SPAN 12)에서 기존 방식(초벌에도 뒤쪽 보조)은 구역 0 이 hi+12 위치(장면 끝 가까이)까지 읽는다. 지연이 SPAN(12위치)과 같은 수준이 아니라 장면 전체에 묶인다.
- 대안 "초벌은 뒤쪽 보조 없이, 정밀만 뒤쪽 보조 포함" 은 구현해 선택 가능하게 했다(`--coarse-back off`). 초벌이 읽는 마지막 위치는 모든 구역에서 hi−1 이 되어 지연이 0 이 된다.
- 그러나 기본 경로 verify 가 7/7 에서 5/7 로 떨어진다(초벌 등록 61/81, 구역 0 은 14/42). 기준(7/7 유지)을 못 채워 **기본은 켬(기존 동작) 으로 둔다.** 소유자 결정이 필요하다.
- 80위치·stride 1 측정과 back_step 4 + 나머지 맞춤 F 보조 대안은 시간이 모자라 못 돌렸다.

## 수치 표 (기본 합성 장면, 27위치, SPAN 12, ovl 2, 기본 인자)
같은 기계에서 두 실행을 동시에 돌려(4 코어 측정 기계, 다른 작업도 동시 실행) 시각·실행 시간은 절대값으로 믿을 수 없고 둘의 상대 비교만 참고용이다.

| 방식 | 구역 | 사진(소유+보조) | 보조 | 마지막 위치 − hi | 초벌 등록 | 초벌 출력 시각 |
|---|---|---|---|---|---|---|
| 기존(초벌에도 뒤쪽 보조) | 0 | 68 (42+26) | 26 | 12 | 42/42 | 294.2 s |
| 기존 | 1 | 60 (48+12) | 12 | 0 | 48/48 | 421.7 s |
| 기존 | 2 | 37 (15+22) | 22 | -1 | 15/15 | 471.5 s |
| 초벌 뒤쪽 보조 없음 | 0 | 42 (42+0) | 0 | -1 | 14/42 | 140.0 s |
| 초벌 뒤쪽 보조 없음 | 1 | 58 (48+10) | 10 | -1 | 48/48 | 430.6 s |
| 초벌 뒤쪽 보조 없음 | 2 | 37 (15+22) | 22 | -1 | 15/15 | 500.2 s |

| 방식 | verify | 등록(초벌/정밀) | 정밀 재투영 | run 시간 |
|---|---|---|---|---|
| 기존 | 7/7 통과 | 81/81, 81/81 | 0.247 px | 478 s |
| 초벌 뒤쪽 보조 없음 | 5/7 (registered, preview_align 실패) | 61/81, 81/81 | 0.247 px | 516 s |

정밀 쪽 구역별 등록은 두 방식 모두 소유 사진 전부(42/42, 48/48, 15/15). 초벌 뒤쪽 보조 없음에서 초벌 재투영 2.182 px (기존 1.409 px), 구역 간 스케일 차 13.48 % (기준 10 %).

## 방법
- 구역 사진 목록을 만들 때 `HelperConfig::coarse_back` 가 거짓이면 초벌은 뒤쪽 보조(back_span=0) 없이 등록·점군을 만들고, 정밀 스레드가 뒤쪽 보조 사진을 직접 읽어 구역 전체를 다시 매칭·등록한 뒤 BA 를 한다. 다시 등록이 실패하면 초벌 등록 결과로 BA 한다.
- 기록 줄: `region N images A (own B + helper C) last position - hi L`, 정밀 완료 줄에 구역 전체 사진 수·보조 수·소유 등록 수.
- 시험(`crates/cli/tests/helper_latency.rs`): 22위치·span 8 에서 초벌 보조 끄면 모든 구역 L = -1, 켜면 마지막 구역 외 L > 0.
- 80위치 장면은 `synth` 명령에 위치 수 인자가 없어(SceneConfig 기본 80위치, run 의 stride 3 으로 27위치가 됨) 같은 시험 파일의 무시(ignored) 시험으로 쓴다. `run` 에 `--stride 1` 을 줘야 80위치가 된다.

## 남은 문제
- 80위치·SPAN 12·stride 1 의 구역별 표(초벌 지연, 구역당 사진 수 최대 약 90, 등록 시간): 못 돌림. synth 한 번이 측정 기계에서 약 4분이고 run 은 27위치도 8분 가까이 걸렸다.
- 초벌 보조 끄기가 실패하는 원인은 구역 0 의 R·L 이 다른 카메라 짝(F 보조는 구역 앞쪽이라 구역 0 에는 없음)을 못 받아서다. back_step 4 + 나머지 맞춤 F 보조, 또는 초벌에만 hi+SPAN 정도의 짧은 뒤쪽 보조(예: back_span 을 SPAN 으로 제한) 를 시험해야 한다.
- manifest 의 events 에는 새 필드를 넣지 못했다(맡은 파일 밖).
