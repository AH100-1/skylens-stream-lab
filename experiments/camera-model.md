# T02 camera-model — 왜곡 핀홀 투영·역투영·야코비안

## 결론
채택 제안. 핀홀 + k1,k2,p1,p2 왜곡 투영, 뉴턴법 역왜곡, 세계점·자세(왼쪽 섭동 회전 + 이동)·내부 파라미터 8개에 대한
해석적 야코비안을 넣었다. 중앙 차분 수치 미분과의 최대 상대 오차 1.16e-7 (기준 1e-6).
`experiment/synthetic-scene`(#2) 위에서 땄다.

## 수치
| 검증 | 기준 | 결과 |
|---|---|---|
| 야코비안 vs 중앙 차분(h=1e-6), 3점 × (3 + 6 + 8) 열 × 2 행 | 상대 오차 < 1e-6 | 최대 1.16e-7 |
| 왜곡 → 역왜곡 왕복 (200점, |x|≤0.6, |y|≤0.35) | < 1e-12 | 통과 |
| 투영 → 역투영 정규 좌표 | < 1e-12 | 통과 |
| 왜곡 0 이면 핀홀과 일치 | < 1e-12 px | 통과 |

상대 오차 = |해석 − 수치| / max(|수치|, 1).

## 방법
- `crates/core/src/distortion.rs`: `Distortion`(왜곡·야코비안·역왜곡), `DistortedIntrinsics::project_with_jacobian`.
- 유도: `docs/derivations/camera-jacobian.md` (방사·접선 모델 Brown 1966).
- 시험 카메라: fx 820, fy 815, 주점 (481, 268), k1 −0.12, k2 0.03, p1 0.001, p2 −0.0015, 임의 자세.

## 남은 문제
- 기존 `camera::Camera`(왜곡 없음)와 `DistortedIntrinsics` 가 따로 있다. 번들 조정(T08) 전에 하나로 합칠지 정한다.
- 합성 렌더러는 아직 왜곡 없이 렌더한다.
- 역왜곡은 왜곡이 단조인 범위에서만 보장한다(강한 배럴 왜곡 가장자리에서 실패 가능 → None 반환).
