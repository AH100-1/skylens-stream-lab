# 회전 평균 (T06 rotation-averaging)

## 결론
- `rotation_averaging::average_rotations` 추가: 다수결 탐욕 초기화 → 코시 IRLS 가우스–자이델 → 이상치(잔차 > 5°) 제거 → 리 대수 선형 최소제곱(가우스–뉴턴, 촐레스키). 유도는 `derivations/rotation-averaging.md`.
- 합성 장면 240대(80 위치 × 3 카메라), 간선 942개(같은 카메라 1~3칸 시간 이웃 + 같은 위치 카메라 간)에서
  - 잡음 0: 최대 오차 7.7e-14°.
  - 간선 잡음 축당 σ = 0.5/1/2°: 평균 오차 0.53/1.06/2.12° (≈ 1.06σ). 추정 비용이 정답 회전에서의 비용보다 작음 → 최소제곱 전역 최적에 도달.
  - 간선 10%(94개)를 임의 회전(축당 1 rad)으로 오염 + σ = 1°: 이상치 94개 모두 검출, 놓침 0, 오거부 0, 평균 0.82° 최대 2.10°.
- 연결 안 된 정점은 None, 범위 밖 번호·간선 없음은 None, NaN 회전·0 가중치·자기 간선은 무시(패닉 없음).
- 전체 테스트 59개 통과(fmt·clippy 통과).

## 수치

| 경우 | 평균 오차(°) | 최대 오차(°) | 비용(추정) | 비용(정답) | 비고 |
|---|---|---|---|---|---|
| 잡음 0 | 4.8e-14 | 7.7e-14 | — | — | |
| σ = 0.5° | 0.529 | 1.267 | 0.1662 | 0.2197 | 문턱 5° |
| σ = 1° | 1.058 | 2.540 | 0.6646 | 0.8789 | 문턱 5° |
| σ = 2° | 2.120 | 5.106 | 2.658 | 3.516 | 문턱 10°(=5σ) |
| σ = 1° + 이상치 10% | 0.823 | 2.102 | 0.5198 | 0.7461 | 검출 94/94, 오거부 0 |

비용 = 정상 간선 Σ d² (rad²). σ = 2° 에 기본 문턱 5° 를 쓰면 정상 간선 일부가 이상치로 빠져 평균 2.65° 로 나빠졌다(간선 각 오차 평균 ≈ 1.6σ = 3.2°). 문턱은 잡음의 5배 이상이어야 한다.

### 고치기 전 판(테스트가 항상 참이 아님을 보이는 기록)
- 초기화를 무작위 신장 트리 16개 중 최다 일치로 했을 때: 이상치 10% 장면에서 평균 60.4° 최대 134.5°, 이상치 17개 놓침, 정상 224개 오거부 → 테스트 실패.
- 선형 최소제곱 없이 가우스–자이델만(최대 200회): σ = 0.5° 에서 400회 돌고도 평균 1.03° 최대 2.74°(수렴 안 함) → 비용 조건·평균 조건 실패.

## 방법
- 정답: `Scene::new(SceneConfig::default())` 의 `views[v].camera.pose.rotation`.
- 간선 R_ij = exp(σ·n) R_j R_iᵀ, n ~ N(0, I₃) (결정적 splitmix 난수). 이상치는 σ = 1 rad.
- 오차: 세계 회전 G 로 맞춘 뒤(`aligned_errors`) 정점별 각.
- 테스트: `exact_graph_recovers_truth`, `noisy_graph_error_below_edge_noise`(평균 < 1.5σ, 비용(추정) ≤ 비용(정답)), `outlier_edges_are_rejected`(놓침 0, 오거부 ≤ 1%, 평균 < 1.5° 최대 < 4°), `disconnected_and_invalid_inputs`.

## 남은 문제
- 정규 방정식을 밀집 행렬(3N × 3N)로 푼다. N = 240 이면 720² 로 충분히 빠르지만(테스트 전체 0.3초), 수천 대면 희소 촐레스키나 켤레 기울기가 필요하다.
- 간선 잡음은 등방 가정. 실제 `recover_pose` 결과의 잡음(시차 작은 시간 이웃 쌍은 회전이 더 정확하고 이동이 부정확)을 반영한 가중치는 아직 없다. 지금은 `weight`(예: 정상 대응 수)만 쓴다.
- 실제 영상 파이프라인(특징 → 매칭 → recover_pose → 회전 평균) 종단 시험은 아직 없다. 순수 회전 판정으로 None 이 된 쌍도 회전은 쓸 수 있으므로, 회전만 돌려주는 경로가 필요하다(degenerate-inputs 남은 문제).
