# 초벌 삼각측량과 2구역 거름 하한 합치기 (pipeline-merge-2206)

## 결론

- 두 후보를 합쳐도 서로 부딪치는 곳은 한 줄뿐이었고(초벌 광선 각 거름 호출), 설정값 `preview_min_ray_deg` 를 쓰면서 점 수 하한만 50 으로 정리했다.
- 단구역: 7/7 유지, 초벌↔정밀 높이 차 1.553 → 1.114 m, 최근접 1.416 → 1.109 m.
- 2구역: 여전히 6/7 (preview_vs_refined 만 실패). 높이 차 5.829 → 4.555 m, 최근접 4.923 → 3.515 m 로 줄었으나 기준(높이 차 2 m, 최근접 3 m)에는 못 미친다. 각각 단독 효과(6.278 → 3.469 m)만큼은 겹쳐지지 않았다.
- 대가: 2구역 preview_align 이 verify 는 통과하지만 시험의 이전 상한을 못 맞춘다(점쌍 최소 1221 → 1170, 구역 간 스케일 차 0.05% → 1.66%). 단구역 정밀 점 95% 표면 거리도 1.465 → 1.896 m 로 커졌다. 이 상한들은 느슨하게 하지 않았고, 그래서 `pipeline_e2e` 두 시험은 지금 실패 상태다.

## 방법

1. `origin/feat/pipeline-merge-2106`(e064aab) 에서 작업 가지를 따고 preview-tri(66fce68) 를 병합 커밋으로, 이어서 two-region-height(bec30fb) 를 병합 커밋으로 합쳤다.
2. 충돌은 `crates/core/src/pipeline.rs` 의 구역 초벌 `well_conditioned` 호출 한 곳. 한쪽은 `cfg.preview_min_ray_deg`, 다른 쪽은 상수와 하한 50 이어서 `cfg.preview_min_ray_deg` + 하한 50 으로 정리했다. 다른 두 호출(옵션 거름·진단 시험)의 200 은 그대로 뒀다.
3. README 명령 그대로: `synth scene 320 180`, 단구역 `run --stride 2`, 2구역 `run --stride 1`(공통 `--span 48 --ovl 2 --max-features 800 --dense-width 96 --hfov 65 --ba-iters 15`), 각각 `verify`.

## 남은 문제

- 2구역 preview_vs_refined 는 여전히 높이 차 4.555 m. 구역 0 은 하한 50 으로 거름이 켜졌지만 삼각측량 개선과 합쳤을 때 단독 3.469 m 까지 내려가지 않는 이유를 구역별로 나눠 봐야 한다(어느 구역이 중앙 최대인지 아직 확인 안 함).
- 합침 뒤 preview_align 점쌍 수와 스케일 차가 나빠진 원인(초벌 점이 달라져 구역 간 짝이 줄어든 것으로 추정, 미확인). 단구역 중심 오차 최대가 2.912 → 1.051 m 로 크게 달라진 것도 정밀 단계가 초벌에 의존하는 경로가 있는지 확인이 필요하다.
- `pipeline_e2e` 상한 두 곳은 위 원인이 정리될 때까지 실패 상태. `--test pipeline` 은 미실행.
- `preview_default_pose_error_bounds` 는 부모에서도 실패(회전 중앙 1.48° > 1.2°).
