# 구역 2개 종단 시험: 주석 수치와 출력 수치 대조

## 결론
`synthetic_two_region_end_to_end`(기본 설정, 초벌 BA 0회)의 출력을 다시 받아 시험 파일 주석을 출력과 맞췄다. 단언 문턱은 그대로이며 시험은 통과한다. 주석에 있던 수치 다섯 개가 이전 실행값이어서 고쳤고, 출력에만 있던 중심·표면 수치는 주석에 추가했다. verify 는 7항목 중 6개 통과, `preview_vs_refined` 만 미달(SPEC 목표 높이 차 < 2 m)이다.

## 수치 표
4 코어 측정 기계, 측정 중 부하 평균 약 16(다른 작업과 공유). 수치는 시험 출력 원문.

| 항목 | 출력 | 이전 주석 | 단언 |
|---|---|---|---|
| 등록 수 | 240/240 (초벌 240/240, 정밀 240/240) | 240 | == 240 |
| 구역 수 | 2 | - | >= 2 |
| 중심 오차 중앙 / 최대 | 0.279 m / 3.152 m | 없음 | 중앙 < 2.5 |
| 표면 거리 중앙 | 0.446 m | 없음 | < 4.5 |
| 정밀 재투영 | 0.284 px (초벌 3.209 px) | - | 통과 |
| 초벌 정렬 점쌍 최소 | 1211 | 1221 | >= 1200 |
| 구역 간 스케일 차 | 0.36% | 0.05% | <= 1.0 |
| 초벌 정렬 잔차 중앙 최대 | 4.965 m | 5.130 m | < 6 m |
| 초벌↔정밀 높이 차 중앙 최대 | 4.590 m | 5.829 m | 2 < 값 < 8 (미달 판정 유지) |
| 초벌↔정밀 최근접 중앙 최대 | 4.100 m | 4.923 m | 단언 없음(SPEC < 3 m) |
| 겹침 차 중앙 최대 (1쌍) | 0.285 m | 0.257 m | < 0.3 m |
| 스냅샷 | 3단계, PLY 3개, 점 1540→12362, final 20188, 새 영역 최소 1038 | - | 통과 |

verify 항목별: registered 통과, region_images 통과, refined_reprojection 통과, preview_align 통과, preview_vs_refined 미달, refined_overlap 통과, snapshots 통과.

## 방법
`cargo test --release -p skylens-stream --test pipeline synthetic_two_region_end_to_end -- --nocapture`, 흐름 가지 e1dc44c. 출력의 CASE 줄과 SPEC 목표 줄을 그대로 옮기고 주석과 한 줄씩 대조했다. 주석만 고쳤고 println 은 추가가 필요 없었다(주석의 모든 값이 이미 출력에 있다).

## 남은 문제
- 이전 주석값과 이번 출력값이 다르다(예: 높이 차 5.829 → 4.590 m). 두 실행 사이 코드 변경 때문인지는 확인하지 않았다.
- 겹침 차 0.285 m 는 문턱 0.3 m 에 가깝다. 여유가 작다.
- `preview_vs_refined` 는 여전히 SPEC 목표에 못 미친다.
