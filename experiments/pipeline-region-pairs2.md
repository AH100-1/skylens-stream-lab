# pipeline-region-pairs2

## 결론
- 가설 확인: 구역 1 의 정렬 창 [46,50) 은 4 위치 x 3 카메라 = 12 이미지뿐이고, 이 안의 트랙 324 개가 점쌍의 전부였다. 초벌·정밀 트랙은 같은 트랙 집합(관측 일치율 100%)이라 점쌍은 곧 창 안 트랙 수다.
- 대응을 구역의 모든 이미지의 공유 관측(같은 이미지·같은 특징 번호)으로 넓혀 구역 1 점쌍 324 → 1221, 2구역 verify 5/7 → 6/7 (preview_align 통과).
- 목표 점쌍 >= 1500 은 미달(최소 1221): 구역 트랙 총수가 구역 0 에서 1310, 구역 1 에서 1442 로 상한이다. 대응을 더 늘리려면 트랙 자체(특징 수·매칭)를 늘려야 한다.
- 높이 차(preview_vs_refined)는 6.278 → 5.829 m 로 소폭 개선, 2 m 기준 미달 유지.
- 단구역: 구역 0 은 이전에도 구역 전체 창을 써서 코드 경로가 동일(점쌍 2746 은 stride 2 설정 값). 단구역 시험은 이번에 다시 돌리지 않았다.

점쌍이 버려지는 단계(구역 1, 후): 구역 트랙 1442 → 전 이미지 관측 대응 1442(손실 0, 일치율 100%) → 구역 범위 [46,80) 안 관측이 있는 쌍 1221 → 강건 적합 내점 약 1154 (전 이미지 기준).

## 방법
- `own_align` 기본 경로의 점쌍 수집 범위를 정렬 창에서 구역 `[lo,hi)` 전체로 변경(`point_pairs`, 같은 이미지·특징 번호를 가진 두 트랙을 짝, 중복 쌍 1회). 창 범위는 `SKYLENS_PAIR_SCOPE=window` 로 되돌릴 수 있다.
- 진단 `SKYLENS_PAIR_DEBUG=1`: 창 통계와 전 이미지 점쌍 수·강건 내점 수를 PAIRDBG 로 출력.
- 시험 `synthetic_two_region_end_to_end`: preview_align 통과 단언(점쌍 >= 1200, 스케일 차 <= 1%, 잔차 < 6 m)으로 갱신, 높이 차 미달 단언 유지.

## 남은 문제
- 점쌍 1500 이상: 트랙 수 상한. 특징 수·매칭 확대가 필요하다.
- 구역 0 잔차 5.130 m 와 높이 차 5.8 m: 초벌(BA 없음)의 구역 내 드리프트라 닮음 변환 하나로 줄지 않는다.
- 단구역 시험·SKYLENS_REGION_SIM3 모드 1/2 와의 조합은 미측정.
