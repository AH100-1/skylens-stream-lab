# ta-sparse: 위치 평균 풀이의 희소화

## 결론
점 번호 압축과 점 소거(카메라 축소 계통) 구성은 들어갔고 기존 시험은 통과한다. 그러나 240장 x 장당 4000 관측 측정은 아직 기준(수십 초, 1 GB)에 못 미친다. 반복마다 축소 행렬을 점 수 x (점당 카메라 수)^2 로 만드는 비용이 남아 있다.

## 수치
| 항목 | 값 |
|---|---|
| 기존 시험 `translation_averaging` | 10 통과, 0 실패 (51.9 s) |
| 측정 시험 240장 x 4000 관측, 점 5000, 번호 0 / 1e6 두 번 | 합 772 s (부하 평균 약 17 인 4 코어 측정 기계, 시간 신뢰 불가), 단언 실패 |
| 메모리 | 미측정 |

## 방법
- 쓰인 점 번호를 0.. 으로 압축하고 결과를 원래 번호로 풀어 돌려준다.
- 정규방정식은 점 블록이 스칼라 대각이므로 점을 소거한 n_cam x n_cam 밀집 계통만 촐레스키로 풀고 점은 역대입한다. 게이지(규약·릿지·첫 관측 d = 1)는 그대로.

## 남은 문제
- 축소 행렬 구성이 반복당 약 2.9e8 곱셈(점 5000, 카메라 240, 가시율 80%) x 최대 1200 회. 해결안: 점-카메라 가중 행렬 B 로 S = B diag B^T 를 블록 gemm·병렬로 구성하거나, 축소 계통에 블록 야코비 전처리 공액 기울기(행렬곱 O(관측))를 쓰고 가중이 거의 안 변하는 반복은 분해를 재사용.
- 측정 시험 어느 단언에서 실패했는지 한가한 기계에서 다시 확인 필요. 소수 4자리 동일성은 기존 시험의 수치 단언 통과로만 확인.
