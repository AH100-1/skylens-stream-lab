# 번들 조정 강건화 시험 단언 보강

## 결론
- 축 회전 고정 시험에 회전 차 단언(`rot < 1e-6`)을 넣었고, 축척 고정 시험에 촐레스키 실패 0 단언을 넣었다. 두 시험 모두 통과.
- 회전 차의 실측은 각도 계산의 수치 바닥(약 3e-8 rad)이다. 사전항 없는 실행도 같은 바닥이라 "사전항 없을 때보다 줄었음" 비교는 의미가 없어 넣지 않았다(축 고정을 끈 상태를 따로 만들 수 없다).

## 수치 표
| 단언 | 실측 | 상한 |
|---|---|---|
| 두 감쇠 초기값 실행의 최대 회전 차 | 2.98e-8 rad | 1e-6 |
| 중심 최대 차(기존) | 2.98e-9 | 1e-6 |
| 촐레스키 실패 수(감쇠 1e-12, 1e-4) | 0, 0 | 0 |
| 축척 고정 카메라 거리 상대 차(기존) | 4.1e-11 | 1e-9 |

## 방법
합성 장면에서 감쇠 초기값 1e-12 와 1e-4 로 각각 최적화하고 포즈를 비교했다. 측정 기계 4 코어, release 빌드.

## 남은 문제
- 같은 (카메라, 점) 중복이 `num_observations_rejected` 에 섞이는 점은 보고 필드 분리 없이 남아 있다.
