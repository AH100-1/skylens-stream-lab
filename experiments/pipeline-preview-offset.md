# 초벌 공통 회전 오프셋 분해 (pipeline-preview-offset)

## 결론

- stride 1 의 초벌 포즈 회전 오차 중앙 2.75° 는 전부 좌표계 맞춤의 롤 선택 단계에서 생긴다. 방향 맞춤(Kabsch) 직후는 0.80°, 롤 선택 직후 2.75° 이고, 이후 위치 풀이·위치 다듬기는 회전을 건드리지 않아 2.75° 그대로다. 회전 평균 직후는 공통 회전 하나를 빼면 0.16° 라서 평균 자체는 문제가 없다.
- 공통 회전 2.76° 의 성분은 비행 축 둘레 -2.23°, 축에 수직 1.62° 다. 방향 맞춤만 쓴 상태의 공통 회전은 0.79°(축 둘레 +0.42°)였다. 즉 광축 높이 분산 최소 규칙이 고른 롤이 방향 맞춤이 이미 정한 롤보다 나쁘다. stride 2 는 방향 맞춤의 롤이 8.0° 틀어져(특이값 비 0.003) 롤 선택이 0.48° 로 고쳐 준다. 단순히 롤 선택을 없앨 수는 없다.
- 초벌 정렬(3D 점 닮음)은 이 오프셋을 정밀 쪽으로 옮겨 놓을 뿐이고(정렬 뒤 회전 오차 그대로 1.91°, 공통 회전 빼면 0.16°), 정밀과의 비교 지표에는 거의 영향이 없다. stride 1 구역 0 에서 초벌↔정밀 최근접 중앙 0.436 m(기준 < 3 m), 높이 차 중앙 0.570 m(기준 < 2 m). 오프셋이 3D 점 닮음 안에 흡수되므로 기준과 동떨어진 값이 아니다.
- 방향 맞춤의 둘째/첫째 특이값 비가 충분히 클 때만 롤 선택을 건너뛰는 옵션(`kroll`)을 넣어 재 보니 stride 1 에서 회전 오차 0.80°, 최근접 중앙 0.384 m, 높이 차 0.498 m 로 소폭 좋아졌다(차이 0.05~0.07 m). 근거가 장면 둘뿐이고 지표는 이미 기준에 충분히 못 미쳐서 기본은 끈 채(0) 두었다. 흐름 기본 동작은 바뀌지 않는다.

## 방법

- 진단용 `PreviewStages` 에 방향 맞춤 직후 g(롤 전), 롤 선택 뒤 g, 방향 맞춤 특이값을 추가했다. 측정 시험 `preview_offset_stages`(`#[ignore]`, `SKYLENS_STRIDE`, `SKYLENS_RATIO`)가 구역 0 만 초벌 경로로 돌려 단계마다 정답 포즈와 비교한다.
- 공통 회전 Q 는 모든 사진에서 R_i Q ≈ T_i 가 되는 최소제곱 해(Σ R_iᵀ T_i 의 폴라 분해). 크기는 회전 벡터를 정답 비행 축(첫 사진에서 끝 사진 방향의 수평 성분)에 사영해 축 둘레와 수직 성분으로 나눴다.
- 4 단계는 흐름과 같게: 초벌 포즈 사본에 GPS 사전 BA 10회와 GPS 닮음 정렬로 정밀을 만들고, 구역 점 대응에 `align_region` 의 반복 트리밍 닮음(5회, 임계 max(3×잔차 중앙, 0.3 m))으로 초벌을 맞춘 뒤 닮음 변환을 포즈와 점에 적용해 비교했다. 점군은 폭 96 스윕 조밀화.
- 주의: 이 4' 의 정밀은 같은 초벌 포즈에서 출발한 BA 라 롤 오프셋을 물려받는다(BA 10회로 비행 축 롤이 풀리지 않는다). 흐름의 정밀 BA 는 예전 롤 규칙(2° 격자)으로 만든 시작점을 쓰므로 정밀 쪽 롤은 다를 수 있다.

## 남은 문제

- 롤 선택(광축 높이 분산 최소)의 축 둘레 오차가 stride 1 에서 2.2° 다. 방향 맞춤의 둘째 특이값이 충분하면 방향 맞춤 롤이 더 좋다(0.42°). 건너뛰는 문턱(둘째/첫째 특이값 비 0.01 부근이 두 장면을 가른다)을 정하려면 비행 패턴이 다른 장면(곡선·카메라 간격 변화, GPS 잡음 증가)이 더 필요하다. 지금은 두 장면뿐이라 기본을 바꾸지 않았다.
- 정렬 뒤 초벌 중심의 정답 대비 오차는 오히려 커진다(0.49 → 0.64 m). 점 닮음이 점을 기준으로 맞추고 중심 위치를 직접 맞추지 않기 때문으로 보이나 원인 분해는 못 했다.
- 단구역 전체 흐름(span 100)·2구역에서 같은 분해는 하지 않았다(구역 0 한 번만 측정).
