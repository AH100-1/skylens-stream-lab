# 초벌 뒤쪽 보조 없음(--coarse-back off) 에서 정밀 다시 등록의 앞 구역 기준 처리

## 결론
- 지적된 상황(정밀 쪽이 뒤쪽 보조까지 넣어 다시 등록하는데 앞 구역 기준이 적용되지 않고 GPS 맞춤도 빠짐)은 현재 기본 설정에서는 실제로 일어나지 않는다. 앞 구역 기준 기능은 상수 `ANCHOR_NEXT_REGION = false` 로 꺼져 있어 기준이 항상 없음이고, 이때는 `gps_align_refined` 가 이미 돈다. 이벤트 기록에도 `anchor region N none` 만 나온다.
- 13.48 % 스케일 차는 정밀 쪽이 아니라 초벌 미리보기 정렬(preview_align)의 값이다. 정밀 구역 이음은 `--coarse-back off` 에서도 잔차 중앙 0.03~0.04 m, 겹침 높이 차 중앙 최대 0.118 m 로 기본 경로 수준이다.
- 그래도 기능을 켤 때를 대비해, 다시 등록한 목록에서 고정 사진을 gid 로 다시 찾아 적용하고(3장 미만이면 포기), 적용하지 못하면 GPS 맞춤을 돌리도록 바꿨다. 기본 경로(coarse_back on)와 현재 꺼진 기준 상태의 동작은 그대로다.

## 수치 표 (27위치 기본 장면, 4 코어 측정 기계)
| 항목 | off | on(기본) |
|---|---|---|
| verify 통과 | 5/7 | 7/7 |
| 등록(초벌/정밀) | 61/81, 81/81 | 81/81, 81/81 |
| 초벌 구역 간 스케일 차 | 13.48 % | 5.77 % |
| 정밀 재투영 | 0.247 px | (7/7 통과) |
| 정밀 구역 이음 잔차 중앙 | 0.043, 0.030, 0.043 m | - |
| 정밀 겹침 높이 차 중앙 최대 | 0.118 m | 통과 |
| 실행 시간 | 3분 7초 | 2분 1초 |

off 의 실패 두 항목(registered, preview_align)은 모두 초벌 쪽이다. 수정 전후 off 결과가 같다(기준이 꺼져 있어 분기에 들어가지 않음).

## 방법
`pipeline.rs` 정밀 스레드에서 `full` 이 Some 이고 기준이 있으면, 초벌 gid 목록으로 기준의 고정 사진 번호를 gid 로 바꾸고 다시 등록한 목록의 번호로 대응시킨다. 등록된 사진만 3장 이상 대응되면 닮음 변환과 고정 자세를 적용, 아니면 GPS 맞춤. 시험 `coarse_back_off_keeps_refined_seams_tight`(22위치)는 off 경로의 정밀 재정렬 잔차 중앙값이 모두 1 m 미만임을 단언한다(측정 0.614 m). 이 장면은 작아서 27위치보다 느슨하다.

## 남은 문제
- 기준 기능을 켠 상태(상수 true)의 다시 등록 경로는 측정하지 못했다. 3구역 측정에서 기준이 오히려 나빴던 이유(초벌 닮음 변환 잔차 1.7~3.1 m)가 그대로 남아 있다.
- off 의 초벌 쪽 스케일 차 13.48 % 와 등록 61/81 은 별개 문제다.
- 검사: fmt·clippy 통과, helper_latency 2개·pipeline_arrival 2개·pipeline_stream_order 1개 통과.
