# ba-schur-memory: 슈어 구성 메모리·시험·스레드 불변

## 결론
- 슈어 보수 누적을 고정 조각 64개(점 수로만 결정) + 스레드 수 개의 재사용 버퍼 배치로 바꿔, 조각마다 n_cam² 부분 행렬을 모두 보관하던 것을 없앴다. 합 순서가 스레드 수와 무관해 1/4 스레드 결과가 일치한다(중심 차 ≤ 1e-12 시험).
- 300 반복 상한 도달의 원인 하나를 찾았다: 비용이 반올림 수준(1e-15)일 때 상대 변화 판정이 영원히 통과하지 못했다. 비용 바닥값(활성 관측당 1e-12)을 두자 척도 기준에 맞춘 정답 시작 무잡음 풀이가 12 반복에서 멈춘다. 무작위 초기값(냉시작)은 여전히 300 에 닿는다(미해결).
- 이동 판정은 중심 분포 크기(최소 1)에 대한 상대값, 주석 단위 정정.

## 방법
조각 경계 고정, 조각 배치별 병렬 계산 뒤 조각 순서로 행 병렬 합산. 시험은 합성 입력에서 단순 이중 루프, 밀집 정규방정식과 비교.

## 남은 문제
- 냉시작 300 반복 상한: 척도 기준(첫 관측 d = 1)과 중심·d 교대 풀이가 척도 골짜기를 천천히 흐른다고 보이나 확인 못 함.
- 카메라 블록 쌍 단위 희소 누적은 하지 않았다(버퍼는 여전히 n_cam²·스레드 수).
- 1000장 이상 실측 최대 메모리, 240장 시간·RMS 미측정.
