# 작은 사진 개선 후속: 시험 정리와 기본 경로 측정

## 결론

- 기본 경로(인자 없는 `run`, SPAN 12, 3구역)의 320x240 에서도 확대 검출 효과가 확인된다. 확대 검출을 넣은 병합 트리는 verify 7/7, 등록 81/81, 넣지 않은 #64 단독은 3/7, 등록 31/81 이다.
- 제품 시험 이름을 실제 단언과 맞췄다. 기존 시험은 좌표 복원 시험으로 이름을 바꾸고, 합성 장면 한 장(320x240)에서 확대 검출 수가 끔 검출 수보다 많음을 숫자로 단언하는 시험을 추가했다.

## 수치 표

### 확대 검출 수 (합성 장면 320x240 한 장, 사진당)

| 설정 | 검출 수 |
|---|---|
| 확대 끔(`upscale_below` 0) | 393 |
| 기본(확대 채움) | 2679 |

(`DetectorConfig` 기본은 특징 상한 설정이 검출기 안에 없어 상한 전 개수이다. 파이프라인은 이후 `--max-features` 로 자른다.) 좌표 복원 시험(240x160 덩어리 영상)은 끔 96, 기본 96 으로 같다(원래 크기 검출이 이미 상한의 절반 이상이라 채우지 않음). 이 시험은 개수가 아니라 좌표 범위와 중심 1 px 이내를 본다.

### 인자 없는 기본 경로, 합성 `synth <폴더> 320 240` → `run`(인자 없음) → `verify`

4코어 측정 기계, 두 측정을 동시에 돌려 시간은 흔들린다. 등록은 verify 의 registered 항목(위치 81개 기준, 기준은 240/240 사진). 구역 3개.

| 트리 | verify 통과 | 등록 | 구역별 자체 등록 | run 시간 | 실패 항목 |
|---|---|---|---|---|---|
| #64 + 작은 사진 개선(병합, 푸시 안 함) | 7/7 | 초벌 81/81, 정밀 81/81 | 48/48, 15/15 (구역 1·2) | 210 s | 없음 |
| #64 단독 | 3/7 | 초벌 31/81, 정밀 31/81 | 16/48, 5/15 (구역 1·2) | 83 s | registered, preview_align(점쌍 최소 215, 스케일 차 29.3%), preview_vs_refined, refined_overlap |

verify 시간은 둘 다 1 s 미만. 정밀 재투영은 병합 0.193 px, 단독 0.290 px.

## 방법

- 측정 트리: 작은 사진 개선 브랜치 머리(cd9a360)에 #64 브랜치(c11b451)를 로컬 병합(푸시 없음)한 것과, #64 브랜치 머리 단독. 각각 별도 빌드 폴더에 release 로 빌드.
- 명령: `skylens-stream synth <폴더> 320 240`, `skylens-stream run <폴더> <출력>`(추가 인자 없음), `skylens-stream verify <출력>`.
- 시험: `small_image_upscaled_keeps_original_coords`(이름만 변경), `small_image_upscaled_detects_more_on_textured_scene`(합성 장면 320x240, `b.len() > a.len()`).

## 남은 문제

- 기본 경로 수치는 1회 측정이다. run 시간은 두 측정을 동시에 돌려 서로 영향을 받았으므로(병합 쪽은 특징이 많아 시간도 더 걸림) 시간 비교는 참고만.
- 기본 경로의 다른 해상도(480x270, 640x360)는 재지 않았다.
