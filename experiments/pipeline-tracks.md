# 파이프라인 트랙: 임시 합집합 대신 다시점 트랙

## 결론
- 파이프라인의 초벌 희소 모델에서 쓰던 단순 합집합 트랙을 짝 대응 검증 + 변위 선거름 + 충돌 분할을 하는 다시점 트랙 구성으로 바꿨다. 호출부 변경은 어댑터 함수 하나다.
- 40위치(120장) 합성 종단 시험은 전후 모두 120/120 등록, 중심 오차 중앙·최대는 거의 같다(0.881→0.899 m, 3.824→3.832 m). 정확도 이득은 이 장면에서는 보이지 않았다.
- 트랙 수는 3213→3309(정밀 단계), 표면 거리 중앙 2.072→2.103 m 로 사실상 동일하다. 이 장면에서는 트랙 구성이 병목이 아니다.
- verify 는 전후 모두 6/7 통과이고 같은 항목(preview_vs_refined)이 실패한다. 원인이 트랙이 아님을 확인한 셈이다.

## 수치 표
| 항목 | 전 | 후 |
|---|---|---|
| 등록 | 120/120 | 120/120 |
| 중심 오차 중앙 / 최대 (m) | 0.881 / 3.824 | 0.899 / 3.832 |
| 점→표면 중앙 (m) | 2.072 | 2.103 |
| 정밀 점 수 | 11480 (구역 68875) | 11558 (구역 69345) |
| 정밀 트랙 수 | 3213 | 3309 |
| 재투영 초벌→정밀 (px) | 0.326→0.182 | 0.326→0.185 |
| verify 통과 | 6/7 | 6/7 |
| 총 시간 (s) | 146.5 | 135.9 |

후 단계 트랙 구성 통계(길이 2 이상, 초벌 모델 입력): 총 5389개, 길이 분포 2:1270, 3:832, 4:635, 5:521, 6:426, 7+:1705. 간선 69704, 충돌로 건너뛴 87, 변위 불일치 216, 길이 미달 25. 전 단계의 길이 분포는 기록하지 않았다.
시간 차이는 측정 기계 부하 편차 범위이고 매칭 시간이 대부분이라 트랙 구성 비용은 0.5 s 안쪽이다.

## 방법
- 짝별 검증 통과 대응과 영상별 특징 화소(+0.5)를 `tracks::build_tracks` 에 넣고, 충돌 처리는 분할 정책, 최소 길이는 2(삼각측량은 2뷰부터 가능하므로 기존과 같게)로 두었다.
- 결과는 기존과 같은 (사진, 특징) 목록 모양으로 돌려줘 삼각측량·번들 조정 쪽 코드는 건드리지 않았다.
- 시험은 합성 종단 시험 그대로 실행했고 수정하지 않았다.

## 남은 문제
- 최소 길이 3 은 시험하지 않았다. 두 뷰 트랙이 위치 추정 이후 삼각측량에서 오점을 만드는지는 별도 측정이 필요하다.
- 전 단계의 길이 분포를 같은 형식으로 남기지 못해 분포 비교는 정성적이다.
- 3~4 m 대의 중심 오차 최대값과 preview_vs_refined 실패는 트랙이 아닌 다른 단계의 문제로 보인다.
