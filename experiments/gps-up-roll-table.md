# 연직 고정 옵션: 롤 크기별 잔차 비·위 방향 각도·기울기 (F-367, F-368 후속)

## 결론

- 롤 0°·4° (시드 1, 2구역, 240장) 두 점만 쟀다. 롤 1°·2° 는 시간 안에 새 진단으로 재지 못했고, 롤 2° 의 잔차 비는 앞선 기록(gps-up-ratio.md, 시드 1 구역별 1.007/1.008)을 그대로 쓴다.
- 안전장치(잔차 중앙값 비 > 1.2 면 기존 해)는 롤 4° 에서도 걸리지 않았다. 비는 구역별 0.984/1.002 (롤 4°), 0.996/1.002 (롤 0°)로 롤 크기와 무관하다. 잔차 중앙값 2.3~2.4 m 가 GPS 잡음에 묻혀 있어서 롤이 달라도 비가 움직이지 않는다. 비교 집합을 공정하게(합집합) 바꿔도 같다: 합집합 크기가 기존 해 정상 대응 수(150, 142)와 같아, 고정 해가 새로 끌어들인 대응은 없었다.
- 롤 4° 에서 켬의 표면 중앙은 0.147 → 0.189 m (x1.29)로 1.2 배 한도 밖이다(끔 x1.2+0.01 = 0.186 m). 롤 0° 는 0.151 → 0.147 m. 중심 중앙은 롤 4° 0.175 → 0.169, 롤 0° 0.190 → 0.192 m 로 차이가 없다. 그러니 롤이 커지면 켬이 한도를 넘는 후퇴가 실제로 나오는데 안전장치는 그걸 못 본다. 단 한 장면이다.
- 구역 기울기(정답 대비 연직, 사진별 중앙값)는 구역 0 에서 끔이 2.6~2.8° 로 크고 켬이 0.4~0.5° 로 훨씬 작다. 구역 1 은 끔 0.17~0.19° 가 켬 0.13(롤 0°)~0.36°(롤 4°)보다 작거나 같다. 즉 연직 고정은 기존 해가 기운 구역을 바로잡지만(구역 0), 기존 해가 이미 맞는 구역에서는 롤이 커질수록 약간 기울이는 쪽으로 간다.
- 위 방향 각도(기존 해가 내포하는 위 vs 고정한 위)는 구역 0 이 2.19°(롤 0°)·2.33°(롤 4°), 구역 1 이 0.13°·0.42°. 롤 0° 에서도 구역 0 이 2° 를 넘으므로 이 각도는 "어느 쪽이 맞는가"가 아니라 "두 해가 얼마나 다른가"만 알려준다. 구역 0 에서는 고정 쪽이 맞고(기울기 0.4~0.5° 대 2.6~2.8°), 구역 1 에서는 각도 증가(0.13 → 0.42°)가 켬 기울기 증가(0.13 → 0.36°)와 같은 방향이다. 문턱은 이 두 점으로 정할 수 없다(다음 절).
- F-368 처리: 시험 이름을 gps_fixed_up_with_roll_noise_stays_within_1_2x_of_off 로 바꾸고 주석을 "1.2 배 안"에 맞췄다(롤 2° 에서 측정된 +15% 는 한도 안). F-367 의 확인 기준은 롤 4° 에서 켬이 끔보다 기울기는 구역 0 에서 개선, 구역 1 에서 악화(0.17 → 0.36°), 표면 중앙은 악화(x1.29), 기존 해로 물러나지 않음으로 충족되지 않는다: 물러남을 보인 측정이 아니라 물러나지 못한 측정이다.

## 방법

- 환경 변수 SKYLENS_GPS_UP_DIAG 를 주면 구역마다 (1) 위 방향 각도: 기존 해의 회전 역변환으로 세계 +z 를 복원 좌표로 옮긴 벡터와 사진 회전에서 구한 고정 위 방향의 각도, (2) 잔차 비교 집합 크기, (3) 기존/고정 잔차 중앙값·비·사용 해, (4) 정렬 뒤 사진별 중심과 카메라 좌표에서 본 세계 +z 를 표준 오류에 찍는다. 변수가 없으면 동작은 그대로다.
- 잔차 비교 집합: 이전에는 기존 해의 정상 대응만 썼다. 그러면 기존 해 쪽으로 기운다(그 집합은 기존 해가 고른 것). 이제는 기존 해의 정상 대응과, 고정 해 잔차가 max(3 x 고정 해 잔차 중앙값(기존 정상 대응 위), 3 m) 이하인 대응의 합집합에서 두 해의 중앙값을 잰다. 정상 판정 규칙은 기존 해와 같다. 이 장면에서는 합집합이 기존 정상 대응(150, 142)과 같았다.
- 기울기: 시험이 진단의 사진별 값(중심, 세계 +z)을 정답 카메라(가장 가까운 정답 중심)의 같은 벡터와 견줘 구역마다 각도 중앙값을 낸다. 끔 실행에서도 같은 진단이 나온다.
- 측정 시험: gps_fixed_up_ratio_sweep (수동, 기본 건너뜀).

```
cd <제품 작업 트리>
export RAYON_NUM_THREADS=2
GPSUP_ROLL=4 GPSUP_SEED=1 cargo test --release -j 2 -p skylens-stream --test pipeline_gps_up gps_fixed_up_ratio_sweep -- --ignored --nocapture
```

롤은 GPSUP_ROLL 로 바꾼다. 로그에서 "gps-up diag", "vertical tilt", "SWEEP" 줄을 본다.

## 남은 문제

- 롤 1°, 롤 2° 새 진단, 시드 2 롤 4° 미측정. 장면 두 개(롤 0°, 4°)와 시드 하나라서 경향만 본다. 표면 중앙 x1.29 도 한 장면이다.
- 문턱 제안은 하지 않는다. 구역 0 은 롤과 무관하게 위 방향 각도가 2.2~2.3° 이면서 고정 해가 맞았고, 구역 1 은 0.13 → 0.42° 로 커질 때 오히려 고정이 약간 나빠졌다. 이 각도 하나로는 "고정이 맞음"과 "고정이 틀림"을 가르는 문턱이 서지 않는다. 기존 해 쪽 기울기를 모르는 상태에서 둘의 차이는 어느 쪽이 맞는지 알려주지 않는다.
- 후보 척도: 구역 안 사진 회전의 연직 일치도 분산(고정 위 방향을 사진별로 본 편차), 겹치는 구역 사이 높이 차. 아직 재지 않았다.
- 시험 한도(끔 x1.2+0.01)는 롤 2° 용이다. 롤 4° 장면은 이 한도를 넘는다(x1.29).
