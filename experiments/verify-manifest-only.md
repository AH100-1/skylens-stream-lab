# verify: SPEC §2 출력만으로 항목 1~3 판정

## 결론
- 등록 사진(1)과 구역 사진 수(2)는 `preview/`·`refined/` 파일 이름의 위치 범위 `pos{lo}-{hi}` 에서 계산해 판정한다. `report.json` 이 있으면 그 값도 맞아야 통과하는 추가 검사로만 쓴다.
- 재투영 오차(3)는 SPEC §2 의 어떤 파일에서도 계산할 수 없다. `report.json` 이 없으면 FAIL 이 아니라 "판정 불가"(종료 코드 2)로 남는다. 이 항목은 출력 형식(SPEC)에 값을 올리지 않는 한 해결되지 않는다.
- `report.json` 을 지운 출력에서 항목 1·2·4~7 의 판정은 지우기 전과 같다(합성 장면 출력 3가지로 확인).

## 수치 표 (합성 장면: 구역 pos0-14, pos10-26)
| 항목 | report.json 있음 | report.json 없음 |
|---|---|---|
| 1 등록 사진 | PASS (초벌 240/240, 정밀 240/240 + 이름 계산 78/78) | PASS (초벌 78/78, 정밀 78/78) |
| 2 구역 사진 수 | PASS | PASS (구역 0: 14→42장, 구역 1: 16→48장) |
| 3 재투영 | PASS (0.700 px) | 판정 불가 |
| 4 초벌 정렬 | PASS | PASS |
| 5 초벌↔정밀 | PASS (1.990 m) | PASS (1.990 m) |
| 6 이웃 겹침 | PASS (0.290 m) | PASS (0.290 m) |
| 7 스냅샷 | PASS | PASS |
| 종료 코드 | 0 | 2 |

정밀 구역 이름을 pos20-26 으로 바꿔 위치 14..20 에 빈틈을 내면 report.json 없이도 1·2 가 FAIL(정밀 60/78), 종료 코드 1.

## 방법
- 등록: 초벌·정밀 각각 이름 범위 합집합이 0..마지막 위치를 빈틈없이 덮는지 계산, 위치 하나 = 사진 3장.
- 구역 사진 수: 구역마다 초벌·정밀 범위 동일, 0 에서 시작, 이웃과 겹쳐 이어짐을 확인하고 3 × 위치 수를 표시.
- report.json 이 있으면 기존 값 검사를 더해 둘 다 맞아야 통과. 깨진 파일은 FAIL.

## 남은 문제
- 1·2 는 "구역 파일이 위치를 덮는다"는 대리 지표이고, 실제 등록 실패 사진 수나 구역 밀집에 쓴 사진 수는 출력에 없다.
- 3 은 SPEC §2 에 재투영 값이 올라가기 전에는 판정 불가.
