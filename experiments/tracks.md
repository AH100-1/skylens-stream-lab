# tracks — 짝별 검증 대응에서 다시점 특징 트랙 만들기

## 결론
- 채택: (영상 번호, 특징 번호) 노드를 합집합-찾기로 묶어 트랙을 만든다. 입력은 매칭 단계 출력(`verified_matches`, 대응·정상 표시 길이가 다르면 오류).
- 기본 규칙 `Split`(2 단계). 1 단계: 삼각 지지도 > 0 간선을 지지도 내림차순으로 합치고 같은 영상 특징이 둘이 되면 건너뛴다. 2 단계: 지지도 0 간선을 1 단계 뒤 성분 쌍마다 묶어, 서로 다른 간선 수가 많은 쌍부터 영상이 겹치지 않을 때 합친다.
- 최신 변경(c8fa58d): 2 단계를 순서로 나눴다. 성분 그래프(지지도 0 간선을 성분 쌍으로 묶은 것)에서 간선 2 개 이상이거나 공통 이웃 성분(성분 단위 삼각형)이 있는 "강한" 쌍만 먼저 합치고, 성분 그래프를 다시 만들어 되풀이(최대 8 번)한다. 강한 쌍이 더 없으면 남은 단일 간선을 간선 수 순으로 마지막에 합친다. 참 트랙이 먼저 커지면 무작위 단일 간선 오대응이 나중에 영상 겹침(충돌)으로 걸러질 기회가 늘어난다는 가정.
- 결과: 재현율 30%·오대응 1% Split 순도 0.9672 → 0.9720, 완전도 0.9898 → 0.9922. 50%·1% 순도 0.9935 → 0.9972. 오대응 0 두 경우는 그대로 1.0000/1.0000. 순서만으로는 0.99 에 못 미친다 — **F-123 아직 일부**.
- 이전 변경: 2 단계의 "이미 자란 두 성분은 간선 2 개 이상" 문턱을 없앴다. 재현율 30% 에서 참 조각 사이 간선이 1 개뿐인 경우가 대부분이라 이 문턱이 완전도를 0.83 으로 묶고 있었다. 문턱을 없애자 네 경우 모두 Split 완전도 ≥ 0.989, 오대응 0 에서 Split = Drop(1.0000).
- **아직 미달(F-123)**: 재현율 30%·무작위 오대응 1% 에서 Split 순도 0.9672(기준 0.99). 문턱이 있을 때(0.9761)보다 낮다 — 문턱이 막던 단일 간선 오대응이 이제 충돌 없이 통과한다. 시험 `sparse_recall_keeps_tracks_whole` 은 이 한 경우로 실패한다(기준은 낮추지 않았다).
- 일관된 반복 무늬형 오대응 1%(F-125)에서 Split 순도 0.9954(기준 0.99 통과) — 변경 전후 같다.

## 추가 실험: 재현율 30%·무작위 오대응 1% 순도 (F-123 아직 미달)
기준은 c8fa58d 에 origin/main 을 합친 트리(tracks.rs 는 그대로). 순도는 모두 0.97 대에서 움직이지 않았다.

불순 트랙 길이 분포(30%·1%, 불순 34 개): 길이 2 가 3 개, 3~9 가 각 1~4 개, 10~12 가 15 개. 짧은 무작위 두 점 트랙이 아니라 긴 참 트랙에 관측 한두 개가 잘못 붙은 경우가 대부분이다.

해석
- 지지도 1 단계는 순수하다(오대응이 삼각형을 이루려면 오대응이 둘 이상 겹쳐야 함). 불순은 지지도 0 단일 간선 합치기에서 생기고, 대응 재현율 30% 에서는 참 트랙에 남은 이웃이 한 개뿐인 관측이 많아 "참 잎(관측 하나가 간선 하나로 붙은 것)"과 "오대응 잎"이 그래프 구조로는 구별되지 않는다. 잎 합치기를 막으면 완전도가 0.39~0.81 로 떨어진다.
- 성분 영상 짝 수로 "짝이 많은데 간선이 하나면 오대응" 이라고 보는 판정은 참 조각 연결(완전도)을 같이 끊어 순도를 올리지 못했다.
- 순도 ≥ 0.99 는 그래프만으로는 얻지 못했다. 화소 좌표(또는 카메라 자세가 있는 뒤 단계)의 기하 일관성 — 트랙 관측의 재투영 오차 — 이 필요하다. 트랙 단계는 카메라 모델을 받지 않으므로 인터페이스 변경(호출하는 쪽 합의)이 필요한 일이다.

시간 문제로 이번에는 제품 쪽 규칙을 바꾸지 않았고 origin/main 만 합쳐 푸시했다(tracks.rs 변경 없음).

## 수치
합성 장면 12 위치(편대 기본 배치) 36 영상, 표면 위 1.5 m 격자 점의 정답 투영을 특징으로, 후보 짝(시간 5, 교차 4, 2의 거듭제곱 16) 중 공통 점 16 개 이상인 짝만.
순도 = 정답 점이 하나뿐인 트랙 비율. 완전도 = 정답 점마다 (한 트랙에 모인 최대 관측 수 / 참 대응만으로 이어지는 최대 관측 무리 크기, 너비 우선 탐색) 평균.
모든 수치는 `cargo test --release -p skylens-core tracks:: -- --nocapture` 출력.

## 방법
- 노드 번호 = 영상별 특징 수의 누적합 + 특징 번호. 범위 밖 번호·같은 영상 짝은 버리고 센다.
- 인접 목록은 오프셋 + 평탄 배열(노드마다 정렬), 성분 영상 목록은 정렬 없는 병합.
- 합성 대응: 짝마다 참 대응을 해시로 `keep_percent` 만 남기고, 무작위 오대응을 1000 개당 `outlier_per_mille` 개, 일관 바꿈은 정답 점 `swap_percent`% 를 번호 + 1 인 옆 격자 점(1.5 m)의 특징과 모든 짝에서 대응시킨다.
- 상한 시험은 트랙 수의 절반을 상한으로 줘 `truncated > 0` 을 단언한다.
- 측정 기계 4 코어(부하 상태), 트랙 시험 전체 1 초 안팎.

## 남은 문제
- 재현율 30%·오대응 1% 순도 0.9720(순서 나누기 뒤, 기준 0.99 미달, 시험 `sparse_recall_keeps_tracks_whole` 실패 상태 그대로 — 기준을 낮추거나 무시로 돌리지 않음). 순서만으로는 0.005 오르는 데 그쳐, 단일 간선 오대응의 대부분은 마지막 단계에서도 양쪽 성분 영상이 겹치지 않는다(30% 에서 조각이 끝까지 작게 남음). 다음 후보는 아래 경쟁 판정.
- (이전 기록) 재현율 30%·오대응 1% 순도 0.9672: 단일 간선 오대응 중 두 점의 성분이 영상을 공유하지 않는 경우가 통과한다. 조각이 작을수록(재현율 낮을수록) 충돌로 드러날 기회가 적다. 다음 후보: 단일 간선 합치기를 모든 간선 수 ≥ 2 쌍과 1 단계 뒤로 미루고, 한 노드에서 나가는 단일 간선들의 상대 성분끼리 영상이 겹치면(서로 경쟁하면) 소수 쪽을 버리는 판정; 또는 짝별 화소 좌표의 국소 일관성(이웃 대응과의 변위 차) 사용.
- (이번 점검에서도 F-127 기준 규모 시간은 재지 못했다.)
- F-127 기준 규모(240 장 × 8192 특징) 시간은 이번에도 재지 못했다(4 코어 측정 기계 부하 평균 20 이상이라 단독 측정 불가). 순서 나누기는 성분 그래프 재구성을 최대 9 번(노드 수 크기 배열 초기화 포함) 더하므로 기준 규모 시간이 늘 수 있다 — 측정 필요(구조만 평탄 배열·정렬 없는 병합).
- 실제 렌더 영상 + 실제 매칭 출력에서의 순도·완전도는 아직 재지 않았다.
