# tracks — 짝별 검증 대응에서 다시점 특징 트랙 만들기

## 결론
- 채택: (영상 번호, 특징 번호) 노드를 합집합-찾기로 묶어 트랙을 만든다. 입력은 매칭 단계 출력(`verified_matches`, 대응·정상 표시 길이가 다르면 이제 오류).
- 기본 규칙 `Split` 을 2 단계로 바꿨다. 1 단계: 삼각 지지도 > 0 간선을 지지도 내림차순으로 합치고 같은 영상 특징이 둘이 되면 건너뛴다. 2 단계: 지지도 0 간선을 1 단계 뒤 성분 쌍마다 묶어, 서로 다른 간선 수가 많은 쌍부터 합치되 이미 자란 두 성분은 2 개 이상의 간선으로 이어질 때만 잇는다.
- 재현율 100% 장면(편대 배치)에서는 오대응 0·1% 모두 Split 순도·완전도 1.0000.
- **미달(F-123)**: 대응 재현율 50%·30% 에서 Split 완전도가 Drop 보다 낮다(50%: 0.9756 대 1.0000, 30%: 0.8313 대 1.0000). 재현율 30%·오대응 1% 에서 Split 순도 0.9761(기준 0.99 미만). 시험 `sparse_recall_keeps_tracks_whole` 은 이 기준으로 실패한다.
- 일관된 반복 무늬형 오대응 1%(F-125)에서 Split 순도 0.9954(기준 0.99 통과), Drop 1.0000.

## 수치
합성 장면 12 위치(편대 기본 배치) 36 영상, 표면 위 1.5 m 격자 점의 정답 투영을 특징으로, 후보 짝(시간 5, 교차 4, 2의 거듭제곱 16) 중 공통 점 16 개 이상인 짝만.
순도 = 정답 점이 하나뿐인 트랙 비율. 완전도 = 정답 점마다 (한 트랙에 모인 최대 관측 수 / 참 대응만으로 이어지는 최대 관측 무리 크기, 너비 우선 탐색) 평균.
모든 수치는 `cargo test --release -p skylens-core tracks:: -- --nocapture` 출력(제품 커밋 아래).

## 방법
- 노드 번호 = 영상별 특징 수의 누적합 + 특징 번호. 범위 밖 번호·같은 영상 짝은 버리고 센다.
- 인접 목록은 오프셋 + 평탄 배열(노드마다 정렬), 성분 영상 목록은 정렬 없는 병합.
- 합성 대응: 짝마다 참 대응을 해시로 `keep_percent` 만 남기고, 무작위 오대응을 1000 개당 `outlier_per_mille` 개, 일관 바꿈은 정답 점 `swap_percent`% 를 번호 + 1 인 옆 격자 점(1.5 m)의 특징과 모든 짝에서 대응시킨다.
- 상한 시험은 트랙 수의 절반을 상한으로 줘 `truncated > 0` 을 단언한다.
- 측정 기계 4 코어(부하 상태), 트랙 시험 전체 1 초 안팎.

## 남은 문제
- 재현율 30~50% 의 조각 문제: 성긴 대응에서는 참 조각 사이 간선이 1 개뿐인 경우가 많아 2 단계 문턱(2 개)에 막힌다. 문턱을 조각 크기에 비례시키거나(예: 두 조각 관측 수의 곱 대비 간선 비율), 지지도를 원래 그래프가 아닌 1 단계 성분 단위로 다시 세는 방법을 재야 한다. 무작위 오대응과 구분하는 근거가 필요하다.
- 재현율 30%·오대응 1% 순도 0.9761: 조각이 많아 오대응이 홀로 노드·작은 조각을 끌어오는 경우로 보인다. 미분석.
- F-127 기준 규모(240 장 × 8192 특징) 시간은 이번에 재지 못했다(구조만 평탄 배열·정렬 없는 병합으로 바꿈).
- 실제 렌더 영상 + 실제 매칭 출력에서의 순도·완전도는 아직 재지 않았다.
