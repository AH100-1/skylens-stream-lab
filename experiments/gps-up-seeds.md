# 구역 GPS 정렬 연직 고정 옵션: 시드·구역 수를 늘린 판정 측정

## 결론

- gps_fixed_up 을 기본 켜기로 바꾸지 않는다. 판정 규칙(모든 장면에서 표면 중앙·refined_overlap 이 0.01 m 넘게 나빠지지 않고 verify 7/7 유지)을 두 장면이 깬다.
  - 시드 7, 1구역: 표면 중앙 0.471 → 0.515 m (+0.044 m). 기울기는 0.894 → 0.505° 로 줄었는데 표면 중앙은 늘었다. 기울기가 줄어도 표면 높이 오차가 같이 줄지는 않는다.
  - 인자 없는 기본 경로(시드 1, stride 3·span 12): refined_overlap 중앙 최대 2.604 → 2.665 m (+0.061 m). 이 경로는 켬·끔 모두 verify 가 4/7 이고 등록이 48장뿐이라 이미 기준 밖이다. 옵션이 못 고치고 조금 더 나쁘게 만든다.
- 나머지 장면(시드 1 1구역, 시드 3·11 2구역)은 켬이 같거나 좋다. 시드 11 은 표면 중앙 1.385 → 0.415 m, 기울기 4.264 → 0.124°. 시드 3 은 표면 중앙 0.789 → 0.166 m. refined_overlap 은 2구역 두 장면에서 0.002~0.004 m 줄었다.
- 기본값은 꺼짐 그대로 둔다. 제품 코드·시험·문서는 바꾸지 않았다(새 커밋 없음).
- 1구역 설정에서도 켬이 대체로 기울기를 줄인다(1.205 → 0.275°, 0.894 → 0.505°). 다만 표면 중앙은 시드 1 에서 좋아지고 시드 7 에서 나빠져 일관되지 않다.

## 수치 표

모두 4 코어 측정 기계에서 장면당 한 번씩 잰 값이다. 합성 장면 320x180, 80위치 × 3대. 기울기는 구역별 최종 정밀 자세의 정답 대비 평균 회전 오차각(도, 구역 순서). 중심은 정답 카메라 중심 대비 중앙/최대(m). 표면은 정밀 점의 정답 표면 수직 거리 중앙(m). overlap 은 verify 의 refined_overlap 겹침 차 중앙 최대(m, 1구역은 해당 없음).

## 방법

- 제품 브랜치 feat/gps-up(6a35180)을 그대로 release 로 빌드해 썼다. 합성 장면은 시드만 바꿔 라이브러리에서 만들어 디스크에 쓰고(synth 명령행에는 시드 인자가 없다), 같은 장면에 run 을 옵션 끔 → 켬 순서로 한 번씩 돌린 뒤 verify 를 명령행으로 돌렸다. 한 번에 한 작업만 돌렸다(1구역 약 30~60 초, 2구역 약 110~160 초, 기본 경로 약 70 초).
- run 공통 옵션은 README 의 합성 예와 같다: --span 48 --ovl 2 --max-features 800 --dense-width 96 --hfov 65 --ba-iters 15. 1구역은 --stride 2(40위치, 구역 1개), 2구역은 --stride 1(80위치). 기본 경로는 run 에 옵션을 하나도 주지 않은 것(stride 3, span 12, max-features 1500, dense-width 160).
- 구역별 기울기는 구역 정밀 자세가 정해진 직후(정렬·앵커 적용 뒤)의 회전을 임시 기록 코드로 파일에 떨궈 얻었다. 사진마다 정답 회전과의 세계 좌표 회전 차를 구하고 구역 안 평균 회전(극분해)의 각도를 쟀다. 이 기록 코드와 측정 시험은 저장소에 넣지 않았다.
- 카메라 중심·표면 오차 계산은 pipeline_gps_up 시험과 같다(정답 원점과 첫 GPS 원점 차 보정, 표면은 Scene::surface_height 수직 거리).

## 남은 문제

- 시드 7 1구역에서 기울기는 줄고 표면 중앙은 늘어난 까닭을 못 가렸다. 구역 높이 오프셋이나 배율이 연직 고정 뒤 다르게 풀리는 것으로 의심하나 확인하지 않았다. 켬이 표면 중앙을 해치는지 시드 흔들림인지 가리려면 시드를 더 늘려야 한다(이번에는 1구역 두 시드뿐).
- 기본 경로는 구역이 12위치라 구역 간 겹침이 없어 verify 가 켬·끔 모두 4/7 이다. 첫 구역 기울기가 30.742° 로 남는 것은 옵션과 무관한 별도 문제로 보이며 켬으로도 줄지 않는다. 이 경로에서 overlap +0.061 m 가 흔들림인지는 모른다.
- 장면당 한 번씩이라 흔들림 크기를 모른다. 같은 설정 반복과 시드 추가가 필요하다.
- 짐벌(카메라 x 축 수평) 가정이 깨진 데이터는 여전히 미측정이다.
- 기본 켜기는 위 두 항목(시드 7 1구역, 기본 경로)이 설명되기 전까지 미룬다.
