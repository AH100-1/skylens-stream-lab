# 두 시점 검증 짝 감소(F-209)와 F-148 관계

## 결론
- 474bcf8 기점 트리에서 성공하고 2bf4795 포함 트리에서 실패하는 짝 26개는 모두 다른 카메라 짝이고 대응이 5~10개뿐이다(다른 카메라 짝 156개의 대응 수는 1~10, 평균 4.7). 예전 트리는 이 무작위 대응에서 정상 5~7개짜리 해를 만들어 통과시켰고, 통과 간선의 정답 대비 회전 오차는 32°~179° 다. 새 트리의 거부(정상 수 하한 15, 겹침 없는 짝 유의성 검사)는 과도한 거부가 아니라 올바른 거부다. 평면·시차 판정이나 쌍둥이 처리 탓에 잃은 짝은 없다(판정 규칙 때문에 잃은 참 짝 0, 26짝 모두 정답 대비 회전 오차 32° 초과).
- 그래서 two_view.rs 의 판정 규칙은 바꾸지 않았다. 회전 평균이 8/24 만 돌려주는 것은 통과 간선 75개가 모두 같은 카메라 짝이라 그래프가 F/R/L 세 덩어리이기 때문이며(F-148 이력과 같음), 두 시점 쪽에서 풀 문제가 아니라 다른 카메라 짝에 참 대응이 나오지 않는 매칭·짝 쪽 문제다.
- 시험 추가: `formation_cross_camera_random_matches_never_pass`(실측 편대 다른 카메라 짝에 무작위 대응 5~10개, 통과 0·2° 초과 0 단언).
- F-209 확인 기준(24/24·2° 초과 5% 이하·정렬 오차 중앙 1° 이하)은 이 수정으로는 충족되지 않는다.

## 방법
- 두 트리를 worktree 로 만들어 같은 bench(`--repeat 1`)를 돌리고, 임시로 짝별 줄(짝, 카메라, 위치, 대응 수, 성공 여부, 정상 수, 정답 대비 회전 오차)을 찍었다(커밋하지 않음). 새 트리 쪽은 `top < needed` 거부 지점에 임시 출력을 넣어 이유를 확인했다.
- 회전 오차는 복원 자세 회전과 정답 상대 회전 R_j R_iᵀ 의 각.

## 남은 문제
1. 다른 카메라 짝에 참 대응이 없다(매칭 단계 대응 1~10개). 24/24 반환은 SPEC §1(리그 제약 없음) 아래 카메라 사이를 잇는 다른 경로(위치 평균·GPS 사전 정보 등)가 필요하다. 매칭·짝 쪽 후속.
2. 시험은 무작위 대응 거부만 단언한다. 실측 편대 참 대응(렌더·특징·매칭 포함) 통과 간선 2° 초과 비율 시험은 추가하지 못했다.
3. 같은 카메라 간격 짝 0.966°→1.983° 악화(F-191/F-192 와 같은 종류) 확인 필요.
4. 10–21·13–21 두 짝의 거부 경로 미확인.
