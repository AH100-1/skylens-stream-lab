# P17 dense-prep — 왜곡 보정 규약·저역 통과·유효 마스크, 이웃 선택 보강

## 결론
채택 제안. 밀집 깊이 입력 준비 두 모듈을 고쳤다.
- 왜곡 보정이 저장소 화소 중심 규약(화소 i 중심 = 연속 i + 0.5)을 따른다. 주점은 연속 좌표에서 cx' = cx·s.
  저장소 규약으로 그린 반점의 무게중심과 정답 투영 차가 0.25 px → 최대 0.0068 px 로 줄었다(기준 0.01 px).
- 축소 전 가우스 저역 통과(σ = 0.6·√(r² − 1), 2048→960 에서 σ = 1.13 원본 px). 주기 3 px 줄무늬 출력 표준편차 3.25(기준 ≤ 5).
- 유효 영역 마스크를 함께 돌려준다. 원본 밖은 0·무효, 가장자리 반 화소 띠는 끝 화소 값·유효.
- 이웃 선택: 유한하지 않은 점·점수는 0, 관측 없는 사진은 `try_depth_range` = None 이고 `dense_jobs` 에서 빠진다.
  축척 비는 카메라 z / f 로 정하고 시험으로 고정했다. 실측 편대 배치에서 1칸 이웃은 세 카메라 모두 상위 8 밖,
  1위는 같은 카메라 7칸 이웃이다(SPEC 실측 예는 8칸 1위 — 아래 남은 문제).

## 방법
### 화소 중심 규약 유도
연속 좌표 x 에서 영상은 [0, W) 를 덮고 화소 번호 i 의 중심은 x = i + 0.5. 크기를 s 배로 바꾸면 같은 장면 점의
연속 좌표는 x' = s·x 이다(영상 가장자리 0 → 0, W → sW 가 맞물리므로). 핀홀 투영 x = fx·n + cx 에 대입하면
x' = (s·fx)·n + s·cx, 따라서

- fx' = s·fx, cx' = s·cx (연속 좌표 주점).
- 주점을 화소 번호 좌표 c_idx = cx − 0.5 로 쓰면 c_idx' = cx' − 0.5 = (c_idx + 0.5)·s − 0.5.

예전 코드는 cx(연속 좌표)에 화소 번호용 식 (cx + 0.5)·s − 0.5 를 써서 cx' 가 s·cx 보다 0.5·(1 − s) 만큼 커졌다
(1920→960: 0.25 px, 2048→960: 0.266 px). 출력 화소 u' 는 연속 좌표 u' + 0.5 에서 표본을 잡고, 대응하는 원본
연속 좌표 p = fx·d.x + cx 를 화소 번호 좌표 p − 0.5 로 바꿔 보간한다.

시험은 모듈과 독립적으로 규약을 고정한다. 반점 영상은 원본 화소 (u, v) 값을 연속 좌표 (u + 0.5, v + 0.5) 의
정규 좌표에서 계산해 그리고, 출력 무게중심은 화소 번호 + 0.5 로 잰다. 정답은 돌려받은 핀홀의 `Camera::project`.
램프 시험은 원본 화소 번호를 실수 값으로 넣어 출력 값이 (u' + 0.5)/s − 0.5 인지 본다(cx' 반 화소 오류면 약 0.53 원본 px).

### 저역 통과
축소비 r 에서 출력 나이퀴스트는 원본 0.5/r 주기/px. 가우스 σ 응답 exp(−2π²σ²f²) 와 쌍선형 보간 응답이 겹쳐
f = 1/3 줄무늬를 진폭 100 → 표준편차 5 아래로 줄이는 데 σ ≈ 1.1 이 필요하다. 축소비에 따라 자라고 축소 없을 때 0 이
되도록 σ = K·√(r² − 1) 꼴을 쓰고 K = 0.6 으로 정했다(2048→960 에서 1.13). 대칭 필터라 반점 무게중심은 움직이지 않는다.
필터는 원본 공간에서 분리형, 가장자리는 끝 화소 반복.

### 유효 마스크
출력 화소 중심의 원본 연속 좌표가 [0, W] × [0, H] 안이면 유효. 화소 번호 좌표로 [−0.5, W − 0.5] 이고
양 끝 반 화소 띠는 끝 화소로 붙인다. 예전 감독 측정 27,185 는 반 화소 띠까지 0 으로 둔 값이고, 이 규칙에서는 26,588.

### 이웃 선택
- 축척 비 시험: 점 X 를 원점에 두고 기준 사진은 X 를 광축에서 25° 벗어나 z = 30 m(광선 길이 33.1 m)로 본다.
  후보 두 장은 기준 광선과 10° 를 이루는 같은 방향에서 30 m, 60 m 거리로 X 를 광축에 둔다. z 축척이면 (30/60)² = 0.25,
  광선 길이 축척이면 (33.1/60)² / (30/33.1)² = 0.37.
- 편대 시험: `synth::SceneConfig::default()` 의 실측 배치를 40곳으로 줄임(960×540, 화각 65°, 기울기 60°).
  지면(건물 포함 표면 높이)에서 x ∈ [−40, 80], y ∈ [−60, 60] 균일 4만 점, 사진 안에 투영되는 사진을 관측자로 두고
  관측자 2장 이상만 남김. 가림은 무시했다.
- 1위 간격 예측: 위치 20 사진의 광축이 닿는 지면 점에서 같은 카메라가 b 칸 이동했을 때 광선 사이 각이 10° 에 가장
  가까운 b. 세 카메라 모두 6칸(편대 방위가 달라도 광축-진행 방향 사이 각이 비슷). 측정 1위는 7칸 — 사진 가장자리
  점은 거리가 멀어 같은 기선에서 각이 작아지므로 합산 1위가 예측보다 한 칸 먼 쪽으로 간다.
- 측정: 4 코어 측정 기계, release.

## 남은 문제
- SPEC §3.6 실측 예는 8칸 1위인데 합성 편대에서는 7칸 1위, 8칸은 F 4위·R 5위·L 5위다. 합성 장면의 지면 점 분포
  (균일, 가림 없음)와 실제 희소 점 분포(무늬 많은 곳에 몰림)의 차이일 수 있다. 실측 희소 점으로 재확인 필요.
- 공유 점 수가 많은 쌍이 합산 점수를 독식하는 문제(점 수 정규화)는 아직 보지 않았다.
- 마스크는 돌려주기만 한다. 밀집 깊이 쪽(patchmatch)이 무효 화소를 정합 비용에서 빼는 것은 그 묶음 일이다.
- 원본 전체 흐림을 사진마다 새로 한다. 구역 하나(42~48장) 시간에 미치는 영향은 아직 재지 않았다.
