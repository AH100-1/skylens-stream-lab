# 덩어리 사이 보정 회전 다수결: 정밀 BA 뒤 회전 오차와 시드 1·2 영향

## 결론
- 기본 켬 제안은 불가(현 시점). 정한 기준(시드 1·2 세 구역 묶음별 F/R/L 정밀 BA 뒤 회전 오차 중앙이 켬에서 끔 대비 +0.2° 이내) 18 칸 중 17 칸은 통과, 1 칸이 넘었다:
  시드 2 구역 0 L 묶음, 켬 1.217° / 끔 0.994° (+0.222°, 절반 덜어내기 Q 기준). 같은 구역 위치 오차 중앙도 0.304 → 0.380 m 로 커졌다.
- 이득은 분명하다: 시드 1 구역 0 L 은 1.060° → 0.471° (-0.59°), 시드 2 구역 2 L 은 1.697° → 1.365° (-0.33°). 시드 3 구역 0 의 84.72° → 0.78°(회전 평균 직후)도 같은 방향이다.
- 켬은 정밀 BA 뒤에도 L 묶음이 시드 1·2 에서 1° 안팎이던 문제를 줄이지만, 시드에 따라 반대로 0.1~0.2° 나빠지는 칸이 있다. 시드를 더 늘려 악화 칸의 원인(덩어리 사이 다수결 가중이 구역 0 시드 2 에서 3~4° 편향 간선 쪽으로 기우는지)을 확인하기 전에는 기본 켬을 올리지 않는다.

## 방법
- 제품 브랜치 feat/zone0-rot (6f369fa) 그대로, 시험 코드 변경 없음. `crates/cli/tests/zone0_up.rs` 가 시드별 합성 장면을 만들어 파이프라인을 돌리고 구역 좌표 정밀 포즈를 정답과 비교한다.
- 명령: `ZONE0_SEEDS=<시드> cargo test --release -j 2 -p skylens-stream --test zone0_up -- --ignored --nocapture` (끔), 같은 명령 앞에 `SKYLENS_ROT_BRIDGE=1` (켬). 시드 1·2 에 대해 네 번을 같이 돌렸고(4 코어 측정 기계, 부하 중복으로 각 약 1660 초) 모두 통과.
- 표의 오차는 시험이 낸 묶음 F/R/L(묶음 0/1/2)별 카메라 회전 오차 중앙. 시험 한 번이 시드 하나의 구역 0·1·2 를 모두 낸다.

## 남은 문제
- 시드 수가 3(회전 평균 직후만)+2 뿐이다. 시드 4 이상으로 켬/끔 악화 칸의 빈도를 봐야 한다.
- 시드 2 구역 0 L 의 악화 원인 미확인. 덩어리 보정 회전 무리의 가중 선택을 덤프(`SKYLENS_DUMP_ROTAVG`)로 확인할 필요가 있다.
- 기준 0.2° 는 좁은 편이라 +0.222° 는 시험 잡음 범위일 수 있다(같은 설정 재실행 분산을 아직 재지 않음).
- 시드 3 의 정밀 BA 뒤 값은 이번 묶음에서 다시 재지 않았다.
