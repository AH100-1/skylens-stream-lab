# F-294c 초벌 좌표계 맞춤: 비행 축 둘레 회전 선택 교체

## 결론
- 원인 확정: Kabsch 행렬 특이값이 [5385, 18.2, 0.38] 로 사실상 계수 1(직선 비행)이라 롤은 Kabsch 로 정해지지 않는다. 기존 휴리스틱은 보는 방향 평균 z 를 최소화하는데, 카메라 방위가 비대칭(-3°, 125°, -116°)이라 평균 광축이 연직에서 약 4° 벗어나 있어 이 기준이 편향된다. 격자를 0.1° 로 하면 1.73°, 같은 기준의 닫힌 식은 1.71° 로 같은 값이 나온다(2° 격자의 0.82° 는 우연).
- 교체: 롤을 "카메라 광축 z 성분의 분산 최소"로 닫힌 식(2x2 공분산 최소 고유 방향, 부호는 평균이 더 아래인 쪽)으로 선택. 같은 기울기로 장착된 카메라는 롤이 맞으면 광축 높이가 같다는 가정이며 평균 방향 편향을 받지 않는다.
- 결과: placed 회전 중앙 1.48 → 1.06°(기준 1.2° 이내), 중심 중앙 1.12 m 불변.
- 미해결: `preview_default_pose_error_bounds` 전체는 아직 통과하지 못함(시간 한도로 어느 단언인지 확인 못 함; 회전 중앙 < 1.2 단언 줄이 아니라 그 뒤 여러 줄 단언 하나로, 비교 대상 prune=0 가지의 값도 함께 바뀌었을 가능성). 다음 작업에서 실패 단언 확인 필요.
- F-294 처리됨-검증대기 후보: 회전 중앙 기준은 충족, 시험 전체 통과는 미확인이므로 "부분 처리".

## 방법
- pipeline.rs 에 roll_by_level_spread 추가, sparse_init_with 의 2° 격자 탐색을 대체. 진단용으로 Kabsch 특이값 출력(PIPE_DEBUG).
- 측정: `cargo test --release -j 2 -p skylens-core preview_candidates -- --ignored --nocapture`.

## 남은 문제
- preview_default_pose_error_bounds 실패 단언 확인(비교 가지 prune=0,prior=0.2 의 회전이 같이 좋아져 `< 0.6 * old` 가 깨졌을 가능성).
- 남은 1.06° 대 rotfree 0.63°: 광축 높이 가정이 카메라별 실제 기울기 차이를 반영하지 못함. 삼각측량 지면 평면 법선 기준을 시도할 만함.
- fmt/clippy 는 통과, pipeline 관련 다른 시험은 재확인하지 못함.
