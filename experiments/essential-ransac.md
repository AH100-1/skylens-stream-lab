# essential-ransac — 보정된 짝의 5점 본질 행렬 RANSAC (FEEDBACK F-015)

상태: **검토 요청**. 제품 `feat/essential-ransac` 6f15c5a.

## 결론
- `ransac_essential` / `ransac_essential_candidates`(5점 최소 해 + Sampson 정상 판정 + 후보별 국소 정밀화 + 평면 호모그래피 거르기)를 추가했다.
- **F-015 새 확인 기준(11:22 감독) 충족**: 평면 σ0.5px 시드 1..=20 에서 시드마다 최선 후보 회전 ≤ 정답 시작 Sampson 정밀화 회전 + 0.1°.
  이상치 0 은 하한 대비 최대 초과 **0.0000°**, 이상치 30% 도 **0.0000°**(모든 시드가 하한과 같은 해). 정답 후보 없는 시드 0.
  학습에 쓰지 않은 시드 21..=80 에서도 이상치 0 초과 0.0000°, 이상치 30% 최대 초과 0.0213°.
- 핵심 원인과 처방: 이상치 30% 실패(7/20 시드)는 **최적화가 아니라 자료** 문제였다. 각 후보는 자기 정상 집합의 최적점에 이미 수렴해 있었고
  (같은 정상 집합으로 정답에서 시작해도 같은 회전), 에피폴라 문턱(1차원 제약) 안에 우연히 든 이상치 1~5개가 평면의 얕은 골짜기를
  최대 0.9° 기울였다. 평면 장면에서는 정상 짝이 호모그래피(2차원 제약)도 만족하므로, 정상 짝 80% 이상이 한 호모그래피로 설명되면
  호모그래피 정상 짝(전달 오차 < 2.5 × 문턱)으로 정상 집합을 바꾸고 한 번 더 정밀화한다.
- 평면은 두 시점만으로 두 겹 모호하다(쌍둥이 해 회전 약 4.4°·방향 약 78°). 후보는 최대 4개를 돌려주고, 하나를 고르는 일은 T07(셋째 시점) 설계로 넘긴다(감독 판단 11:22).

## 방법
- 5점 표본마다 `essential_5pt` 후보 E 를 모두 평가, 정상 = |Sampson 잔차| < 문턱/초점(px→정규화).
- 정규화한 E 사이 거리 min(‖E₁−E₂‖, ‖E₁+E₂‖) > 0.1 이면 다른 가설로 보관(최고 정상 수의 0.9 배 이상만, 최대 4개).
- 적응형 종료(5점) + 최소 300회(쌍둥이도 표본에 나오게).
- 후보마다 키랄리티 분해(`recover_pose`) → `refine_pose`(국소 LM) → 정상 집합 갱신, 두 번.
  처음엔 F-012 의 `refine_relative_pose`(14 시작점)를 썼는데, 다중 시작이 쌍둥이 둘을 비용이 조금 작은 쪽 하나로 합쳐 버려 기각.
- LM 반복 30 → 100 은 결과 변화 없음(국소 최소 문제이지 수렴 부족 아님).
- 실패한 시도: 후보별로 F-012 시작점 7개에서 정밀화하고 후보 E 근처에 남은 해 중 최소 비용 선택 → 이상치 0 최악 1.363°(나빠짐), 기각.
  최소 반복 300 → 1000: 변화 없음, 기각.
- 효과가 있던 것: 최종 정렬(정상 수 → 비용)이 정답 골짜기 후보를 3·4번째로 밀어내고 있었다. 반환 후보를 2 → 4 로 늘리자 해결.
  즉 정상 수·비용으로는 정답·쌍둥이·그 변형을 가를 수 없다(평면 모호성의 직접 증거).
- 정렬: 정상 수 내림차순, 같으면 Sampson 비용 오름차순. `ransac_essential` 은 첫 후보.
- 진단(6f15c5a 직전): 미달 시드의 후보마다 (a) 후보에서 200회 정밀화, (b) 같은 정상 집합으로 정답에서 시작한 정밀화를 비교 →
  두 회전이 소수 넷째 자리까지 같음(예: 시드 2 0.9912°/0.9912°, 거짓 정상 3). 즉 최적화는 수렴했고 정상 집합이 틀렸다.
- 평면 거르기: 후보의 정상 짝에서 4점 DLT 호모그래피 RANSAC(200회, 결정적 난수) → 정상 짝 전체로 다시 맞춘 H 로 **모든** 대응을 판정
  (에피폴라 문턱 밖으로 밀려난 정상 짝도 되찾음). 호모그래피 정상 수 ≥ 0.8 × 에피폴라 정상 수이면 정상 집합을 교체하고 `refine_pose` 1회.
- 전달 문턱 2.5 × 문턱(1.5 px → 3.75 px)의 근거: 전달 오차 ‖b − Ha‖ 는 두 영상 잡음이 2차원으로 더해져(축마다 분산 약 2σ²)
  χ²₂ 99.9% 반지름이 약 5.3σ(σ0.5px 에서 2.6 px)이고, 무작위 이상치가 한 점 둘레 3.75 px 원에 들 확률은 1920×1080 에서 약 2e-5,
  시험 장면(960×540)에서도 약 8.5e-5 라 넓혀도 거짓 정상이 늘지 않는다. 그래서 놓침을 없애는 쪽으로 넉넉히 두었다.
  1.5·2.0 배에서 시드 18 이 정상 짝 1~3개를 놓쳐 미달했다. 2.5 는 시드 1..=20 측정으로 고른 값이므로 시드 21..=80 으로 따로 확인했다.
- 테스트: `ransac_essential_planar_rotation`·`ransac_essential_planar_with_outliers` 의 `#[ignore]` 해제, 기준은 시드별
  `planar_floor`(이상치 아닌 대응만으로 정답 자세에서 시작한 정밀화, 정답 카메라에서 독립 계산) + 0.1°. `homography_dlt_recovers_plane_transfer` 추가.

## 남은 문제
1. 비평면(높이 10 m) + 이상치 30% 에서 하한 대비 0.245° 초과(거르기가 적용되지 않음). 같은 원인(에피폴라 문턱 안 거짓 정상)으로 보이며,
   비평면에서는 호모그래피 대신 다른 정상 판정(예: 문턱을 잡음 추정에 맞추기, 강건 비용 정밀화)이 필요. F-015 범위(평면) 밖이라 새 항목 제안.
2. 후보 4개 중 정답 고르기 — T07(셋째 시점 일관성, 비행 사전 정보: 이동이 지면과 거의 평행) 설계.
3. 평면 판정 비율 0.8 과 전달 문턱 2.5 배는 σ0.5px 합성 장면 측정값. 실영상 잡음에서 다시 잴 것.
4. `ransac_fundamental` 대신 기본으로 쓰는 연결(파이프라인)은 아직 안 함. F-003(8점 퇴화 판정)과 묶어 처리.
