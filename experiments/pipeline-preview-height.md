# 초벌 높이 차 (pipeline-preview-height)

## 결론
미완. 단구역 preview_vs_refined 높이 차 중앙은 2.657 → 2.424 m 로 줄었으나 2 m 기준은 아직 못 넘었다(6/7 유지). 2구역 실행은 시간 한도로 못 돌렸다.
원인은 개별 불량 점이 아니라 초벌 자세 오차(휨)다. 구간별 보정장(전체 닮음 뒤 잔차를 수평 칸별로 흡수)은 방향은 맞지만 부족하다.

## 수치
| 항목 | 전 | 후 |
|---|---|---|
| 단구역 높이 차 중앙 | 2.657 m | 2.424 m |
| 단구역 최근접 중앙 | 2.358 m | 2.110 m |
| 초벌 재투영 / 정밀 | 3.026 / 0.300 px | 같음 |
| preview_align 점쌍·잔차 | 2746 · 3.932 m | 같음(전체 닮음은 그대로) |
| verify | 6/7 | 6/7 |
| 2구역 | 높이 차 6.278 m, 점쌍 324 | 측정 못 함 |

진단(diagnose_preview, 단구역): 초벌 자세 중심 오차 중앙 1.12 m·회전 1.48 도(정밀 0.33 m·0.53 도). 정답 자세로 삼각측량하면 표면 거리 0.07~0.19 m 이므로 삼각측량 자체는 정상. 초벌 점 표면 거리(정렬 전) 광선각 [2,5) 도 9.23 m, [5,90) 도 4.80 m. 광선각 < 2 도 점은 0개라 광선각 거르기는 효과 없음(전/후 동일 점 2746). 정렬 뒤 초벌 밀집 점 표면 거리 중앙 2.68 m, 정밀 0.45 m. 즉 휨이 원인이고 특정 점 탓이 아니다.

## 방법
stream.rs 에 WarpField 추가: 전체 닮음 잔차(≤ max(3 med, 0.3 m)) 를 수평 12×12 칸 평균으로 모아 가우스(폭 0.7 칸) 가중 보정. 짝 200 미만이면 전체 닮음만 쓴다. pipeline.rs 는 자기 구역 정렬 뒤 보정장을 만들어 최종 초벌 출력에 적용. 전체 닮음 변환 규칙(robust_fit)은 바꾸지 않았다(preview_align 수치 불변). 단위 시험 warp_field_absorbs_bending: 휜 8 m 합성 면에서 전체 닮음 높이 잔차 중앙 > 1 m, 보정장 < 0.3 m.

## 남은 문제
- 보정장이 잡는 것은 희소 점 위치의 잔차뿐이라 밀집 점 높이 오차(밀집 깊이 편향)는 남는다. 다음: 잔차를 z 만 / 칸 크기·폭 조정, 밀집 단계 깊이 범위 점검, 점쌍 적은 2구역은 보정장 최소 짝 수 확인.
- 2구역 전/후 표, fmt·clippy 외 통합 시험 전체 미실행(관련 단위 시험 1개만).
- 측정 부하: load average 약 20 (4코어), 단구역 run 1m40s.
