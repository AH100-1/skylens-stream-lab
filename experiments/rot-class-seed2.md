# 종류별 회전 문턱 시드 2 끔/켬: 기본 켬 가능 여부

## 결론
- 시드 2 에서 켬은 표면 오차 중앙을 1.1094 → 1.2533 m(+0.144 m), p95 를 3.3486 → 3.6092 m 로 키우고, 카메라 중심 오차 중앙도 0.3456 → 0.3819 m 로 키운다. 등록(81)·verify(8/8)는 같다.
- 시드 1·2·3 종합: 표면 중앙은 측정한 두 시드(1, 2) 모두 켬이 나쁘다(+0.102 m, +0.144 m). verify 는 시드 1 8/8 → 8/8, 시드 2 8/8 → 8/8, 시드 3 5/8 → 7/8 로 합 21/24 → 23/24(+2, 시드 3 한 곳에서만). 시드 3 의 표면·중심 수치는 이 묶음에서 재지 않았다.
- 기본 켬은 아직 불가. 얻는 것은 시드 3 의 verify +2 뿐이고, 시드 1·2 에서 표면 중앙 악화가 일관되다. 기본 끔 유지.
- 참고: 시드 2 는 끔에서도 표면 중앙 1.1094 m 로 기준 0.5 m 를 넘는다(켬과 무관한 시드 고유 문제).
