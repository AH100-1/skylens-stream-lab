# 점진적 스트림(구역 분할·초벌 정렬·스냅샷)

## 결론
- 구역 분할, 3D 점 대응 기반 초벌 정렬(닮음 변환 + 5회 트리밍, 임계 max(3×중앙, 0.3 m)), 잔상 거르기(1.5 m, 격자 해시), 6:1 추출 스냅샷, manifest.json 쓰기·읽기를 넣었다.
- 합성 시험에서 초벌을 정답에 맞춘 뒤 정답 대비 잔차 중앙 0.10~0.12 m(기준 < 0.5 m), 스케일 비 오차 0.07 % 이하(기준 1 %).
- 스냅샷 점 수 단조 증가, 2단계부터 초벌 새 영역 > 0, NaN 없음(SPEC §4) 확인.

## 수치
합성: 위치 40곳, SPAN 12, OVL 2, 위치당 4줄 × 60점. 초벌 = 정답 + 휨 0.002·d² (d = 구역 시작에서 x 거리, 구역 끝 0.39 m) + 균일 잡음 ±0.1 m, 그 뒤 구역마다 다른 닮음 변환의 역. 정밀 = 정답 + ±0.02 m.

| 구역 | 점 짝 | 맞춤 잔차 중앙(m) | 정답 대비 잔차 중앙(m) | 스케일 / 정답 |
|---|---|---|---|---|
| 0 | 3360 | 0.1031 | 0.1016 | 0.99929 |
| 1 | 960 | 0.0980 | 0.1238 | 0.99950 |
| 2 | 960 | 0.0990 | 0.1244 | 0.99981 |
| 3 | 960 | 0.0989 | 0.0983 | 1.00014 |

- 기준 근거: 휨 최대 0.39 m + 잡음 0.1 m 이므로 정렬이 맞으면 중앙은 0.5 m 를 넘지 않는다. 측정값에 맞춘 값이 아니다.
- 트리밍: 20 % 오대응(5~15 m) 섞은 400쌍에서 오대응 80개 전부 제외, 정상 320개 전부 유지, 남은 잔차 중앙 < 0.03 m.
- 잔상 거르기: 거리 0, 1.0, 1.49, 1.51, 2.9, 3.1, 10 m 중 1.51 m 이상 4개만 남음. 무작위 2000점에서 전수 비교와 일치.
- 스냅샷 손 계산: 정밀 0(x ≤ 13.75)과 0.4 m 위 초벌 1 → x ≥ 15.25 의 43줄 × 60 = 2580점 남고 6:1 추출 뒤 430점, 일치.
- 구역 경계(80곳): (0,14) (10,26) (22,38) (34,50) (46,62) (58,74) (70,80), 정렬 창 구역 0 = (0,14), 구역 1 = (10,14).

## 방법
- 대응: 정밀 점의 관측 (이미지, 특징점 번호) → 점 번호 표를 만들고, 초벌 점 관측으로 찾는다. 이미지 위치가 정렬 창 안인 관측만, 같은 (초벌, 정밀) 짝은 한 번.
- 닮음 변환: Umeyama(1991) 공분산 SVD, 반사 보정. 매 회 전체 짝 잔차 중앙값으로 임계, 남은 짝으로 재추정.
- 스냅샷 step_k: 정밀 0..k-2 의 점을 반경 1.5 m 격자(칸 = 반경, 27칸 검사)에 넣고, 초벌 k-1 에서 반경 안 점을 뺀 뒤 각 점군을 6:1 추출. preview_new_area = 그 단계에 들어간 초벌 점 수(추출 뒤).
- 파일 이름의 k 는 0부터인 구역 번호, pos{lo}-{hi} 의 hi 는 포함하지 않는 끝. 스냅샷 단계는 1부터, manifest step 은 "01".."final" 문자열.
- 4 코어 측정 기계에서 스트림 시험 8개 0.1 s 안팎.

## 남은 문제
- 닮음 변환은 stream.rs 안의 임시 구현(`Similarity`, `robust_similarity`). align 묶음 병합 뒤 `align::Similarity`, `align::robust_similarity` 로 교체해야 한다(같은 모양이라 import 만 바꾸면 됨).
- 실제 데이터(초벌 4.5 px)의 휨은 합성보다 클 수 있다. 정렬 창이 구역 시작 ±2곳이라 구역 끝쪽 오차가 커질 수 있으니 실측 잔차로 확인 필요.
- 마지막 구역이 앞 정밀 구역 안에 다 들어가면(위치 수가 SPAN 배수 + OVL 이하로 남을 때) 새 영역이 0 이 된다. SPAN·OVL 정할 때 고려.
- 전체 시험에서 two_view::five_point_terminates_on_many_seeds 가 실패(이 묶음과 무관, 부하 상태에서 기존 시험). 확인 필요.
- manifest 는 손으로 쓰고 읽는다(작은 JSON 읽기 포함). 직렬화 크레이트로 바꿀지 결정 필요.
