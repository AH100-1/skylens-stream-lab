# 떨어진 성분 장착 회전 거부 조건의 시드 1~5 확인 (F-379)

## 결론
- 시드 1~5 확인은 끝내지 못했다. 시드 1~5 `seed_verify` 를 동시에 돌렸으나 측정 기계(4 코어)의 부하가 20 이상이라 마감까지 한 건도 끝나지 않았다. 7/7·81/81 유지와 붙은 L 성분 회전 오차 ≤ 3° 는 아직 확인되지 않았다.
- 문턱 3° 근거는 기존 시드 5 보고치(정상 L 0.38°·2.47°, 거부 10.05°)뿐이다. 시드 1~4 의 정상·거부 분포는 새로 재지 못했다.
- 문턱 근거를 상수 주석에 남기고, 시험의 경계 묶음을 정상 최대 2.47° 와 거부 최소 10.05° 사이로 좁혔다(F-399 대응).

## 수치 표
| 항목 | 값 |
|---|---|
| 시드 5 정상 성분 각거리(중앙값 기준) | 0.38°, 2.47° (최대 2.47°) |
| 시드 5 거부 성분(구역2 L 5장) | 10.05° |
| 문턱 | 3.0° (정상 최대 + 0.53°, 거부 최소 − 7.05°) |
| 시드 1~4 | 미측정 |

시험 경계 사례: 2.47°·2.6°·2.95° 는 붙고 3.05°·3.4°·4°·10.05° 는 거부.

## 방법
- 기존 `component_far_from_rig_targets_is_not_attached` 에 사례를 추가하고 문턱이 정상 최대와 거부 최소 사이이며 정상 최대보다 0.5° 이상 크다는 단언을 넣었다.
- 검사: fmt, clippy -D warnings 통과. `cargo test --release -p skylens-core --lib detached` 7개 통과. `pipeline_stream_order` 라는 시험은 저장소에 없어 실행하지 못했다.

## 남은 문제
- 부하가 낮을 때 시드 1~5 `default_path_seed_verify`(`SKYLENS_REGION_DIAG=1`)를 시드별 병렬로 돌려 `diag rig check` 중앙값과 붙임 여부 분포(최소·중앙·최대)를 채울 것.
- 시드 1~4 가 기준선(7/7·81/81)과 같은지, 시드 5 가 80/81 인지 확인.
