# 두 시점 보강 (F-028 처리, F-032·F-033 진단)

## 결론
- F-028: `refine_relative_pose` 의 프로크루스테스 회전을 한 번만 계산하도록 고쳤다(결과 동일).
- F-032·F-033: 시험을 써서 원인을 진단했으나 기한 안에 전부 통과하는 상태에 이르지 못해 제품 브랜치에는 넣지 않았다.
- 비평면(높이 10 m)+이상치 30% 의 첫 후보 초과는 정상 집합 문제가 아니다. 시드 9 는 거짓 정상 0·놓침 0 인데 회전이 하한 대비 0.43° 초과 → 최소 표본 가설의 골짜기에 갇힌 국소 최소.

## 수치 (σ0.5 px, 200점, 문턱 1.5 px, 시드 1..=20)
| 경우 | 기준 | 하한 대비 최대 초과 |
|---|---|---|
| 비평면 h=10, 이상치 0 (현행) | 이상치 아닌 대응, 정답에서 시작한 정밀화 | 0.062° |
| 비평면 h=10, 이상치 0.3 (현행) | 같음 | 0.508° (시드 7), 0.4° 이상 시드 4·7·9·13·16 |
| 비평면 h=10, 이상치 0.3, 다중 시작 마무리 + MSAC 순위 | 정답 E 문턱 안 대응 전부로 정답에서 시작한 정밀화 | 0.298° (시드 8), 0.288° (시드 18) |
| 85/15 장면, 평면 밖 정상 비율 (현행) | ≥ 0.95 | 0.000 (모든 시드) |
| 85/15, 재판정 + PLANAR_MIN_SHARE 0.95 | ≥ 0.95 | 통과 |
| 평면 순위(재판정 뒤, 정상 수 순위) | 상위 2 | 이상치 0 시드 5 에서 3순위 |

## 방법
- 비평면 하한: 정답 자세에서 시작해 Sampson 정밀화(50회). 문턱 기반 하한은 정답 E 의 Sampson 거리 < 1.5 px 인 대응 전부(띠에 든 이상치 포함)를 쓴다.
- 시도한 수정: (1) 호모그래피 정상은 정밀화에만, 반환 정상은 정밀화된 E 로 재판정, (2) PLANAR_MIN_SHARE 0.8 → 0.95(평면+이상치 30% 에서 호모그래피 밖 에피폴라 정상은 약 2%, 85/15 장면은 15%), (3) 비평면이면 `refine_relative_pose` 다중 시작 마무리, (4) MSAC 점수 순위.
- (3)·(4) 를 넣자 호모그래피 정상 = 에피폴라 정상일 때(잡음 없는 평면) 평면 판정이 꺼져 다중 시작이 쌍둥이를 합쳤다(평면 이상치 0 에서 4.38° 초과). 평면 판정을 `hm != inl` 와 분리해야 한다.

## 남은 문제
1. 위 판정 분리 후 평면·비평면 시험 재확인, 비평면 이상치 30% 시드 8·18 의 0.3° 초과 원인(국소 최소 vs 띠 이상치 가중) 분리.
2. F-033 순위 시험(평면 상위 2), F-032 85/15 시험을 제품에 넣기.
3. F-027 해석적 야코비안, F-026 주석(둘 다 matching.rs 소관), `refine_relative_pose` 200·2000 대응 시간 측정 미완.
