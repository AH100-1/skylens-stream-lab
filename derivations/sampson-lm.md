# F 의 Sampson 비용 Levenberg–Marquardt 정밀화

대응 (xᵢ, x'ᵢ) (동차 좌표 a = (x, y, 1), b = (x', y', 1)) 에서 에피폴라 대수 오차는 eᵢ = bᵀ F a.
1차 기하 오차 근사(Sampson 거리)는 eᵢ 를 그 기울기 노름으로 나눈 것이다:

  rᵢ(F) = bᵀFa / √((Fa)₁² + (Fa)₂² + (Fᵀb)₁² + (Fᵀb)₂²)

(Hartley & Zisserman 11.4.3). 비용 C(F) = Σ rᵢ².

## 매개화
- Hartley 정규화 T₁, T₂(무게중심 0, 평균 거리 √2)로 F̂ = T₂⁻ᵀ F T₁⁻¹ 을 놓고 F̂ 의 성분 9개를 매개변수로 쓴다.
  잔차는 픽셀 좌표의 F = T₂ᵀ F̂ T₁ 로 계산하므로 rᵢ 는 픽셀 단위 그대로다. 정규화는 야코비안 조건수만 좋게 한다.
- F 는 척도 불변(1)이고 계수 2(det F = 0, 1)라 자유도는 7. 걸음마다 F̂ + δ 를 SVD 로 계수 2 에 투영하고(가장 작은 특이값 0)
  프로베니우스 노름 1 로 나눈다. 척도 방향의 야코비안은 0 이라 JᵀJ 가 특이하지만 LM 감쇠 λ·diag(JᵀJ)+ε 가 이를 막는다.

## 걸음
- J 는 해석적(아래 '해석적 야코비안'). 이전에는 전진 차분(h = 1e-7)이라 반복마다 잔차를 10번 계산했다.
- (JᵀJ + λ diag(JᵀJ)) δ = −Jᵀr 를 촐레스키로 풀고, 투영 후 C 가 줄면 받아들이고 λ ← λ/10, 아니면 λ ← λ·10(최대 8번).
- 상대 감소 < 1e-10 이거나 반복 상한이면 멈춘다. 비용이 줄지 않으면 시작 F 를 그대로 돌려준다(악화 없음).

## 왜 8점 재적합보다 나은가
8점 최소제곱은 Σ eᵢ² 를 줄인다. eᵢ = rᵢ · ‖∇eᵢ‖ 이므로 기울기 노름이 큰 점(에피폴에서 먼 점, 에피폴이 멀면 영상 전체에서 노름이 고르지 않음)에
가중이 쏠린다. Sampson 비용은 이 가중을 없앤 것이라 문턱(Sampson 거리 < 1.5 px)과 같은 척도로 정상 수를 늘린다.

## 해석적 야코비안
정규화 a' = T₁a, b' = T₂b, T = [[s,0,−s cₓ],[0,s,−s c_y],[0,0,1]] 이면 F = T₂ᵀF̂T₁ 에서
- e = bᵀFa = b'ᵀF̂a'
- (Fa)ₖ = Σᵢ T₂[i,k](F̂a')ᵢ = s₂(F̂a')ₖ (k = 1, 2; T₂ 의 첫 두 열은 s·eₖ)
- (Fᵀb)ₗ = s₁(F̂ᵀb')ₗ (l = 1, 2)

g = F̂a', h = F̂ᵀb' 로 두면 D = s₂²(g₁² + g₂²) + s₁²(h₁² + h₂²), r = e/√D.
- ∂e/∂F̂ₖₗ = b'ₖa'ₗ
- ∂gᵢ/∂F̂ₖₗ = δᵢₖa'ₗ, ∂hⱼ/∂F̂ₖₗ = δⱼₗb'ₖ 이므로 ∂D/∂F̂ₖₗ = 2s₂²gₖa'ₗ[k ≤ 2] + 2s₁²b'ₖhₗ[l ≤ 2]
- ∂r/∂F̂ₖₗ = (∂e)/√D − e/(2D^{3/2})·∂D = b'ₖa'ₗ/√D − (e/D^{3/2})(s₂²gₖa'ₗ[k ≤ 2] + s₁²b'ₖhₗ[l ≤ 2])

곧 야코비안 행은 세 외적 b'a'ᵀ, ũa'ᵀ, b'ṽᵀ (ũ = s₂²(g₁, g₂, 0), ṽ = s₁²(h₁, h₂, 0)) 의 합이라 점마다 O(9) 이다.
D ≤ 0(F̂a', F̂ᵀb' 의 첫 두 성분이 모두 0)이면 잔차·행 모두 0 으로 둔다.
중앙 차분(h = 1e-6)과의 상대 오차는 최대 1.5e-10(정답 F 와 흔든 F 에서 대응 60개).
