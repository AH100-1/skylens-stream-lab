# 측지 좌표 → 지역 동-북-위 좌표

WGS84 타원체: 장반경 a = 6378137 m, 편평률 f = 1/298.257223563, 이심률 제곱 e² = f(2−f).

## 측지 → ECEF
묘유선 곡률반경 N(φ) = a / √(1 − e² sin²φ).

    X = (N + h) cos φ cos λ
    Y = (N + h) cos φ sin λ
    Z = (N(1 − e²) + h) sin φ

## ECEF → 측지 (고정점 반복)
p = √(X² + Y²), λ = atan2(Y, X). 위 식에서 Z/p = (N(1−e²)+h) sin φ / ((N+h) cos φ) 이므로

    tan φ = Z / (p · (1 − e² N/(N+h))),   h = p / cos φ − N.

초기값 tan φ₀ = Z / (p(1−e²)) (h = 0 가정)에서 φ, h 를 번갈아 갱신한다. 지표 근처에서는
수 회 반복으로 배정밀도 한계까지 수렴한다(극점 근처 cos φ → 0 은 이 용도에서 다루지 않음).

## ECEF → ENU
원점 (φ₀, λ₀) 에서 동·북·위 단위 벡터를 ECEF 로 쓰면

    e = (−sin λ₀,  cos λ₀, 0)
    n = (−sin φ₀ cos λ₀, −sin φ₀ sin λ₀, cos φ₀)
    u = ( cos φ₀ cos λ₀,  cos φ₀ sin λ₀, sin φ₀)

u 는 측지 법선(타원체 수직)이다. ENU = [e; n; u] · (X − X₀). 역변환은 전치 행렬.
